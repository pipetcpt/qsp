## 1. 이 모델이 설명하려는 것

요소회로는 인체가 **질소를 대량으로 버릴 수 있는 유일한 경로**입니다.
식이 단백과 내인성 단백 분해에서 나온 질소는 암모니아로 문맥주위 간세포에
도달하고, NAG로 활성화된 CPS1 → **OTC** → ASS1 → ASL → ARG1을 거쳐 요소가 되어
신장으로 배설됩니다. 어느 한 단계가 막히면 질소는 되돌아옵니다.

몸의 첫 반응은 암모니아를 선형으로 쌓는 것이 **아니라 글루타민으로 완충**하는
것입니다(주로 골격근 glutamine synthetase, 전신 플럭스 ≈300 µmol/kg/h). 그래서

- **혈장 글루타민이 암모니아보다 먼저 오릅니다** — 조기경보 지표인 이유.
- **질환은 경사가 아니라 절벽입니다** — 완충이 버티는 동안 환자는 멀쩡해 보이고,
  질소 부하가 잔존 요소생성 용량을 충분히 오래 넘기면 암모니아가 급격히 치솟습니다.

치명적인 장기는 뇌이고 기전은 **삼투압**입니다. 별아교세포는 CNS에서 유일하게
glutamine synthetase를 가지므로 혈중 암모니아가 그곳에서 글루타민으로 갇힙니다.
글루타민은 삼투질이고, 별아교세포는 **myo-inositol을 배출해** 부피를 방어합니다.
그런데 **만성 고암모니아혈증에서는 myo-inositol이 이미 소진되어 있습니다.**
그래서 정상 뇌라면 견딜 유발인자에도 만성 환자가 파국적으로 무너집니다.
이 상호작용이 UCD에서 가장 중요한 비직관적 거동이며, 이 모델은 그것을
`MINSB` 구획으로 명시적으로 재현합니다.

## 4. mrgsolve 모델 (35 구획)

### 4.1 구획 구성

- **PK (16)** — GPB 장내 풀 · PBA 장/혈장 · PAA · PAGN(혈장·요중 누적) ·
  벤조산 장/혈장 · 히푸르산(혈장·요중 누적) · 시트룰린 장/혈장 ·
  아르기닌 장/혈장 · 카글룸산 장/혈장
- **질소 균형 (5)** — 혈장 암모니아 · 교환성 글루타민 · **심부 조직 글루타민
  저장고** · 누적 요소 질소 · 이화 상태
- **중추신경 (4)** — 뇌 암모니아 · 뇌 글루타민(혈중 암모니아 유래분) ·
  **뇌 myo-inositol** · 뇌 수분 초과
- **보조 풀 (4)** — 오르니틴 · 글리신 · BCAA · 오로트산
- **유전자치료 (2)** — 전달체 주형(AAV episome / LNP-mRNA) · 전이유전자 유래 OTC 활성
- **적분기 (4)** — AUC>100 · 혼수 범위 누적 시간 · 신경 손상 지수 · PAA 초과 노출

### 4.2 자기보정 기저상태 (self-calibrating baseline)

초기값을 하나도 하드코딩하지 않습니다. `$MAIN`에서 환자 기술자로부터
치료 전 정상상태를 **이분법으로 수치해**하고

```
RA_N  =  A·C/(KM+C)  +  CL_NH4R·C  +  CL_RGLN·vgs(C)/(KGLNASE+CL_RGLN)
```

그 근으로부터 글루타민·뇌 암모니아·뇌 글루타민·myo-inositol·뇌 수분·오르니틴·
오로트산·글리신·BCAA를 모두 닫힌 형태로 유도해 초기값으로 넣습니다.
따라서 **무치료군은 정확히 정지 상태**이며, 시뮬레이션에서 보이는 변화는
전부 기전에서 나온 것입니다.

검증: 건강 대조(활성 100%, 단백 1.0 g/kg/d) → 암모니아 34.2 µmol/L,
글루타민 601 µmol/L, 뇌 글루타민 5.2 mmol/L, 오로트산 0, 단백 내성 1.55 g/kg/d.

### 4.3 질소 화학량론 — 모델의 핵심

글루타민은 질소를 **2개** 나릅니다. 따라서 글루타민 합성은 자유 질소 풀에서
2 N을 차감하고, glutaminase는 2 N을 돌려줍니다. 신장 glutaminase는 1 N을
요중 NH4+로 배설하고 1 N을 돌려줍니다. 그 결과

- **PAGN 1분자 = 질소 2개**가 몸에서 영구히 빠짐
- **히푸르산 1분자 = 질소 1개**

이것이 몰당 페닐부티레이트가 벤조산보다 질소 효율이 두 배인 이유이고,
모델은 이를 구조적으로(임의의 효과 파라미터가 아니라) 재현합니다.

### 모델이 재현하는 임상 관찰

- **시나리오 3 vs 4** — 동일 PBA 몰수에서 GPB는 PAA Cmax가 85 → 61 µg/mL로 낮고
  암모니아 조절은 오히려 약간 더 좋습니다. Diaz 2013 *Hepatology*의 교차설계
  결과와 같은 방향이며, 원인은 모델 안에서 오직 **췌장 리파아제 의존적
  서방출 단계 하나**입니다.
- **시나리오 5** — 벤조산은 질소 배출의 15%만 담당합니다(PAGN은 30%). 몰당
  질소 1개 vs 2개라는 화학량론의 직접적 귀결.
- **시나리오 9 vs 10** — 신생아 위기에서 투석은 암모니아를 4시간 만에
  1182 → 31 µmol/L로 떨어뜨리지만, **약물치료만으로는 108시간에 걸쳐 236까지밖에
  못 내립니다.** 그리고 투석 종료 후 심부 글루타민 저장고에서 질소가 재분포하며
  **반동**(86 h에 13 → 120 h에 181 µmol/L)이 나타납니다. 그럼에도 두 군의
  최종 IQ 차이는 3점뿐입니다 — **예후를 정하는 것은 치료 방식이 아니라
  진단까지의 60시간 지연**이라는, 이 질환에서 가장 뼈아픈 사실입니다.
- **시나리오 11** — 카글룸산은 NAGS 결핍에서 단백 내성을 0.46 → 1.35 g/kg/day로
  올립니다. 유일하게 약물로 표현형이 치유되는 UCD.
- **시나리오 13** — 신·간 기능 저하가 겹치면 PAA가 549 µg/mL에 이르고
  PAA:PAGN 비가 문턱 2.5를 넘습니다(최고 19.3). 포합 포화의 조기 신호.

## 6. 실행 방법

```r
# 1) 모델 빌드 + 시나리오
source("ucd_mrgsolve_model.R")
mod <- UCD_build()
sim <- UCD_simulate_scenarios(mod)          # 14개 전부
UCD_summarise(sim)                          # 요약표
UCD_plot(sim, "NH3", "Plasma ammonia (umol/L)", log = "y")

# 2) 개별 환자 시뮬레이션
mod |>
  mrgsolve::param(OTCACT = 0.15, PROT = 0.45, WT = 70) |>
  mrgsolve::mrgsim(events = ucd_gpb(17.5, n = 3, ii = 8, addl = ucd_addl(30, 8)),
                   end = 30*24, delta = 1, hmax = 0.25) |>
  plot(NH3 + GLNP + PAAUG ~ time)

# 3) 대시보드
shiny::runApp("ucd_shiny_app.R")
```

필요 패키지: `mrgsolve` (>= 1.0; 2.0.1에서 개발·검증), 대시보드는 추가로
`shiny`, `shinydashboard`, `dplyr`, `tidyr`, `ggplot2`, `DT`.

## 7. 알려진 한계

- 아미노산 네트워크를 명시적으로 풀지 않고 **자유 질소 풀 하나**로 축약합니다.
  글루타민의 두 질소를 모두 그 풀에 대해 차감·환급하는 방식으로 수지를 닫았으며,
  이는 전신 질소 균형 수준에서는 정합적이지만 개별 아미노산 동태를 예측하지는
  않습니다.
- `IQEST`는 혼수 지속시간-예후 관계를 **재현하도록 보정한 예시 지표**이며
  개인의 예후를 예측하지 않습니다.
- 태반 청소가 없으므로 출생 직후 신생아의 "정상 암모니아" 구간은 표현되지
  않습니다. 시나리오 9/10은 생후 12시간 시점에서 시작합니다.
- ARG1 결핍(아르기닌 축적형)과 HHH 증후군은 지도에는 있으나 ODE에서는
  `DISTALA` 축약으로만 다룹니다.
