# 중증 화상 (Major Thermal Burn Injury) — QSP 모델

> **한 번의 손상, 두 개의 시계, 그리고 일하는 동안 이득이 줄어드는 제어기.**
>
> 화상 소생술은 보통 "공식대로 주고 소변량을 보라"로 가르쳐집니다. 이 모델은
> 대신 **곱셈 하나**에서 출발합니다.
>
> ```
>        혈관내 증가분  =  주입량 × f_ret ,        f_ret = f_ret(Π_p)
> ```
>
> 그리고 Π_p(혈장 교질삼투압)가 단백질 농도의 **볼록 함수**라는 사실만
> 추가합니다 — Landis–Pappenheimer,
>
> ```
>        Π = 2.1 C + 0.16 C² + 0.009 C³        [C = 총단백 g/dL]
> ```
>
> 총단백을 7.0 → 3.5 g/dL로 **절반** 희석하면 교질삼투압은 25.6 → 9.7 mmHg,
> 즉 **62 %**가 사라집니다. 따라서 **무단백 결정질 수액은 매 리터가 직전
> 리터보다 비쌉니다.** f_ret는 소생술이 진행되는 동안 계속 떨어집니다.

## 이 모델이 주장하는 세 문장

### ① 곱 (The product)

혈관내 용적은 **주입한 것**이 아니라 **주입량 × 유지분율**입니다. 그리고
유지분율은 위의 볼록성 때문에 누적 결정질 수액의 감소함수입니다. 이것은
비유가 아니라 시뮬레이션이 시간마다 출력하는 값입니다.

```
 t[h]   R[mL/h]  배수   UO[mL/h]  VP[%]    Cp    COP
    0       900   1.00       80     100   7.00   25.6
    4      1288   1.43        6      62   4.64   14.1
    8      2359   2.62       56      90   2.31    5.8
   12      1109   2.46       77      99   2.58    6.6
   24       179   0.40      262     125   4.37   13.0
```

**투여속도 배수(R)가 올라가는 바로 그 구간에서 교질삼투압이 무너집니다.**
제어기는 자기가 파괴하고 있는 이득 위에서 더 세게 밀고 있습니다.

### ② 제어기 (The controller)

소변량에 맞춘 소생술은 **폐루프**입니다.

```
        dR/dt = g · R · (UO_목표 − UO_측정) / UO_목표
        루프 이득 = (dUO/dVP) · f_ret
```

f_ret가 ①에 의해 감소하므로 **루프 이득이 감소합니다.** 같은 소변량을
유지하려면 제어기는 투여속도를 계속 올려야 합니다.

> **수액 크립(fluid creep)은 투여 실수가 아니라, 이득이 감소하는 제어기의
> 고정점입니다.**

모델은 이것을 예측이 아니라 계산으로 내놓습니다: 개방루프로 공식을 문자
그대로 지키면 정확히 4.00 mL/kg/%TBSA이지만 소변량이 목표에 도달하지 못하고
(24시간 소변 0.53 L), 소변량에 맞춰 적정하면 **5.97 mL/kg/%TBSA**, 즉 처방량의
**1.49배**가 됩니다. 문헌의 관찰값은 5.2–6.7이며 in:out 비 1.2–1.6입니다.

콜로이드는 **부피를 더해서** 듣는 것이 아니라 **f_ret를 복원해서** 듣습니다.
그래서 시험에서 알부민의 신호는 혈역학 개선이 아니라 **in:out 비의 감소**로
나타납니다.

그리고 복강내 고혈압이 **두 번째 고리**를 닫습니다: 복강내압이 신관류를 깎아
같은 혈장량에서 소변량을 줄이고, 제어기는 그것을 저혈량으로 읽어 **더 많이
투여합니다**. 이 고리는 양성입니다.

### ③ 두 개의 시계 (The two clocks)

같은 %TBSA가 시간상수가 세 자릿수 다른 두 과정을 구동합니다.

| 과정 | 시간상수 | 지속 |
|---|---|---|
| 모세혈관 누출 | τ ≈ 9.5 h | 24–36시간이면 닫힘 |
| 대사항진 | τ ≈ 104 d | 12–24개월 지속 |

그리고 **느린 시계의 구동원은 입원 시 %TBSA가 아니라 오늘의 개방 창상 면적
A_open(t)입니다.** 이 치환 하나가 조기 절제·이식이 왜 REE를 낮추는지를
설명합니다 — **구동원 자체를 제거하기 때문**입니다. 프로프라놀롤은 대신
**전달자**(β-수용체)를 차단합니다.

둘은 같은 곱의 서로 다른 인자에 작용하므로 **상가적이지 않습니다**:

```
                                        최대 REE    14일 제지방량
  지연 절제(14일), 무투약              :  160.5 %      −11.3 %
  지연 절제(14일) + 프로프라놀롤       :  157.3 %       −0.6 %   전달자 단독 −3.2점
  조기 절제(3일), 무투약               :  150.6 %       −5.2 %   구동원 단독 −9.9점
  조기 절제(3일) + 프로프라놀롤        :  150.4 %       +3.4 %   둘 다     −10.1점

  각각의 합 −13.2점  vs  병용 −10.1점   →  SUB-ADDITIVE
```

**프로프라놀롤은 폐쇄가 느릴 때 −3.2점을 벌고, 빠를 때는 −0.2점을 법니다.**
검증 가능한 주장입니다.

## 모델이 틀리는 곳 (숨기지 않음)

1. **8시간에 시작한 알부민은 수액을 5 %밖에 줄이지 못합니다.** 메타분석 추정치는
   20–40 %입니다. 모델의 이유는 기계적이고 검증 가능합니다 — 파클랜드의 전반
   8시간 집중 투여 형태에서는 8시간 시점에 이미 교질삼투압 희석의 대부분이
   끝나 있습니다. 같은 콜로이드 분율을 0시간에 시작하면 **−38 %**입니다.
   시험에서 시작 시점이 그만큼 중요하지 않다면 **이 구조가 틀린 것**입니다.
2. **아스코르브산이 Tanaka의 값을 잘 재현하는 것은 승리가 아니라 문제입니다.**
   이후 어떤 시험도 그 결과를 재현하지 못했으므로, 모델은 사실이 아닐 수 있는
   결과에 맞춰져 있는 셈입니다. 이 시나리오는 권고가 아니라 "Kf 병변의 산화
   가설이 옳다면 무엇이 따라오는가"로 읽어야 합니다.
3. **5 % 알부민을 총단백 교질삼투압 식에 넣었습니다.** 알부민은 그램당
   글로불린보다 삼투 활성이 크므로 콜로이드 군은 **구조적으로 보수적**입니다.
4. **사망률은 개방 창상 위험함수를 통해 rBaux 로지스틱에 맞춰졌습니다.**
   따라서 위의 나이–%TBSA 교환 가능성 결과는 내적 일관성 검사이지 독립 검증이
   아닙니다.
5. **프로프라놀롤의 제지방량 효과가 문헌보다 작습니다.** 대조군 대비 변화폭
   (약 +10.5 %p)은 방향과 자릿수가 맞지만, 대조군이 Herndon이 보고한 −9 %보다
   덜 잃어서 두 군 모두 위쪽에 있습니다.
6. **없는 것들:** 응고병증, 횡문근융해 동역학, 약물별 신독성. 흡입 손상은
   수액 배수와 위험 배수로만 들어가며 가스 교환은 모델링하지 않았습니다.
