## 1. 이 모델이 답하려는 질문 (the question this model exists to answer)

PSP에서 수행된 두 개의 프로그램은 **표적 결합률과 임상 결과가 서로 반대 방향을
가리키는** 숫자를 보고했습니다.

| 프로그램 | 표적 결합 | 임상 결과 |
|---|---|---|
| **가수라네맙 (gosuranemab, PASSPORT, n=486)** | CSF unbound N-terminal tau **−98%** (위약 +11%, p<0.0001) | PSPRS 52주 변화 **10.4 vs 10.6** (p=0.85), CSF NfL 무변화 |
| **NIO752 (MAPT ASO, phase 1, n=59)** | CSF total tau / p-tau181 **−20%** (5배 **작다**) | CSF NfL **안정화** (위약 +40%) — 이 질환 역사상 유일한 하류 신호 |

타우오패시 임상시험 역사상 **가장 큰 표적 결합률**이 **가장 평평한 무효 결과**에
붙어 있고, **가장 작은 바이오마커 변화**가 **유일한 신호**에 붙어 있습니다.
그리고 후자는 3상(Preserve, n=300, 72주, mPSPRS-10)에 진입했습니다.

"타우를 낮춘다"가 **하나의 축**인 모델은 이 두 사실을 동시에 담을 수 없습니다.
그래서 이 모델은 타우를 **크기가 10³–10⁴배 다르고 인과적 역할이 전혀 다른
여러 풀(pool)** 로 분리하고, 두 시험이 **서로 다른 풀을 움직였다**는 것이
출력으로 나오도록 구성했습니다.

```
intraneuronal soluble monomer   TMON    ~2000 nM     ← 엔진 (the engine)
regional aggregate load         A1..A8  0–1          ← 병리
ISF N-terminal fragments        ETN     ~1 nM        ← 측정된 것 (the assay analyte)
ISF seed-competent assemblies   ETS     ~0.02 nM     ← 인과적 종 (the causal species)
CSF                             CTN,CTS ~0.005 nM
```

## 2. 일곱 개의 구조적 축 (seven structural axes)

각 축은 **fitted knob이 아니라 코드 한 줄**입니다.

### AXIS 1 — 풀 크기. 세포외 풀은 엔진이 아니라 배기가스다

```
F_EXT = ETN / TMON = 5.75e-4      (모델 출력, 문헌 범위 3e-4 ~ 1e-3)
```

세포내 단량체는 ~2000 nM, 항체가 도달할 수 있는 ISF 풀은 ~1 nM입니다.
**작은 풀의 98%를 제거하면 뇌 전체 타우의 0.06%가 제거됩니다.** 세포외 기전의
천장은 `F_EXT × Φ_ACC`이며, **용량과 친화도를 무한히 올려도 이 천장은 움직이지
않습니다.**

### AXIS 2 — 결합 역설. 98%라는 숫자 자체가 표적이 작았다는 증거다

−98%는 **맞춘 값이 아닙니다**. 실제 PK와 실제 친화도에서 나옵니다.

```
2000 mg q4w, V1 = 3 L, t½ ≈ 25 d   →  Cp,avg ≈ 300 mg/L ≈ 2000 nM
Kp,brain = 0.15%                    →  AISF = 6.73 nM        (모델 출력)
Kd = 0.034 nM                       →  free fraction = 1/(1 + 196)
complex 제거가 free보다 4배 느림      →  측정치 = -98.04%     (관측 -98%)
```

**150 kDa IgG를 저나노몰 농도로 넣으면 1 nM 항원은 포화시키고 2000 nM 항원에는
무관합니다. 98% 결합은 표적 타당성의 증거가 아니라 표적이 포화 가능할 만큼
작았다는 증거입니다.**

부수적으로, 복합체가 유리 타우보다 **느리게** 제거되므로(크고 bulk-flow/FcRn
제한) 모델은 **CSF total tau가 +283% 올라간다**고 예측합니다 — unbound는
내려가고 total은 올라가는, **하나의 기전 두 개의 반대 방향 판독값**입니다.

### AXIS 3 — 에피토프. 측정된 종과 인과적 종은 서로 다른 분자다

ISF/CSF의 타우는 **절단되어 있습니다**. 모델은 두 개의 물리적으로 분리된 상태를
둡니다.

- `ETN` — N-말단 절편. **풍부하고**, caspase-3/calpain/AEP에 의해 잘려 나온,
  **seeding 능력이 없는** 종. 이것이 문자 그대로 "unbound N-terminal tau"
  분석법이 보고하는 물질입니다.
- `ETS` — mid-domain / MTBR 조립체. **희소하고**, seeding 능력이 있으며,
  **N-말단을 이미 잃어버린** 종.

N-말단 항체는 첫 번째에 `Kd = 0.034 nM`, 두 번째에 `Kd = 10⁶ nM`을 가집니다.
**에피토프 파라미터 하나가 측정된 종의 −98%와 인과적 종의 0%를 동시에
만들어냅니다.** 모델은 판별 분석법도 지목합니다: **CSF seeding activity**와
**MTBR-tau243** — total tau도, N-말단 tau도 아닙니다.

### AXIS 4 — 기하학. 진행은 커넥톰을 지나는 이동 전선(travelling front)이며, 국소 동역학은 이미 포화되어 있다

국소 templated seeding은 자가촉매적(`dA/dt = k·A·(1−A)`)이므로 **로지스틱**,
즉 각 핵에서 **포화**합니다. 포화 시그모이드의 합이 선형이 되려면 영역이
**순차적으로 동원**되어야 합니다. 따라서 **PSPRS 기울기가 ~11점/년으로 거의
선형인 것 자체가 전선(front)의 증거**이며, 그것은 **이미 침범된 모든 핵이
`k`를 바꿔도 아무 일도 일어나지 않는 지점에 앉아 있다**는 뜻입니다.

모델이 계산한 동원 순서(50% 부하 도달 시점, 년):

| | 핵 | 년 | 임상 대응 |
|---|---|---|---|
| R1 | 시상하핵 (STN) | 2.05 | — |
| R4 | 중뇌 피개 (riMLF/rip) | **2.36** | **수직 안구운동 마비 — 가장 이른 징후** |
| R2 | GPi/SNr | 4.01 | 파킨슨증 |
| R5 | 대뇌각교뇌핵 (PPN) | **4.08** | **후방 낙상** |
| R3 | SNc | 4.73 | 도파민 결핍 |
| R8 | LC / 연수 (bulbar) | 6.96 | 연하장애·구음장애 |
| R7 | 전두피질 | 7.15 | 실행기능·무감동 |
| R6 | 치아핵 | 7.57 | 소뇌 징후 (PSP-C) |

시험 등록 시점은 7.07년입니다. **즉 등록할 때 전선은 이미 여덟 개 핵 중 여섯 개를
지나갔습니다.**

**세 개의 무효 결과가 이 한 문장에서 나옵니다.** 티데글루십(GSK-3β), OGA 억제제,
다부네타이드(미세관 안정화)는 모두 `k`에 작용하며, `k`는 **이미 포화된 양**을
곱합니다.

### AXIS 5 — 제곱근 법칙이 아니라 **측정된 탄성도**

연속체 Fisher–KPP는 `v ∝ √(D·k·M)`, 즉 탄성도 0.5를 예측합니다. 희소 그래프
위의 이산 pulled front는 `v ≈ k·Δx / ln(k/D)`, 즉 거의 1을 예측합니다.
**이 모델은 어느 쪽도 주장하지 않고 측정합니다** (`psp_elasticity()`).

| MAPT knockdown | 등록 시점부터 투여: 72주 기울기 (상대) | 생물학적 발병부터 투여: 등록 중증도 도달 지연 |
|---|---|---|
| 10% | 0.9974 | 0.42 년 |
| 20% | 0.9947 | 0.98 년 |
| 30% | 0.9918 | 1.71 년 |
| 50% | 0.9854 | **4.14 년** |
| 70% | 0.9782 | 10.62 년 |
| 80% | 0.9743 | **20.45 년** |
| 90% | 0.9702 | 33년 내 도달하지 않음 |

```
치료기 탄성도  dln(slope)/dln(M) = 0.022
=> 증상이 이미 있는 환자에서 기울기를 절반으로 만드는 것은
   어떤 knockdown 수준에서도 불가능하다.
```

**같은 파라미터, 같은 약, 세 자리 수 차이. 차이는 오직 *언제* 주는가입니다.**
이것은 Preserve 시험(2027–28 판독 예정)에 대한 위조 가능한 예측입니다:
72주 mPSPRS-10에서 **0.02점**.

### AXIS 6 — ASO 구배. CSF 바이오마커는 전선에 대한 효과를 과대평가한다

척수강내 ASO 노출은 **피질 ≫ 심부핵**인데, 전선은 심부핵에 있고 CSF 바이오마커는
피질이 지배합니다. `ASO_DEEP = 0.4`는 이 괴리를 명시적으로 만듭니다:
**CSF total tau −19%는 전선이 보는 monomer 감소 ~10%에 해당합니다.**

이 인자를 넣지 않으면 모델은 Preserve의 효과를 2.5배 과대평가합니다.

### AXIS 7 — 타이밍. 점수는 지연되고 예비능으로 문턱이 걸린 신경 소실의 **적분**이다

응집 부하는 점수를 만들지 않습니다. **손실률**을 만들고, 그것이 신경 수로
적분되고, 그것이 **영역별 예비능 문턱(θ_r)** 을 넘고, 그것이 두 개의 transit
구획을 통과해 점수를 움직입니다. 약과 종말점 사이에 **적분 두 번과 문턱 하나**가
있습니다.

**모델 내 반사실(counterfactual) — 52주 PSPRS 이득:**

| 개입 | 시작 시점 | 52주 이득 |
|---|---|---|
| 응집을 **100%** 차단 | 등록 시점 | **0.21 점** |
| 응집체를 **50배 속도로 제거** | 등록 시점 | **1.78 점** |
| MAPT ASO (Preserve 용법) | 등록 시점 | 0.02 점 |
| mid-domain 항체 | 등록 시점 | 0.0001 점 |
| 응집을 100% 차단 | **증상 발생 3년 전** | **49.57 점** |

**완벽한 약도 등록 시점에 시작하면 52주에 0.21점입니다.** 이유는 손상률이 `A`에
비례하고 `dA/dt`에 비례하지 않기 때문입니다 — **응집을 멈추는 것과 응집체를
없애는 것은 다르며, 등록 시점에 필요한 것은 후자입니다.** 그리고 후자조차
1.78점입니다.

> PASSPORT와 ARISE는 **설계상 금지된 효과 크기**를 검출하도록 검정력을
> 계산했습니다. 표본 수의 문제가 아닙니다.

### 시간 축은 입력이 아니라 출력입니다

등록 시점을 "생물학적 발병 후 3.5년"으로 **고정하는 것은 불가능했습니다** —
그렇게 하면 점수가 t=0부터 선형이어야 하고, PSPRS 38점과 10.6점/년을 동시에
만족시킬 수 없습니다. 그래서 등록 시점을 **모델 자신의 PSPRS = 38 통과 시점**으로
정의했고, 그 결과 **전임상 기간이 출력이 되었습니다.**

```
t = 0.00 y   첫 타우 응집체
t = 3.57 y   증상 발생        ← 3.6년의 전임상 타우오패시 (출력)
t = 7.07 y   시험 등록 중증도 (PSPRS 38)
t = 11.31 y  중위 생존        ( = 증상 발생 후 7.73년, 관측 7.9년)
```

**어떤 임상시험도 본 적 없는 3.6년이 증상 앞에 있습니다.** AXIS 7의 반사실이
가리키는 창(window)이 바로 이 구간입니다.

## 4. 실패로 보고하는 것 (failures reported, not repaired)

### 4.1 PSP-P의 기울기 — 파동 원점만으로는 설명되지 않는다 (\|log ratio\| 0.439)

모델은 PSP-P를 **파동 원점의 차이만으로** (STN+중뇌 대신 SNc) 표현합니다.
그 결과 **등록 중증도 도달이 2.13년 늦어지고** 생존이 길어지지만
(8.16년 vs 7.73년), **기울기는 느려지지 않습니다** (13.73 vs 관측 ~5).

이것은 모델에 없는 것을 필요로 합니다: **부검에서 PSP-P는 PSP-RS보다 타우 부하
자체가 낮습니다.** `KAGG`를 낮추면 기울기는 맞지만, 그렇게 하면 "아형 차이는
원점만으로 나온다"는 진술이 더 이상 참이 아니게 됩니다. **기울기를 맞추기 위해
구조적 주장을 포기하지 않고, 실패를 보고합니다.** 판별 실험은 명확합니다:
PSP-P와 PSP-RS에서 **같은 중증도**일 때의 tau-PET SUVR 총량 비교.

### 4.2 CSF NfL의 1년 상승률 (\|log ratio\| 0.424)

NIO752 phase 1의 위약군은 1년에 **+40%** 를 보고했고, 모델은 **+15.1%** 를
예측합니다. 모델에서 NfL은 축삭 부피로 가중된 (i) 신경 사멸률과 (ii) 진행 중인
비치사적 축삭 손상의 합인데, 전선이 대용적 백질(전두피질)에 막 들어가는
등록 시점 근처에서 최대 상승률을 냅니다. 그것으로도 40%에는 미치지 않습니다.

다만 **더 넓은 문헌에서 PSP의 CSF NfL은 상승해 있으나 종적으로 비교적 안정적**
이며(그래서 진단 표지자로 쓰입니다), +40%는 n≈20 위약군의 단일 phase 1
관측입니다. 모델이 틀렸을 수도 있고 그 관측이 소표본 변동일 수도 있습니다.
**어느 쪽인지 결정하는 것은 Preserve의 위약군(n=100)입니다.**

### 4.3 작은 미스들

- **중뇌 면적** 89.1 mm² (관측 70–85). 모델의 중뇌는 R4·R1·R5의 가중 조합이며
  피개 밖의 위축을 담지 않습니다.
- **수직 saccade 최대속도** 139.6 deg/s (관측 150–200). `GAM_SAC = 1`(선형)이
  약간 과도한 감소를 줍니다. 지수를 맞추면 "문턱이 없는 판독값"이라는 진술이
  흐려지므로 그대로 둡니다.
- **MRPI** 13.3 (관측 ~15, 절단값 13.55). 진행기에는 20을 넘어가는데, 이는
  MRPI가 검증된 범위를 벗어납니다. **클리핑하지 않고 그대로 보고합니다.**

### 4.4 폐기한 구조 (discarded, not tuned)

**"제곱근 법칙"** — 초안의 지도(.dot)는 `v ∝ √M`이므로 "기울기를 절반으로
만들려면 75% knockdown이 필요하다"고 **주장**했습니다. 탄성도를 실제로 측정할 수
있게 된 뒤 모델은 이를 **반박했습니다**: 치료기 탄성도는 0.022이고, 절반으로
만드는 것은 어떤 knockdown에서도 불가능합니다. 연속체 Fisher–KPP의 0.5는
**하한**이고 이산 pulled front의 ~1.0은 **상한**인데, **이산 8핵 사슬에서
등록 이후에 측정하면 두 한계 모두보다 훨씬 작습니다** — 전선이 이미 지나갔기
때문입니다. 지도와 문서에서 그 주장을 **삭제하고 측정값으로 교체했습니다.**

## 5. 통합 중에 발견하고 고친 결함 (defects found during integration)

mrgsolve 2.0.1 / R 4.3.3에서 실행하며 발견한 것들. **모델을 실제로 돌리지
않았다면 전부 그대로 남아 있었을 것들입니다.**

1. **파동이 없는 축퇴 해(degenerate fit).** 첫 최적화는 `KAGG = 47/day`를
   찾아냈습니다. 모든 영역이 1년 안에 포화하여 **전선이 아예 존재하지 않고**,
   임상 앵커는 순전히 신경 소실 적분기만으로 맞춰졌습니다. 숫자는 전부
   훌륭했고 모델의 중심 구조적 주장은 사라져 있었습니다. 목적함수에 파동 도달
   시각 표적을 넣어 해결.
2. **임상 지연의 소멸.** 자유롭게 맞춘 `KLAG`가 ~19일로 붕괴해, AXIS 7의
   시험설계 논증이 의존하는 지연을 삭제했습니다. 고정.
3. **정상상태를 벗어난 초기조건.** `TMON_0`이 기저 청소 인자(`CLR0`)를 빼고
   설정되어 모델이 자기 정상상태 밖에서 출발했고, 성장항이 **부호가 반대인
   유령 −5% "knockdown"** 을 보았습니다. 그 결과 `ASO_DEEP`이 약효가 아니라
   **자가포식 피드백을 조용히 스케일링**하고 있었습니다. 초기조건과 기준값
   양쪽에 `ACT0/CLR0`를 넣고, `MFRONT`를 약물 기인분과 생리 기인분으로 분해.
4. **자기 자신에 대해 측정된 knockdown.** 탄성도 프로브가 `KSYN_T`를 낮췄지만
   기준값 `TMONS`도 `KSYN_T`를 포함하고 있어서 비율이 항상 1이었습니다.
   **80% knockdown이 0으로 기록되었고, 탄성도는 −0.000이 나왔습니다.**
   고정 기준 `KSYN_T0`/`TMREF` 도입.
5. **시간 게이트가 없는 반사실.** "등록 시점부터 50배 응집체 제거"가 실제로는
   **출생부터** 적용되어, 환자가 애초에 병에 걸리지 않았습니다. 11.2점의
   "치료 이득"은 **질병의 부재**였습니다. `TDIS/FDIS` 게이트 추가 후 1.78점.
6. **"전임상"이 전임상이 아니었다.** `TENROL − 1095`로 코딩된 "증상 발생 3년
   전"은 실제로는 증상 발생 **183일 후**였습니다. `TSYMPT − 1095`로 수정.
7. **기저치 변화량만 보고하던 비교표.** 질병을 **지연**시키는 개입은
   고정 등록 시각에 곡선의 더 낮은 곳에 앉으므로 **변화량이 더 커집니다.**
   S09와 S27이 위약보다 **나빠 보였습니다** (+0.48, +0.61). 절대 점수를 함께
   출력하도록 수정: 같은 시나리오가 −4.30점, −17.32점입니다. (이것은 버그가
   아니라 종말점 선택의 함정이며, 그래서 표에 **남겨** 두었습니다.)
8. **R 문자열 조기 종료.** 모델 코드 주석의 `Kd's` 안의 아포스트로피가
   단일인용 문자열을 끊었습니다. raw string(`r"---( )---"`)으로 전환하고
   파일 전체를 ASCII로 정리(로케일이 POSIX인 환경에서 파싱 실패 방지).
9. **한 줄 다중 선언.** `double a = ..., b = ...;`는 유효한 C++이지만
   mrgsolve의 선언 hoisting은 첫 변수만 처리합니다. 한 줄 한 선언으로 분리.
10. **graphviz `init_rank` 실패.** 클러스터 수준의 순환이 `dot`의 지역
    클러스터 랭킹을 깨뜨렸습니다(23개 클러스터가 양방향으로 얽힘).
    `newrank = true`로 전역 랭킹으로 전환.
