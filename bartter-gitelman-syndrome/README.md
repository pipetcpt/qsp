# 바터 증후군 & 기텔만 증후군 QSP 모델
### Bartter & Gitelman Syndrome — Salt-Losing Tubulopathies · BGS

> **한 개의 병변, 두 개의 위치.** 이 모델은 바터 증후군과 기텔만 증후군을 서로 다른
> 두 질환으로 취급하지 않습니다. **동일한 NaCl 수송 결함을 매큘라 덴사(macula densa)
> 기준으로 위쪽(TAL)에 놓느냐 아래쪽(DCT)에 놓느냐** — 이 한 가지 구조적 차이만
> 부여하고, 임상적으로 두 질환을 구별하는 모든 소견이 **계산 결과로 튀어나오는지**를
> 검증하는 것이 이 모델의 목적입니다.

## 2. 질환 배경 (Disease Background)

바터 증후군(Bartter syndrome)과 기텔만 증후군(Gitelman syndrome)은 신세뇨관의
NaCl 재흡수 장애로 인한 **상염색체 열성 염실성 세뇨관병증**입니다. 공통 소견은
**저칼륨성 저염소성 대사알칼리증 + 고레닌·고알도스테론증 + 정상 혈압**이며,
이 조합 자체가 "신장에서 소금을 잃고 있다"는 신호입니다.

| | 바터 (Bartter) | 기텔만 (Gitelman) |
|---|---|---|
| 병변 위치 | 헨레 상행각 굵은부분 (**TAL**) | 원위곡세뇨관 (**DCT**) |
| 매큘라 덴사 기준 | **위쪽 / 병변에 포함** | **아래쪽** |
| 유전자 | `SLC12A1`(I) · `KCNJ1`(II) · `CLCNKB`(III) · `BSND`(IVa) · `CLCNKA+KB`(IVb) · `MAGED2`(V) | `SLC12A3` |
| 발현 시기 | 산전~신생아 (I·II·IVa·V) / 소아 (III) | 청소년~성인 |
| 요중 PGE₂ | **↑↑ 2–10배** (hyperprostaglandin E syndrome) | **정상** |
| 요중 Ca | **고칼슘뇨** → 신석회화 → CKD | **저칼슘뇨** |
| 혈청 Mg | 정상~경미한 저하 (산전형은 대체로 정상) | **↓↓ 현저** |
| 요농축능 | 심하게 손상 (다뇨·양수과다) | 대체로 보존 |
| 난청 | type IV에서 동반 (barttin이 내이에도 발현) | 없음 |
| COX 억제제 | **효과적 (질환 수정적)** | **거의 무효** |

유병률은 기텔만이 약 1–10/40,000(보인자 빈도 ~1%)으로 가장 흔한
유전성 세뇨관병증이며, 바터는 약 1/1,000,000입니다.

## 3. 모델의 핵심 아이디어 — 위치가 표현형을 만든다

모델에는 유전형별 스위치가 **하나도 없습니다.** 움직이는 것은 두 개의
용량 파라미터뿐입니다.

```
FTAL  = 헨레 상행각 NaCl 수송 용량 (0–1)
FDCT  = 원위곡세뇨관 NCC 수송 용량 (0–1)
```

### 3.1 매큘라 덴사는 자기 자신의 NKCC2로 NaCl을 감지한다

매큘라 덴사는 **TAL의 끝**에 위치합니다. 여기서 흔히 나오는 역설이 있습니다.
바터 증후군에서는 TAL 재흡수가 망가졌으니 매큘라 덴사에 **도달하는** 관내 NaCl은
오히려 **높습니다**. 그런데 왜 레닌과 COX-2가 올라갈까요?

답: 매큘라 덴사 세포도 **자기 자신의 apical NKCC2**로 NaCl을 세포 안으로
받아들여야 감지할 수 있고, **그 NKCC2에도 같은 병변이 있기** 때문입니다.
관내 농도가 높아도 세포는 "소금이 없다"고 읽습니다. 이는 furosemide가 관내
NaCl을 올리면서도 레닌을 자극하는 것과 정확히 같은 논리입니다.

모델에서는 이것이 단 한 줄입니다.

```cpp
LUMREL  = LDCT / LDCTR;                                  // 도달한 NaCl (높음)
MDSENSE = ATAL * pow(LUMREL, EMD);                       // 감지된 NaCl (낮음)
```

`ATAL`이 곱해져 있으므로 **FTAL이 낮으면 감지 신호가 낮아지고, FDCT는
`MDSENSE`에 전혀 등장하지 않습니다.** 해부학적 순서가 곧 수식의 순서입니다.
Shiny 앱 6번 탭에서 이 두 선의 **벌어짐 자체가 바터 증후군**입니다.

### 3.2 여기서 파생되는 것들 (모델에 코딩하지 않은 결과)

| 결과 | 파생 경로 |
|---|---|
| **요중 PGE₂가 TAL 병변에서만 상승** | `MDSENSE ↓ → COX-2 유도 → mPGES-1 → PGE₂` |
| **COX 억제가 바터에서만 유효** | 기텔만은 그 고리를 아예 돌리지 않으므로 약물 표적 점유율이 동일해도 결과가 없음 |
| **PGE₂ 양성 피드백(악순환)** | `PGE₂ → NKCC2 추가 억제 → MDSENSE 더 하락` |
| **요중 칼슘의 부호 역전** | TAL의 K⁺ 재순환 소실 → 관내 양전위(+8 mV) 붕괴 → 측방세포간 Ca²⁺ 구동력 상실(고칼슘뇨) **vs** DCT 병변은 TAL 온전 + 용적수축 → 근위세뇨관 Ca 흡수 증가(저칼슘뇨) |
| **혈청 Mg: 기텔만 < type III < 산전형 바터** | 산전형은 원위 Mg 부하가 폭증해 비대·TRPM6 상향조절된 DCT가 이를 회수(`KMGLOAD`); 기텔만은 DCT 자체가 위축되어 회수 불가 |
| **type III가 기텔만과 중첩** | ClC-Kb가 TAL·DCT 양쪽에 발현 → FTAL·FDCT를 동시에 낮추는 유일한 유전형 |
| **Mg를 먼저 채우지 않으면 K가 오르지 않음** | 저마그네슘혈증이 ROMK의 세포내 Mg²⁺ 차단을 해제 (`KMGROMK`) |
| **KHCO₃가 아니라 KCl이어야 알칼리증이 교정됨** | 염소 결핍이 신장 중탄산 역치를 올림 (`KCLTH`) |
| **티아지드 부하 반응이 기텔만에서 평탄** | 차단할 NCC가 이미 정지 상태 |

### 4.1 네프론 분절 연쇄 (대수적 계산)

```
여과 Na  →  PT (Ang II 의존)  →  TAL (FTAL × PGE₂ 억제 × CaSR)
         →  [매큘라 덴사 감지]  →  DCT (FDCT × NCC 인산화)
         →  ASDN (포화형, ENaC/알도스테론, 아밀로라이드 차단)  →  요중 Na
```

원위 전달량(`LASDN`)이 **K⁺ 분비와 H⁺ 분비를 동시에 구동**하는 결합 변수이며,
이것이 두 증후군이 공유하는 저칼륨성 대사알칼리증의 단일 원인입니다.

### 4.2 요중 전기중성으로 닫은 염소 균형

염소를 별도 파라미터로 맞추는 대신 요중 전기중성식으로 닫았습니다.

```
U_Cl = U_Na + U_K + 0.55·J_H⁺ − U_HCO₃ − U_(미측정 음이온)
```

덕분에 "NaCl을 주면 왜 알칼리증이 좋아지는가"가 별도 가정 없이 나옵니다.

## 7. 임상적 시사점 (모델이 말하는 것)

1. **표적 점유율이 효능이 아니다.** 기텔만에서 인도메타신은 신장 COX-2를 바터와
   동등하게 억제하지만 임상 효과가 없습니다. 표적이 아니라 **회로**를
   봐야 한다는 QSP의 가장 기본적인 교훈이 여기서 정량적으로 재현됩니다.
2. **마그네슘이 칼륨보다 먼저다.** 저마그네슘혈증이 ROMK 차단을 해제하는 한
   경구 KCl 증량은 소변으로 흘러갑니다 (S10 vs KCl 단독).
3. **염화물염이어야 한다.** 중탄산·구연산 칼륨은 알칼리증을 교정하지 못합니다.
4. **NSAID의 이득은 최대화 대상이 아니라 적정화 대상이다.** 질환을 구동하는
   PGE₂는 위점막을 보호하고 사구체 여과를 지지하는 그 PGE₂입니다 (S15).
5. **알약 부담이 진짜 율속단계다.** S17에서 순응도 60%는 병용요법의 생화학적
   이득 대부분을 상쇄합니다 — 하루 6–20정을 평생 복용하는 질환에서 이는
   약리학 문제가 아니라 설계 문제입니다.
6. **소아에서 1차 엔드포인트는 성장이다.** 혈청 K가 아니라 신장 SDS 궤적이
   TAL 병변의 통합 지표이며, PGE₂ 억제로 되돌릴 수 있는 유일한 축입니다.

## 8. 한계 (Limitations)

- 혈압은 결과 변수로만 다루며 혈역학 모델을 포함하지 않습니다.
- PTH·칼시트리올·골 대사는 강한 항상성 항으로 축약했습니다.
- 신장 발생·성장에 따른 네프론 수 변화, 태아 순환은 모델링하지 않았습니다
  (산전형은 소아 파라미터로 근사).
- type V(MAGED2)의 자연 소실은 프리셋으로만 표현되며 HIF-1α 산소 의존성
  자체를 미분방정식으로 풀지 않습니다.
- 파라미터는 공개 문헌의 집단 요약치에 대한 **반정량적** 보정이며, 개별
  환자 데이터에 적합·검증되지 않았습니다.
