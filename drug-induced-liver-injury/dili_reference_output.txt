    HONEST CAVEAT - an unexplained non-monotonicity.
    In the 500 mg/kg and vulnerable-host rows, starting NAC at 2 h is
    slightly WORSE than starting at 6 h. Two hypotheses were tested and
    only one survived:
      (a) 'the fixed 21-h course finishes before a massive ingestion is
          done being bioactivated'. Prolonging the maintenance infusion
          at the SAME rate (more NAC, not the same NAC spread thinner):
            maintenance 16 h:  49.3%  42.4%  32.9%  57.5%  74.5%  82.5%   monotone: False
            maintenance 32 h:  29.9%  26.8%  20.5%  55.7%  74.4%  82.5%   monotone: False
            maintenance 48 h:  29.3%  26.4%  20.2%  55.7%  74.4%  82.5%   monotone: False
            maintenance 72 h:  29.3%  26.4%  20.2%  55.7%  74.4%  82.5%   monotone: False
            (NAC start 2 / 4 / 6 / 10 / 16 / 24 h)
          A longer course helps a great deal (49.3% -> 29.3% lost at a
          2 h start) but does NOT restore monotonicity, so coverage
          duration is only part of the story.
      (b) 'the 2 h run simply accumulates more damage'. FALSIFIED - the
          6 h run has the WORSE glutathione nadir and MORE adducts:
            NAC@ 2 h  GSH nadir  26.2%  peak adducts  20.97  peak JNK 0.281  lost  29.3%
            NAC@ 4 h  GSH nadir  24.5%  peak adducts  22.25  peak JNK 0.268  lost  26.4%
            NAC@ 6 h  GSH nadir  23.3%  peak adducts  23.49  peak JNK 0.243  lost  20.2%
            NAC@10 h  GSH nadir  15.2%  peak adducts  29.04  peak JNK 0.394  lost  55.7%
    So the ordering is a genuine dynamical effect of WHEN the thiol
    supply arrives relative to the reactive-metabolite pulse, not of how
    much damage is done. It is reported here rather than smoothed away;
    it is a model behaviour that would need experimental scrutiny before
    anyone believed it. Note it appears only at the extreme 500 mg/kg
    dose and in the compromised host - the standard 350 mg/kg curve
    above is cleanly monotone, and 'give NAC as early as possible'
    remains the model's advice in every clinically ordinary case.


[5] WHY THERE IS A THRESHOLD AT ALL: the JNK-Sab loop is bistable
    isolated-loop fixed points as a function of redox capacity
    g = (0.30 + 0.70*GSH/GSH0) * NRF2   [g = 1.0 at rest]
      g = 1.60   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 1.40   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 1.20   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 1.10   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 1.00   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 0.95   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 0.90   monostable OFF  (JNK -> 0)      - injury is impossible
      g = 0.85   BISTABLE  (separatrix at JNK = 0.031, ON state 0.391)
      g = 0.80   monostable ON   (JNK -> 0.536)  - injury is now unavoidable
      g = 0.70   monostable ON   (JNK -> 0.645)  - injury is now unavoidable
      g = 0.60   monostable ON   (JNK -> 0.706)  - injury is now unavoidable
    -> GSH consumption LOWERS g and Nrf2 induction RAISES it, so the
       separatrix moves during the run. That is why the antidote window
       in [4] is not a fixed number of hours.

[6] HY'S LAW IS A RATE x RESERVE CONJUNCTION
    ALT  >= 3xULN (120 U/L)  first at 280 mg/kg, with   4.15% of hepatocyte mass lost
    TBIL >= 2xULN (2.4 mg/dL) first at 350 mg/kg, with  64.75% of hepatocyte mass lost
    -> the bilirubin arm requires 15.6x more lost liver than the ALT arm.
       ALT is a low-pass filter on the RATE of hepatocyte death (released per cell that dies);
       bilirubin is set by the RESERVE that remains (clearance scales with surviving mass).
       Requiring BOTH is therefore a test that the liver is dying fast AND has run out of spare capacity
       - which is exactly why the conjunction, and neither arm alone, predicts death.
    Hy's Law (both arms) first satisfied at 350 mg/kg.
    Across 51 simulated doses: 33 cross the ALT arm, 26 cross both (79% of ALT-positive doses).

[11] FALSIFICATION TEST - is the JNK-Sab loop really load-bearing?
     Sab-null mice are protected from APAP hepatotoxicity (Win 2011).
     Setting KROS_SAB = 0 severs the feedback and nothing else:
     250 mg/kg   intact loop: lost   0.1% (JNK 0.050)    loop cut: lost   0.0% (JNK 0.035)
     310 mg/kg   intact loop: lost  37.5% (JNK 0.384)    loop cut: lost   1.7% (JNK 0.115)
     350 mg/kg   intact loop: lost  64.8% (JNK 0.539)    loop cut: lost  19.9% (JNK 0.248)
     400 mg/kg   intact loop: lost  81.3% (JNK 0.646)    loop cut: lost  46.5% (JNK 0.347)
     500 mg/kg   intact loop: lost  92.1% (JNK 0.729)    loop cut: lost  75.9% (JNK 0.512)
     700 mg/kg   intact loop: lost  96.7% (JNK 0.758)    loop cut: lost  89.3% (JNK 0.609)
     -> cutting the loop abolishes injury at 310 mg/kg (37.5% -> 1.7%)
        and pushes the threshold far to the right. The loop is not
        decoration; it is what converts a metabolic insult into
        necrosis, exactly as the knockout experiment implies.
