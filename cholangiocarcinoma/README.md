## 이 모델이 존재하는 이유

담관암은 보통 이렇게 그려진다 — **위험인자 → 담관상피 돌연변이 → 종양 성장 →
항암제가 줄인다 → 오래 산다(또는 못 산다).** 이 그림은 다음 일곱 가지 관찰을
동시에 견디지 못한다.

| | 관찰 | 단선 캐스케이드가 설명하지 못하는 것 |
|---|---|---|
| **A** | ABC-02 젬시타빈/시스플라틴: 반응률 26%, mPFS 8.0개월, mOS 11.7개월 | 이득을 보는 환자의 3/4은 RECIST 반응에 한 번도 도달하지 않는다. 반응과 생존이 느슨하게만 연결되어 있다 |
| **B** | 가장 흔한 종말 사건은 종괴가 아니라 담도다 | 담관염과 폐색성 간부전이 종양 부피만으로 치명적이 되기 훨씬 전에 도착한다 |
| **C** | 담도 배액은 항종양 작용이 **전혀 없다** | 그런데도 배액 없이는 어떤 전신치료도 용량대로 들어가지 않는다 (빌리루빈이 젬시타빈과 시스플라틴을 모두 보류시킨다) |
| **D** | FGFR2 융합 종양은 페미가티닙에서 **다클론성** kinase-domain 변이(V564F, N550K…)로 진행하며, 영상 변화보다 ctDNA가 먼저 움직인다 | 내성이 "유도"되는 것이라면 다클론성일 이유가 없다 |
| **E** | TOPAZ-1: 중앙 생존 11.5 → 12.8개월(거의 안 움직임), 24개월 생존 10.4% → 24.9%(크게 벌어짐) | 평균 종양 크기를 추적하는 모델은 **꼬리를 벌릴 수 없다** |
| **F** | ClarIDHy 아이보시데닙: 반응률 ~2%인데 PFS 위험비 0.37 | 축소 없이 이득. 세포독성이 아니라 세포정지성 |
| **G** | FGFR2 융합과 IDH1 변이는 사실상 간내 담관암에만 있고, 간문부 병변은 폐색으로 실패한다 | 해부학적 위치가 실패 양식 자체를 바꾼다 |

그래서 이 모델은 캐스케이드 대신 **세 가지 구조적 입장**을 취한다.

### I. 전달된 용량은 입력이 아니라 **출력**이다

모든 임상시험 프로토콜은 "젬시타빈 1000 mg/m², d1·d8"이라고 쓰고, 모든 임상시험은
100%에 한참 못 미치는 상대 용량 강도를 보고한다. 이 모델에서 처방은 *의도*로만
들어오고, **투여 시점에 상태로부터 계산된 네 개의 게이트**가 곱해진다.

```
규칙 1  빌리루빈   GATE = 1 / (1 + (BILI/2.6)^6)
규칙 2  호중구     GATE = 1 / (1 + (1.0/ANC)^8)
규칙 3  신기능     GATE = 1 / (1 + (45/CrCl)^8)     ← 시스플라틴만
규칙 4  수행상태   GATE = 1 / (1 + (PS/2.6)^8)
```

간문부의 종양이 폐색을 만들고, 폐색이 빌리루빈을 올리고, 빌리루빈이 규칙 1을 닫기
때문에 이 모델에는 **닫힌 양성 되먹임 고리**가 있다 —
`성장 → 폐색 → 용량 보류 → 성장`. 지도(`cca_qsp_model.dot`)에서 이 고리는
`LOOP 1/4 … 4/4`로 굵은 붉은 선으로 실제로 그려져 있다.

**배액은 이 파일 어디에서도 종양세포를 죽이지 않는다.** 그런데도 지도에서 지렛대가
가장 큰 노드다. 그 고리를 끊는 유일한 간선이기 때문이다. 그것이 요점이다.

> **반증자는 파라미터 하나다.** `GATE_ON = 0`이면 네 규칙이 모두 사라진다.
> 그러면 배액을 60일 늦추는 것이 생존에 영향을 주지 않아야 한다.

### II. 내성은 유도되는 것이 아니라 **선택**된다

FGFR2 kinase-domain 변이 클론 `T_R`은 t = 0에 Goldie–Coldman 규칙
`T_R(0) = T(0) · μ · ln(N)`으로 이미 씨앗이 뿌려져 있다. 이 파일 어디에서도
민감세포가 변이세포로 *전환되지 않는다.* "내성 발생 시점" 파라미터는 존재하지 않는다.

**이 입장은 음성 결과를 낳았고, 그것을 숨기지 않고 보고한다.** 방어 가능한 씨앗
빈도(약 2.5 × 10⁻⁵)에서 이 클론은 7개월 PFS 안에 임상적 우위를 점할 수 **없다.**
산수가 그것을 금지한다 — `ln(0.2 / 2.5e-5) / 0.026`은 약 11개월이다. 그래서 모델은
FGFR 억제제의 중앙 PFS를 **약물내성 지속세포(`T_P`, drug-tolerant persister)**에
할당하고, 클론에는 그것이 실제로 설명할 수 있는 사건들만 맡긴다 — 1년쯤 뒤 확립된
반응의 소실, 영상보다 앞서는 ctDNA 상승, 가역적 억제제와 공유결합 억제제 사이의
교차내성 비대칭(`RHO_PEM` 0.05 vs `RHO_FUT` 0.45). 따라서 `MU_RES = 0`은 첫 1년
안에서 거의 아무것도 바꾸지 않으며, **아래 반증 표에 그대로 그렇게 적혀 있다.**

### III. 생존은 서로 다른 시계를 가진 **두 개의 경쟁 위험**이다

```
h_tumour   느린 시계 : 종양부피/간부피 + 간 예비능 결손 + 악액질
h_biliary  빠른 시계 : 담관염 부담 + ALBI 초과분,  재발성이고 대체로 예방 가능
S(t) = exp(−∫(h_tumour + h_biliary))
```

집단 생존은 개별 `S(t)`의 **평균**이다. 그래서 한 번의 시뮬레이션에서 중앙값과
24개월 꼬리가 동시에 나온다. 그리고 면역치료가 — 모두에게 조금씩이 아니라 종양의
혼합 분율 `PI_IMMUNE`에만 작용하기 때문에 — **중앙값을 거의 움직이지 않으면서
꼬리를 벌리는** 이유가 바로 이것이다.

## 적합된 것과 적합되지 않은 것

8개 파라미터만 데이터에 맞췄다: `K_GEM`, `K_CIS`(세포독성 강도), `KSP0`, `ALPHA_P`
(지속세포 진입과 잔존 살상), `KFGFR_KILL`, `KIMM`, 그리고 두 개의 위험 기울기
`HT_T`, `HB_CH`. 나머지는 발표된 PK 파라미터, 허가사항의 용량, 생리 상수, 또는
사전에 고정한 구조적 선택(Simeoni `PSI = 20`, Friberg 전이구획 3개,
Goldie–Coldman 씨앗 규칙)이다.

### 적합하지 않고 나온 것 (예측)

- **TOPAZ-1의 서명이 재현된다.** 대조군 대비 중앙 생존은 11.0 → 13.1개월(+2.1),
  24개월 생존은 4.0% → **20.3%**. 실제 시험은 11.5 → 12.8(+1.3), 10.4% → 24.9%였다.
  중앙값은 거의 안 움직이는데 꼬리가 벌어지는 이 패턴은 **혼합 파라미터의 결과이지
  적합된 값이 아니다.** 모두에게 조금씩 듣는 평균효과 모델로는 나올 수 없다.
- **배액을 60일 늦추면 전달 용량이 94% → 68%로 떨어지고 중앙 생존이 13.1 → 10.2개월로
  짧아진다.** 항종양 파라미터는 **하나도** 바뀌지 않았다. 스텐트가 언제 들어가는지만
  바뀌었다.
- **금속 대신 플라스틱 스텐트를 쓰면** 개통성 반감기가 239일 → 90일로 짧아지고,
  RDI 94% → 89%, 중앙 생존 11.0 → 10.9개월. 작지만 방향이 맞고 순전히 개통성에서 나온다.
- **아이보시데닙은 반응률 0%로 나온다.** 성장률만 낮추고 살상률이 0인 노드를
  붙였기 때문이며, ClarIDHy의 2%가 바로 그 모양이다.
- **S11은 시행된 적 없는 실험이다.** 페미가티닙의 1주 휴약을 없애면 반응률이
  40% → 65%로 오르고 중앙 생존이 10.9 → 11.6개월이 된다. 휴약 주간마다 `T_S`와
  `T_P`가 온전한 속도로 재증식하기 때문이며, 검증 가능한 예측이다.

### 반증자 (파라미터 하나씩, 나머지 재적합 없음)

| | 변경 | 예측 | 결과 |

### 빗나간 것 (묻지 않고 적는다)

1. **반응률이 전반적으로 높다.** gem/cis 31.7% vs 실제 26.1%, 푸티바티닙 80% vs 42%.
   지속세포 전환이 일어나기 전에 죽는 `T_S`의 비율이 너무 높다. 특히 연속 투여
   경구제에서 심하다 — 펄스형 정맥 투여보다 `e_sp`가 낮게 유지되기 때문이다.
2. **FGFR 억제제의 생존을 크게 과소평가한다.** S6 10.9개월 vs FIGHT-202 21.1개월,
   S7 11.8 vs FOENIX-CCA2 20.0. 이 두 시험의 환자는 이미 1차 치료를 받고도 좋은
   수행상태로 등록된 선택된 집단이고, 모델은 그 선택을 표현하지 않는다.
   `HT_T`가 간내 담관암에서 너무 가파른 것도 원인이다.
3. **보조요법의 생존을 과소평가한다.** 31.2 / 27.0개월 vs BILCAP 53 / 36개월.
   무재발생존(19.5 / 14.8 vs 24.4 / 17.5)은 훨씬 가깝다. 재발 이후의 궤적이 너무
   빠르다는 뜻이며, 재발 시점의 미세 병변이 진단 시점의 종양과 같은 `LAM0`로
   자라도록 되어 있기 때문이다.
4. **1·2번은 같은 결함일 가능성이 높다.** 둘 다 "치료 후 남은 병변이 원래 종양과
   같은 동역학을 따른다"는 가정에서 나온다. `T_P`에 별도의 느린 재증식 시계를
   주면 둘이 함께 개선될 것으로 보이며, 이는 다음 개정의 첫 시도가 될 것이다.

### R 모델과 Python 쌍둥이의 차이

`cca_reference_impl.py`는 `cca_mrgsolve_model.R`의 정확한 쌍둥이다 — 같은 54개 상태,
같은 이름, 같은 숫자. 위 표의 모든 값은 Python 파일에서 나왔고, 그 파일은 **의존성이
전혀 없다**(numpy도 scipy도 쓰지 않는다). 두 파일은 딱 두 가지 기계적 지점에서 다르다.

- **스텐트 교체.** Python은 개통성이 0.25 아래로 떨어지면 재스텐트한다(상태 유발 사건).
  mrgsolve에는 상태 유발 사건이 없으므로 R 드라이버는 고정 간격 교체를 예약한다.
- **적분기.** 젬시타빈의 혈장 반감기가 약 6분이라 Python은 주입 전후로 스텝을
  0.002–0.01일까지 줄이는 고정스텝 RK4를 쓴다. mrgsolve는 LSODA를 쓰므로 필요 없다.

사용해서는 안 된다.** 파라미터는 설명을 위한 근사이며 실제 환자 데이터에 대한
적합과 검증이 별도로 필요하다. 위 "빗나간 것" 절은 완결된 목록이 아니다.
