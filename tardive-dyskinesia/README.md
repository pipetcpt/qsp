# 지연성 운동이상증 (Tardive Dyskinesia, TD) — QSP Model

> 항정신병제를 오래 쓴 뒤 나타나는 불수의 운동을, **부작용의 목록이 아니라
> 두 개의 기억(memory)을 가진 이력현상(hysteresis)** 으로 다룬 정량적 시스템
> 약리학 모델.
> 하나는 수개월 시상수로 완전히 되돌아오는 **시냅스후 D2 초민감성(RUP)**,
> 다른 하나는 스스로를 유지하는 **구조적 손상(SDAM, 이중안정)** 이며,
> 임상에서 쓸 수 있는 두 레버 — 원인약물 감량과 VMAT2 억제 — 는
> **같은 시냅스의 반대편**에 붙어 있다. 이 분리 때문에 이 모델에서는
> "언제 중단하면 되돌릴 수 있는가", "왜 중단이 처음에는 증상을 악화시키는가",
> "왜 약효는 확실한데 질병은 그대로인가"가 모두 하나의 구조에서 계산된다.

## 1. 질환 개요 (Disease in one paragraph)

지연성 운동이상증은 도파민 D2 수용체 차단제(항정신병제, 그리고
메토클로프라마이드 같은 비정신과 약물)에 수개월 이상 노출된 뒤 나타나는
불수의적 과운동성 증후군이다. 구강-혀-씹기 운동이 가장 흔하고, 사지-체간
무도성 운동증, 지연성 근긴장이상, 지연성 좌불안석, 호흡성 운동이상이 겹칠
수 있다. 발생률은 1세대 항정신병제에서 연 5-6%, 2세대에서 연 3-4%이며 55세
이상에서는 연 25-30%까지 올라간다. 기전으로는 (i) 만성 D2 차단에 대한
시냅스후 초민감성(수용체 밀도 증가, D2High 분획 증가, Gi/β-arrestin 이득
증가), (ii) 세포질 도파민 자동산화·MAO 유래 H2O2·미토콘드리아 복합체 I 억제로
인한 산화 손상, (iii) 선조체 콜린성·파브알부민 개재뉴런 소실과 GABA 전달
결핍이라는 구조적 변화, (iv) 그 결과로 생기는 직접로/간접로 불균형과
창백핵-시상 탈억제가 함께 거론된다. 치료는 두 갈래다. 원인약물을 줄이거나
클로자핀처럼 점유율이 낮은 약으로 바꾸는 것, 그리고 VMAT2 억제제(발베나진,
듀테트라베나진)로 전시냅스 도파민 공급을 줄이는 것. 임상적으로 곤란한 점은
이 둘이 서로 다른 대가를 요구하고, 감량은 처음 수주 동안 증상을 **악화**시키며,
어떤 환자에서는 중단해도 다시 좋아지지 않는다는 것이다.
**이 모델의 목표는 그 세 가지 곤란을 약효의 크기가 아니라 시스템 상태의
차이로 설명하는 것이다.**

## 2. 모델의 구조적 주장 (What the model asserts)

```
(A) 가역적 기억: 시냅스후 D2 초민감성 RUP
    dRUP/dt = KIN_R · Hill(OCC; 0.70, n=4) · RISKMOD · (1+0.5·E_ACH)
              − KOUT_R · RUP / (1 + 0.8·SDAM)
    → 점유율 문턱(~70%) 위에서만 구동된다. 구동이 사라지면 τ = 300 d 로
      완전히 사라진다. 이것만 있으면 TD는 항상 가역적이어야 한다.

(B) 준-비가역적 기억: 구조적 손상 SDAM  ← 이 모델의 핵심
    dSDAM/dt = KIN_S · Hill(0.55·ROS + 0.45·RUP; 0.85, n=8) · (1−SDAM)
               − KOUT_S · SDAM
    그리고 결정적으로 SDAM 은 자기 구동원을 되먹인다:
        ros_drive += 2.2 · Hill(SDAM; 0.50, n=4)     (미토콘드리아 자기증폭)
    이 되먹임이 포화형(SDAM<0.3 에서 무시할 수준, >0.7 에서 최대)이기 때문에
    SDAM 방정식은 이중안정이다:
        하위 안정점 SDAM = 0        (수리가 이긴다)
        불안정 문턱 SDAM ≈ 0.50-0.55
        상위 안정점 SDAM ≈ 0.85-0.90 (약을 끊어도 스스로 유지된다)

(C) 관찰되는 운동증은 두 상태에서 직접 읽지 않는다. 기저핵 루프의 출력이다.
    D2STIM = DA_SYN · (1 + 2.2·RUP) · (1 − 0.55·OCC) · (1+0.5·E_ACH)/(1+0.35·E_AMA)
    EXC    = max(D2STIM − 1, 0) + 1.2·SDAM
    IND → GPe → STN → GPi/SNr → THAL → AIMS = 26 · Hill(THAL−1; 0.55, 2)
```

(C)의 두 항이 이 모델의 임상적 내용을 전부 만든다.

* **`(1 − 0.55·OCC)`** — 진행 중인 차단이 자기가 만든 증상을 **가면(mask)**
  한다. 차단을 걷어내면 AIMS는 내려가기 **전에** 올라간다.
* **`+1.2·SDAM`** — 점유율과 **무관한** 항이다. 잠금이 걸린 뒤에는 원인약물을
  어떻게 조작해도 내려갈 수 없는 AIMS 하한이 생긴다.

그리고 두 레버는 같은 시냅스의 반대편에 있다. **D2 차단을 낮추는 쪽**은 RUP의
구동을 없애지만 증상을 드러내고 정신증을 지불한다. **도파민 공급을 낮추는 쪽**
(VMAT2 억제)은 증상을 없애지만 RUP도 SDAM도 건드리지 않고 파킨슨증·우울·진정을
지불한다.

## 3. 계산된 결과 (Computed results)

아래 모든 수치는 **이 방정식들의 출력**이며 문헌 값이 아니다. 동일한 방정식을
numpy/scipy로 독립 구현한 [`td_reference_check.py`](td_reference_check.py)로
전부 재현된다. 기준 환자(index patient) = 58세, 리스페리돈 등가 8 mg/일,
FGA 수준 산화 부담(RISK_FGA 1.6), D2 점유율 0.86, AIMS(730일) = 10.59.

### 3.1 이중안정성이 실제로 존재한다 (`TD_latch_bistability`)

약물이 전혀 없는 상태에서 dSDAM/dt 의 부호를 스캔하면 세 개의 근이 나온다.

| | SDAM | 의미 |
|---|---|---|
| 하위 안정점 | 0 | 수리가 이긴다 — 완전 회복 |
| 불안정 문턱 | 0.50 – 0.55 | 이 위로 올라가면 되돌아오지 않는다 |
| 상위 안정점 | 0.85 – 0.90 | 원인약물 없이 스스로 유지 = 지속성 TD |

### 3.2 누적 용량은 노출 지표가 아니다 (`TD_exposure_threshold`)

같은 약을 용량 × 기간으로 다르게 쪼개어 투여하고 중단 후 6년까지 추적한다.

아니라 앞으로의 궤적이 결정한다.**

### 3.6 억제(suppression)와 수정(modification)은 다른 동사다 (`TD_suppression_vs_modification`)

2년간(y2→y4) 치료하고 y4에 끊는다.

| 처치 | AIMS y2 | AIMS y4 | RUP y4 | SDAM y4 | AIMS y4+8주 | AIMS y6 |
|---|---|---|---|---|---|---|
| 무처치 | 10.59 | 12.36 | 1.445 | 0.872 | 12.41 | 12.74 |
| 발베나진 80 (y4 중단) | 10.59 | **8.88** | 1.413 | 0.872 | **12.33** | 12.71 |
| 듀테트라베나진 36 (y4 중단) | 10.59 | 9.30 | 1.418 | 0.872 | 12.35 | 12.72 |
| 클로자핀 전환 (y2) | 10.59 | **7.70** | **0.295** | 0.871 | **7.48** | **6.00** |
| 클로자핀 + 발베나진 | 10.59 | 4.69 | 0.284 | 0.872 | 7.39 | 5.97 |

VMAT2 억제제는 2년간 AIMS를 3.5점 낮추지만, 끊고 8주가 지나면 무처치군과
구별되지 않는다(12.33 vs 12.41). 과잉 반동(rebound overshoot)은 **없다** —
효과만 사라진다. 반면 클로자핀 전환은 RUP를 1.45에서 0.30으로 내리고, 중단
이후에도 이득이 남는다(y6: 6.00 vs 12.74). 이 모델에서 질병 수정 레버는
클로자핀 전환뿐이다.

6주 시점에 클로자핀 전환 단독은 AIMS를 **악화**시키고(+1.32) 조합은 개선한다
(−2.35). 즉 VMAT2 억제제의 임상적 역할 하나가 여기서 계산되어 나온다:
**전환기의 금단 유발성 악화를 덮어 주는 가교(bridge)**. 반대로 7년 시점의
상호작용 항은 +2.54로 열-가산적이다 — 둘 다 같은 구조적 하한을 밀고 있어서
서로의 여지를 잡아먹는다. 하나의 조합이 시점에 따라 상보적이기도 하고
중복적이기도 하다.

### 3.10 모델이 표현하려던 가설에 반하는 결과

이 모델은 원래 "VMAT2 억제제로 증상을 눌러 두면 그 사이에 원인약물을 줄일
여유가 생겨 조합이 상승효과를 낼 것"이라는 기대로 작성했다. 계산 결과는
**시점에 따라 다르다**: 6주에는 상보적(가교)이지만 7년에는 상호작용 항이
+2.54로 **열-가산**이다. 또 하나 기대와 달랐던 것은 **금단 악화의 크기가
전략의 우열을 정하지 않는다**는 점이다 — 완전 중단은 최고 AIMS가 가장
높으면서도(12.02) 최종 결과가 가장 좋고(5.14), 반대로 소폭 감량은 가장
안전하게 보이면서 5년 이득이 거의 0이다(12.49 vs 12.61). 그리고 세 번째:
항산화 보조 요법이 잠금 시점을 거의 2배로 늦추는데도 5년 AIMS는 1.4%밖에
좋아지지 않는다 — 이 모델에서 **시간을 벌어 주는 개입과 결과를 바꾸는 개입은
다르다.**

## 5. 실행 방법 (How to run)

```bash
# 1) 기계론적 지도 렌더링
dot -Tsvg td_qsp_model.dot -o td_qsp_model.svg
dot -Tpng -Gdpi=150 td_qsp_model.dot -o td_qsp_model.png

# 2) mrgsolve 모델 — 11개 분석을 모두 실행하고 표를 출력
Rscript td_mrgsolve_model.R

# 3) Shiny 대시보드 (9 탭)
R -e 'shiny::runApp("td_shiny_app.R", port = 8080)'

# 4) R / mrgsolve 없이 같은 수치를 재현 (numpy + scipy 만 필요)
python3 td_reference_check.py          # 전체
python3 td_reference_check.py --quick  # 시나리오만
```

`td_reference_check.py`는 `td_mrgsolve_model.R`의 `$ODE` 블록을 그대로 옮긴
독립 구현이며, 위 3절의 모든 표를 다시 만들어 낸다. 두 구현이 동일한 결과를
주는 이유는 (i) 상태·파라미터가 1:1로 대응하고, (ii) 두 쪽 모두 투약을
**0차 일일 입력**으로 처리하며, (iii) 처방 변경을 `0.5(1+tanh((t−t0)/1))`
형태의 매끄러운 계단으로 처리해 해석기가 불연속을 만나지 않기 때문이다.

## 7. 한계 (Limitations)

* AIMS·정신증·파킨슨증·기분 부담은 **정규화된 부담 지표**이며, PARK/DEPR/PSYCH는
  SAS·PANSS·발생률 같은 실제 척도 단위로 보정되지 않았다. 이들의 **상대적
  변화와 순서**만 해석 가능하다.
* SDAM은 "구조적 손상"의 집합 변수이며 특정 세포군(콜린성 개재뉴런,
  파브알부민 FSI)의 소실률로 보정되지 않았다. 이중안정성은 **구조적 가설**이며
  인간 데이터로 검증된 사실이 아니다.
* 항정신병제를 리스페리돈 등가 하나로 묶었다. 빠른 해리(클로자핀·쿠에티아핀)는
  점유율과 `EC50_D2_CLZ`로만 근사되며, D2 부분작용제(아리피프라졸)는 지도에는
  있으나 ODE에는 없다.
* 투약은 0차 일일 입력이다. 실제 복약 누락으로 인한 급격한 점유율 변동
  (금단 유발성 운동증의 흔한 촉발 요인)은 `ADHER` 상태의 평균적 감소로만
  표현된다.
* 이 모델은 **개체 시뮬레이터**이며 집단 변이(IIV)나 발생률 예측을 위한
  확률 구조를 갖고 있지 않다. "발생률 5%/년"은 파라미터 보정에만 쓰였다.
* 은행엽·비타민 E·아만타딘의 효과 크기는 근거가 약한 영역이며, 모델의
  "지연" 결론은 그 약한 근거 위에 세운 구조적 예측일 뿐이다.
