# Heparin-Induced Thrombocytopenia (HIT) — References

Evidence base for the QSP model in `hit_mrgsolve_model.R`, the mechanistic map in
`hit_qsp_model.dot`, and the dashboard in `hit_shiny_app.R`.
**159 PubMed-linked citations**, grouped by the model module each one supports.

Model conventions: time unit **hours**; 59 ODEs; every baseline balance solved
algebraically in `$MAIN` (200-day drift 0.0000%); the disease is generated by
exposure, never assumed.
