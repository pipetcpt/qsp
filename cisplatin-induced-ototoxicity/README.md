# 시스플라틴 유발 이독성 (Cisplatin-Induced Ototoxicity, CIO) — QSP 모델

<a href="cio_qsp_model.svg"><img src="cio_qsp_model.png" width="640" alt="CIO QSP mechanistic map"></a>

> **한 줄 요약.** 와우 백금은 농도가 아니라 **저장고**이고, 혈장에서 와우까지는
> **혈장 → 혈관조 → 외림프 → 유모세포**의 캐스케이드를 거친다. 자유 혈장 백금의
> 반감기는 22분인데 외림프 백금은 6.9시간에 첨두에 이른다 — 그래서 시스플라틴
> 투여 **6시간 뒤**에 주는 티오황산나트륨은 이미 끝난 전신 노출의 99.996%를
> 건드리지 못하면서도 와우가 앞으로 받아들일 백금의 **79%보다는 여전히 상류에**
> 있다. 임상시험이 발견한 "6시간 규칙"은 약리학적 요령이 아니라 **하나의 시간
> 지연**이며, 이 모델은 그것을 산수로 유도한다.

## 1. 이 모델이 다르게 쓴 네 가지 (The four structural choices)

이 모델은 이독성을 "용량–반응 곡선"으로 적합시키지 않는다. 네 개의 구조적 선택을
하고, 임상에서 관찰되는 것들이 그로부터 **유도되는지**를 확인한다.

### (1) 와우 백금은 농도가 아니라 저장고이며, 그 저장고는 둘로 나뉜다

와우에는 림프 배액이 없다. 백금은 세포 안에서 **가역적·산화환원 활성인 labile pool**
(`PT`, 반감기 60일)과 **공유결합으로 고정된 bound pool**(`PTB`, 반감기 2년)로 갈린다.
질량분석으로 수십 년 뒤에도 검출되는 것은 두 번째 저장고인데, **손상을 일으키는 것은
첫 번째뿐이다.**

이것은 편의가 아니라 검증 가능한 주장으로 썼다. `TRET_D`를 1개월에서 20년까지
**240배** 흔들면 측정되는 결합 백금은 0.0001 → 0.7804 으로 같은 배율만큼 움직이는데
**청력도는 소수점 둘째 자리까지 한 dB도 움직이지 않는다** (검증 출력 Part 5b).
모델의 예측: *잔류 백금은 과거 노출의 표지자이지 진행 중인 손상의 주체가 아니며,
수년 뒤 그것을 킬레이트하는 개입은 아무것도 바꾸지 못한다.*

### (2) 와우는 직접이 아니라 캐스케이드로 도달된다 — 그리고 그것이 치료 시간창이다

`자유 혈장 Pt → 혈관조(stria vascularis) → 외림프 → 유모세포`

| 구획 | Cmax | Tmax |
|---|---|---|
| 자유 혈장 백금 | 13.04 µM | 1.0 h (t½ **22.2 분**) |
| 혈관조 백금 | 0.987 | 1.9 h |
| 외림프 백금 | 0.416 µM | **6.9 h** (t½ 4.9 h) |

시각 *t* 에 아직 **남아 있는** 각 적분의 비율:

| t (h) | 자유 혈장 백금 | 와우 흡수 | 종양 부가체(관류 양호) | 종양 부가체(관류 불량) |
|---:|---:|---:|---:|---:|
| 2 | 6.98 % | 98.4 % | 31.07 % | 53.56 % |
| 4 | 0.166 % | 90.6 % | 2.46 % | 14.54 % |
| **6** | **0.0039 %** | **79.0 %** | **0.15 %** | **3.72 %** |
| 8 | 0.00009 % | 66.7 % | 0.01 % | 0.94 % |
| 12 | ~0 % | 44.4 % | 0.00 % | 0.06 % |

6시간 행을 읽으면 된다. 전신 구제요법은 이미 일어난 전신 노출의 99.9961%와
관류가 좋은 종양의 부가체 형성 99.85%보다 **하류**에 있지만, 와우가 앞으로
받아들일 백금의 79%보다는 **상류**에 있다. 이 비대칭이 SIOPEL-6 프로토콜의 전부다.

티오황산염이 이 경로를 우회할 수 있는 이유도 구조에 있다: 백금은 수송체 매개로
혈관조를 통과해야 하지만, 티오황산염은 작은 친수성 음이온이라 외림프로 직접 간다.
모델은 이 비대칭을 가정으로 명시하고, 그것이 없으면 6시간 구제가 불가능함을 보인다.

### (3) 글루타티온 소모가 포화하므로 각 밴드는 자기만의 임계 백금량을 갖는다

산화제 유입에 대한 글루타티온 소모를 포화형(`KCON·FLUX·G/(KMG+G)`)으로 쓰면
정상상태 균형이 무너지는 **임계 labile 백금량**이 닫힌 형태로 나온다:

```
PT*_j = KSYN · GMAX_j / (KCON · KROS)
```

이 문턱에서의 글루타티온 값도 자유 파라미터 없이 닫힌 형태로 떨어진다:
`G*² + KMG·G* − GMAX·KMG = 0`.

**두 문턱은 서로 다른 상태변수에서 독립적으로 계산되므로, 일치 여부가 곧 검정이다:**

| 밴드 | PT* | G* | PT>PT* 예측 주기 | GSH<G* 관측 주기 |
|---|---:|---:|---:|---:|
| 0.25k | 1.195 | 0.1667 | 넘지 않음 | 넘지 않음 |
| 1k | 0.888 | 0.1407 | 넘지 않음 | 넘지 않음 |
| 2k | 0.746 | 0.1272 | 10.06 | 10.10 |
| 4k | 0.620 | 0.1142 | 4.05 | 4.08 |
| 8k | 0.514 | 0.1021 | 2.05 | 2.10 |
| 12.5k | 0.454 | 0.0948 | 2.02 | 2.05 |

전 밴드에서 0.05주기 이내로 일치하고, 넘지 않는 밴드도 두 기준에서 **같은 밴드**다.
그래서 이독성은 프로그램된 곡선이 아니라 **누적용량에 따라 첨부(apex) 쪽으로 쓸려
올라가는 문턱**이다.

### (4) 음조지형적 취약성은 두 기울기의 곱이며, 어느 쪽이 청력도 기울기를 만드는지는 측정된다

밴드는 Greenwood 함수 `f = 165.4(10^{2.1x} − 0.88)` 의 실제 위치에 놓인다.
취약성 = `PT*_j / uptake_j` ∝ (예비능 기울기) × (흡수 기울기의 역수):
기저/첨부 흡수비 1.98, 첨부/기저 예비능비 2.63, 곱하면 **5.20**.

성인 600 mg/m² 에서 8 kHz − 1 kHz 청력도 기울기 = **41.6 dB**. 기울기를 하나씩 없애면:

| | 8 kHz − 1 kHz 기울기 | 잃어버린 비율 |
|---|---:|---:|
| 전체 모델 | 41.6 dB | — |
| 예비능 기울기 제거 (`BGSH=0`) | 1.5 dB | **96.3 %** |
| 흡수 기울기 제거 (`BUPT=0`) | 18.0 dB | 56.8 % |
| 둘 다 제거 | 0.0 dB | 100 % |

**청력도의 모양은 백금이 어디에 더 많이 들어가느냐가 아니라 어디에 방어가 덜 있느냐가
만든다.** 흡수 기울기만으로는 관측되는 고음역 하강형 청력도를 만들 수 없다.

### 2.1 티오황산염 지연 스윕 — SIOPEL-6과 ACCL0431이 한 그림에 들어간다

소아 480 mg/m² 배경. 약도 용량도 일정도 같고 **지연시간만** 바뀐다.

| 지연 (h) | 8 kHz (dB) | 이독성 보호 | 종양 log-kill 손실 (관류 양호) | 종양 log-kill 손실 (관류 불량) |
|---:|---:|---:|---:|---:|
| 0 | 3.1 | 88.6 % | **64.2 %** | **69.0 %** |
| 1 | 11.7 | 65.6 % | 22.0 % | 35.3 % |
| 2 | 13.4 | 60.8 % | 6.3 % | 17.9 % |
| 4 | 14.0 | 59.2 % | 0.4 % | 14.5 % |
| **6** | **15.4** | **55.6 %** | **0.0 %** | **1.2 %** |
| 8 | 17.3 | 50.2 % | 0.0 % | 0.3 % |
| 24 | 29.8 | 10.5 % | 0.0 % | 0.0 % |

- **6시간에서 이독성 보호 55.6%** 는 SIOPEL-6의 상대위험 감소(63% → 33%)와 같은 크기다.
- **동시 투여는 효능의 64%를 태운다.** 티오황산염이 왜 늦게 주어져야 하는지는
  약력학이 아니라 이 한 줄이다.
- **관류가 나쁜 전이성 종양에서는 같은 6시간이 더 이상 공짜가 아니다** (1.2% vs 0.0%,
  24배). 그리고 4시간으로 당기면 14.5%로 급증한다 — ACCL0431과 SIOPEL-6의 상반된
  결과에 대한, 검증 가능한 형태의 기전적 가설. (관찰이 아니라 모델 수준의 가설임을
  명시한다.)

### 2.3 분할 투여는 거의 아무것도 벌어주지 않는다 (통념과 충돌하는 예측)

같은 600 mg/m²:

| 일정 | PTA (dB) | 8 kHz (dB) |
|---|---:|---:|
| 100 mg/m² 3주 간격 × 6 | 9.54 | 45.31 |
| 20 mg/m² 5일 × 6 | 9.04 | 44.56 |
| 50 mg/m² 10.5일 간격 × 12 | 8.86 | 43.38 |

외림프가 혈장 첨두를 완전히 평활화하기 때문이다. 모델은 분할의 이득이 사멸함수의
초선형성에서만 나올 수 있음을 보이고, Hill 계수를 1.0 → 3.0 으로 훑어도 이득의
최대치가 **0.50 dB** 임을 보인다. 분할이 임상적으로 의미 있게 이롭다면, 사멸함수는
이 모델이 쓴 것보다 훨씬 가팔라야 한다 — 이것은 검정 가능한 형태의 반증 조건이다.

### 2.4 치료 종료 후 진행은 labile pool의 성질이다

|---:|---:|---:|---:|---:|

`TLAB_D` 를 1주로 줄이면 늦은 진행은 사라지고, 1년으로 늘리면 +40 dB로 폭주한다.
즉 **늦은 진행의 크기는 labile pool 반감기의 직접적인 측정치**다.

### 2.5 신독성은 병렬 손상이 아니라 이독성의 증폭기다

## 3. 검증 (Verification)

R/mrgsolve 런타임이 없는 환경에서 만들어졌으므로, **모든 방정식을 독립적인 Python
구현으로 먼저 작성하고 실행**했다 (`cio_reference_model.py`, scipy LSODA,
rtol 1e-6/1e-7/1e-8 에서 PTA 가 소수 다섯째 자리까지 동일). R 파일은 그 전사이며
파라미터명·상태명·순서가 1:1로 대응한다.

이 과정에서 **세 개의 실제 결함**이 드러났고, 각각 고쳐진 자리에 주석으로 남겼다.

1. **적분 구동부가 상태를 잘라먹고 있었다.** `solve_ivp` 에 `t_eval` 을 주면
   `sol.y[:,-1]` 은 구간의 끝이 아니라 **마지막으로 요청된 출력 시각**의 상태다.
   투여 구간마다 상태가 조용히 절단되어, 신독성 파라미터를 바꿨을 때 이독성이
   **줄어드는** 물리적으로 불가능한 결과가 나왔다. 이제 `t_eval` 에 구간 끝을 항상
   포함시키고 `assert` 로 확인한다.
2. **고실내 티오황산염을 완전혼합 외림프 풀에 적용하고 있었다.** 그 결과 정원창
   볼루스 하나가 와우 전체를 포화시켜 40 µmol 과 400 µmol 이 구별되지 않았고,
   이 경로의 존재 이유인 기저부 편향 자체가 사라졌다. 국소 항으로 다시 썼다.
3. **잔류 백금을 단일 저장고로 썼다.** 반감기 2년짜리 풀 하나만 두면 사멸 위험이
   치료기 수준으로 영원히 유지되어 2년 뒤 진행이 **+46 dB** 로 폭주했다.
   labile/bound 분리는 이 결함을 고치는 과정에서 나왔고, 그 부산물이 §1(1)의
   검증 가능한 주장이다.

수치적 건전성: 상태 음수 없음, `OHC`/`IHC`/`SGN` 이 [0,1] 이탈 없음, `EP ∈ [0, EP0]`,
글루타티온 음수 없음, 허용오차 3자릿수 변화에 대해 결과 불변.

R 코드는 정적으로 검사했다 — 73개 `dxdt_` 가 73개 `$CMT` 와 정확히 1:1 대응,
`$MAIN`/`$ODE`/`$TABLE` 의 괄호 균형(14/14, 312/312, 133/133), 밴드 인덱스가
`TS7 = 8 kHz` 로 Brock 정의와 맞음. Shiny 앱은 28개 출력이 UI/서버 양쪽에 모두
존재하고 23개 입력이 전부 선언되어 있음을 확인했다.

## 4. 모델이 스스로 밝히는 한계 (Stated, not tuned away)

1. **푸로세미드 병용 +17.7 dB** 는 방향은 문헌과 맞지만 크기는 사람 데이터로
   검증된 적이 없다. 모델에서 가장 노출된 예측이다.
2. **주간 저용량 요법(S20)** 은 누적 360 mg/m² 인데도 GFR 60.7 을 예측한다
   (600 mg/m² 3주 간격은 79.9). 세뇨관 회복 반감기가 7일 간격보다 길기 때문이며,
   별도 검증이 필요하다.
3. **ACCL0431 해석**은 모델 수준의 가설이지 관측이 아니다.
4. **결정론적 "대표 환자" 모델**이다. 임상시험의 33% 대 63% 같은 발생률은 개체간
   변이의 산물이고, 여기서는 약물유전체(TPMT·COMT·ACYP2)를 파라미터로 남겨두었을 뿐
   변이 모델을 붙이지 않았다.
5. 외림프·혈관조 구획은 혈장에 되먹임하지 않는 **추적자 구획**이다(와우 부피가
   무시할 만큼 작다는 표준 가정).
