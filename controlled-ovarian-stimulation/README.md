## 이 모델의 명제 (The claim this model is built to make)

> **수확량과 OHSS는 서로 다른 두 변수가 아니라 같은 상태변수(성장 과립세포 질량)의
> 두 개의 읽기이다. 그러므로 FSH 용량으로는 분리되지 않는다. 분리는 오직 트리거의
> 모양에서 온다 — 난자 성숙은 LHCGR 신호의 앞머리(edge)만 필요하고, OHSS는
> 면적(area)에 비례하기 때문이다.**

이 저장소의 다른 모델들처럼, 중요한 것은 "무엇을 넣었는가"가 아니라 **"무엇을
넣지 않았는데도 나왔는가"** 입니다. 이 모델의 파라미터 목록에는 다음이
**존재하지 않습니다**:

- 자라는 난포의 개수, 채취되는 난자의 개수
- 자극 일수(days of stimulation)
- "hCG가 작용제보다 위험하다"는 어떤 계수
- OHSS 중증도 척도·위험점수·역치
- "PCOS는 고반응군"이라는 분류
- "AMH가 난자 수를 예측한다"는 회귀식

그런데 아래 결과가 전부 나옵니다. 넣은 것은 **하나의 질량과 하나의 리간드 풀,
그리고 그것들을 읽는 서로 다른 커널들**뿐입니다.

| 모델에 넣은 것 (구조) | 모델이 계산해 낸 것 (결과) |
|---|---|
| 난포별 FSH 임계값 분포(로그정규 T50 9 IU/L, σ 0.45) + E2·인히빈의 FSH 되먹임 | 무자극 주기의 **단일 배란**(1.2개), 자극 주기의 18개 동시 성장 — 같은 방정식 |
| 임계값이 크기와 함께 **내려가고**, 11 mm 이후 LH 지지로 **전환**됨 | 우성 난포의 선택과 나머지의 폐쇄 (FSH 7.8 → 2.6 IU/L) |
| 과립세포 질량 하나에서 E2·P4·난자·VEGF를 모두 읽음 | 용량 3배 → 난자 **+15%**, 복수 **+125%** (용량은 분리 수단이 아니다) |
| P4 누출항이 질량에 **선형**(포화 없음) | 트리거일 P4가 난포 계수기가 됨: 0.66(AFC 12) / 1.31(25) / 1.49(32) ng/mL |
| LHCGR 신호를 K = 2 / 25 / 40 IU/L 세 커널로 읽음 | 작용제 트리거: 성숙률 동일(0.77 vs 0.78), 복수 **43배** 감소 |
| 성숙 = 앞머리 + 자율 시계 / 파열 = 시계 × 신호 적분 | 34–38시간 채취 창이 유도됨 (44시간에 61% 손실) |
| 프로게스테론이 GnRH 박동을 억제 | 다수 황체가 **자기 지지를 스스로 끊는** 되먹임 → 황체기 결핍 |
| AMH가 임계값을 올리고 LH 긴장도가 LHCGR 획득 전 난포를 정지 | PCOS의 6–9 mm 정지(다낭성 형태)와 자극 시 과다반응이 동시에 |
| 나이 → 배수성만 | 나이 28→44세에서 난자는 8.0으로 **불변**, CLBR은 76% → 21% |

모든 수치는 [`cos_reference_check.py`](cos_reference_check.py)가 실제로 계산한
것이며, 전체 출력은 [`cos_reference_output.txt`](cos_reference_output.txt)에
있습니다.

| 구획군 | 개수 | 내용 |
|--------|------|------|

| 약물 PK | 12 | rFSH(depot/central), corifollitropin, GnRH 길항제, hCG(depot/central), GnRH 작용제(depot/central), 카베르골린, 레트로졸, 질내 P4 |
| 내분비 | 11 | 뇌하수체 LH 저장풀 · LH · 내인성 FSH · E2 · 인히빈 B · AMH · P4 · 황체 질량 · 서지 준비도 · GnRH 수용체 가용성 |
| OHSS | 5 | VEGF · 혈관투과성 · 제3공간 체액 · 혈장 용적 · 임신 hCG |
| 누적기 | 7 | 성숙 커널 노출 · 자율 성숙 시계 · 파열 적분 · 난자 수 · MII 수 · E2 AUC · VEGF 커널 면적 |

### 난포를 "슬롯"으로 이산화한 이유

난포 코호트를 개체별로 추적하는 대신, **FSH 임계값 분포의 등확률 10분위**를
슬롯으로 잡고 각 슬롯이 `AFC/10`개의 난포를 대표하게 했습니다. 이 선택의 결과:

- 환자 간 차이가 **AFC 하나**로 들어갑니다(슬롯 수·방정식은 불변).
- AMH는 별도 입력이 아니라 소난포 풀에서 **계산되는 출력**입니다(AFC 12 → 2.38,
  AFC 32 → 6.34 ng/mL).
- "몇 개가 자라는가"는 `FSHTOT`가 각 슬롯의 임계값 위에 머무는 시간(창)이
  결정합니다 — 즉 **출력**입니다.

### 하나의 리간드, 세 개의 커널 (이 모델의 중심)

LH·hCG·임신 hCG는 같은 수용체를 씁니다. 그래서 리간드는 하나(`LHEQ`)로 두고,
**하류 과정마다 필요한 신호가 다르다**는 사실만 넣었습니다.

| 과정 | 커널 | 필요한 것 |
|------|------|-----------|
| 테카 안드로겐 · 황체 지지 | `LHEQ/(LHEQ+2)` | 기저 박동으로 충분 |
| 감수분열 재개(성숙) | `Hill(LHEQ, 25, 6)` → 0.06 d 노출 시 **커밋** → 이후 0.85 d **자율 시계** | 서지의 **앞머리**만 |
| 난포벽 파열(배란) | 위 시계 1.55 d **그리고** 신호 적분 ≥ 0.90 d | 앞머리 **와** 지속 신호 |
| VEGF 유도 | `Hill(LHEQ, 40, 3)`의 **시간 적분** | **면적**, 며칠분 |

이 비대칭 하나에서 현대 트리거 문헌 전체가 유도됩니다(아래 표 B).

## 2. 검증 (Verification)

R/mrgsolve를 실행할 수 없는 환경이므로, **65개 ODE 전부를 Python/scipy로 독립
재구현**하여 22개 시나리오 × 34일과 6개 파라미터 스윕을 적분했습니다. 이 과정에서
**8개의 구조적 결함**이 드러나 수정되었습니다.

| # | 드러난 결함 | 증상 | 수정 |
|---|------------|------|------|
| i | 감수분열 커밋 적분을 **총 LHCGR 점유율**로 구동 | 기저 LH 5 IU/L가 주기 1일에 난자를 커밋시켜 4 mm 난포가 2일에 전부 배란 | 하류 과정별 커널 분리 — 이것이 모델의 **중심 주장**이 됨 |
| ii | E2 양성 되먹임 스위치의 시간상수가 너무 빠름(KR 3.0) | E2 148 pg/mL(자극 2일차)에서 부분 서지 → 모든 난포가 7.1 mm에서 정지 | KR 1.20 · KROFF 0.45 · 우성 크기 게이트 · 길항제의 **서지 모드 진입 차단** |
| iii | 뇌하수체 LH 저장풀이 **무한 용량** | 길항제 투여 시 풀이 무한 증가 → **길항제의 정상상태 LH 억제 효과가 0** | 포화 풀(SLHMAX 12 000) → 작용제 플레어 크기가 결과로 도출됨 |
| iv | 난자 계수 창과 난포 붕괴 창이 **겹침** | 이미 비어 가는 난포에서 계수 → AFC 12에서 난자 **2.4개**(정답 8.0) | 계수 창(1.2 h) 후 붕괴 창(7.2 h)으로 분리 |
| v | 작용제 볼루스를 트리거일 **아침**에 투여 | 실제 트리거보다 9.6 h 앞서 투여 → 이중 트리거 arm이 채취 전 배란(14.6 → 2.8개) | 정확한 시각의 이벤트로 분리 적분 |
| vi | 황체 P4 출력이 질량에 **선형** | 무자극 황체기 2.3 ng/mL(관찰 10–20), 15황체 IVF 황체기 173 ng/mL(관찰 25–60) | 포화항 `CL/(1+CL/1.46)` → 양쪽 동시 재현 |
| vii | 프로게스테론의 GnRH 되먹임 **누락** | 어떤 트리거에서도 LH가 2일 내 8–10 IU/L로 회복 → 황체는 항상 구제됨(작용제 결핍 −13%) | `KP4LH` 브레이크 → 황체 질량이 자기 지지를 끊음 + 이중 트리거 구제 재현 |
| viii | 임계값 분포 중심이 6.5 IU/L | 내인성 FSH만으로 6개 슬롯이 성장 → **무자극 주기가 삼배란**, 5일차 E2 300 pg/mL | 9.0 IU/L(σ 0.45)로 재중심 — 자극 arm 보정은 그대로 유지 |

이 표가 모델의 전부입니다.

1. **hCG 용량을 줄이는 것과 작용제로 바꾸는 것은 같은 일이 아닙니다.** hCG
   1500 IU는 복수를 0.02 L로 만들지만 최고치가 32 IU/L에 불과해 성숙 커널
   (K = 25, n = 6)에 겨우 걸리고 성숙률이 0.66으로 떨어집니다. 작용제는 최고치
   152 IU/L(성숙 충분)에 면적 0.41 d(OHSS 없음)입니다. **앞머리는 높고 면적은
   좁은 신호** — 이것이 작용제 트리거의 정체입니다.
2. **황체기는 대가를 치릅니다.** 작용제 단독의 황체 7일 P4는 22.2 vs hCG 37.4
   ng/mL(−41%). 이중 트리거는 34.8로 되돌립니다. 모델은 이 방향을 재현하지만
   임상 관찰(참고문헌 29·30)보다 크기가 작습니다 — 남은 기전은 황체화 자체의
   질적 결함으로 추정하며, 한계로 기재합니다.
