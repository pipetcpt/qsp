## 이 모델이 하려는 말 (The three structural commitments)

교과서적 ICH 모델은 "출혈이 커지면 나빠진다"로 끝납니다. 그 그림 하나로는 문헌이 요구하는
사실들을 동시에 만족시킬 수 없습니다 — 특히 **혈압을 낮추면 혈종 확장은 줄지만 90일
결과는 거의 움직이지 않았다**(INTERACT2·ATACH-2), **혈종 용적은 그대로인데 90일 mRS는
움직였다**(i-DEF), **수술 자체가 아니라 잔여 용적이 문제였다**(MISTIE III) 같은 사실들.
그래서 세 가지 구조적 선택을 했습니다.

### ① 혈종 용적은 상태가 아니라 **적분**이다

모델 어디에도 "약물 X가 혈종을 줄인다"는 항이 없습니다. 출혈 플럭스는 하나이고,
그것은 **세 인자의 곱**입니다.

```
BLEEDR = KBLEED · NOPEN · (1 − CLOT) · max(0, MAP − PTISS)
              ↑        ↑          ↑
        열린 출혈점  지혈 무능   구동압
```

강압제는 첫 번째 인자에, 역전제·트라넥삼산은 두 번째 인자에, 기계적 눈사태와 시술 관련
재출혈은 세 번째 인자에 작용합니다. 이들이 **덧셈항이 아니라 하나의 곱의 인자들**이기
때문에, 단일 약제의 용적 효과가 작고(INTERACT2·ATACH-2·TICH-2 모두 확장은 줄였으나
mRS는 못 움직였습니다) 병용은 상승적이라는 사실(INTERACT3)이 별도 가정 없이 따라옵니다.
어느 인자든 0으로 두면 플럭스 전체가 사라집니다 — 그것이 이 구조의 반증 가능한 내용입니다.

또한 `PTISS = ICP + KTAMP·VHEM`이므로 **탐포네이드가 내생적**입니다. 혈종이 커질수록
스스로 출혈을 멈춥니다. 그래서 무치료 확장이 100%가 아니라 20-38%입니다.
`KTAMP = 0`으로 두면 확장이 8.4 → 9.7 mL로 늘고 자기제한성이 사라집니다.

### ② 결과는 **시계가 다른 두 개의 손상 채널**로 결정된다

| 채널 | 기전 | 시간 규모 | 제거술로 되돌아가는가 |
|---|---|---|---|
| **질량효과** | `STRAIN` → 조직 변형 → 축삭 변위 | 시간~일 | 부분적으로 예 |
| **헴-철 화학** | `HEME → HO-1 → Fe²⁺ → Fenton → LPO → 페롭토시스` | 일~주 | **아니오** |

두 채널 모두 `NEUR`(생존 뉴런)과 `WMI`(백질 보전)을 깎고 mRS에 나타납니다.
이것이 데페록사민이 **혈종 용적을 전혀 건드리지 않으면서** 90일 mRS 분포를 움직일 수 있는
이유입니다 — 모델에서 DFO는 `VHEM`으로 가는 간선이 **하나도 없습니다.**
그리고 MISTIE III가 잔여 용적 ≤15 mL 부분군에서만 이득을 보인 이유이기도 합니다:
제거술은 채널 1에만 작용하고 `STRTHR` 문턱을 넘어야 mRS가 움직이는데, 이미 유리된 철은
채널 2를 계속 흘러내려갑니다.

### ③ MAP는 **부호가 반대인 두 자리**에 등장한다

MAP는 출혈의 구동압이면서(낮을수록 좋음) 동시에 뇌관류압의 분자입니다
(`CPP = MAP − ICP`, 낮을수록 나쁨 — 질량효과와 부종으로 ICP가 오를수록,
그리고 병변 자체가 자동조절 능력 `AUTOR`을 깎을수록 더욱).

**어느 방정식에도 U자 곡선이 코딩되어 있지 않습니다.** 그런데 강압 강도를 0에서 1까지
훑으면 U가 나옵니다.

| 강압 강도 | SBP 최저 | 혈종 확장 (mL) | CPP<60 누적 (h) | P(mRS 0-2) |
|---|---|---|---|---|
| 0.000 | 185 | 8.37 | 0.0 | 0.193 |
| 0.250 | 147 | 6.47 | 0.0 | 0.204 |
| 0.500 | 129 | 5.62 | 0.0 | 0.208 |
| **0.625** | **123** | **5.34** | **4.5** | **0.210 ← 최적** |
| 0.750 | 118 | 5.12 | 35.3 | 0.209 |
| 1.000 | 112 | **4.77 (최소)** | 59.9 | 0.201 |

혈종 확장은 **단조 감소**하는데 결과는 SBP 123 mmHg 근처에서 꺾입니다. 최적 SBP 목표가
숫자가 아니라 **상태 의존적**이라는 뜻입니다. 시나리오 4는 그 해로운 팔에 일부러
올려놓았습니다 — 모든 강압 팔 중 **출혈이 가장 적으면서**(4.68 mL) 90일 결과는 시나리오 3보다
**나쁩니다**. `KISCH = 0`으로 두면 용적은 그대로인 채 해악만 사라지므로, U가 관류를 통해
운반된다는 것을 확인할 수 있습니다.

**ICP는 상태변수가 아닙니다.** Monro-Kellie 용적 수지의 잔차입니다.

```
VADD = VHEM + VIVH + OEDE + OEDL + (VCSF − VCSF0) − VCOMPE      (음수면 0)
ICP  = ICP0 · exp(EELAST · VADD)
```

CSF 흡수는 Davson 식(흡수 = (ICP − Pss) × 전도도)을 따르고, 무손상 상태에서 생산
21 mL/h와 정확히 평형을 이룹니다. 압출 가능한 CSF는 18 mL로 유한하므로 압력-용적 곡선이
지수함수가 아니라 **이상(biphasic)** 이 됩니다 — 예비량이 남아 있을 때는 평탄하고,
소진된 뒤부터 급격합니다. 이것이 대상성 소진의 실제 생리입니다.

## 반증 스위치 (Falsification switches)

각 구조적 주장에는 그것을 죽이는 파라미터가 있습니다. `falsify()` 함수로 확인합니다.

| 스위치 | 결과 | 무엇을 증명하는가 |
|---|---|---|
| `KBLEED = 0` | 확장 8.37 → −0.77 mL | 용적 변화가 전부 이 하나의 플럭스에서 나온다 |
| `KTAMP = 0` | 확장 8.37 → 9.73 mL | 탐포네이드가 자기제한성의 원천이다 |
| `KAVAL = 0` | 확장 8.37 → 7.79 mL | 기계적 눈사태가 초기 시간의 민감도를 만든다 |
| `KCHEL = 0` | 철 AUC 48.1 → 68.8 (용적 불변) | DFO의 효과가 **전부** 철 채널을 지난다 |
| `KFERRO2 = KOEDL = 0` | NIHSS 13.3 → 10.0 (용적 불변) | 화학 채널이 실제로 결과를 운반한다 |
| `KISCH = 0` | 시나리오 4의 해악 소멸 (용적 불변) | U자 곡선이 관류를 통해 운반된다 |
| `KOFFA = 0` | 안덱사네트 반동 소멸 | 반동은 해리+재분포의 창발이며 별도 항이 아니다 |

## 개발 중 문헌 때문에 모델을 고친 사례

QSP 모델의 가치는 맞춘 것보다 **틀렸음이 드러나 고친 것**에 있습니다.
초안을 실제로 적분해 보고 다음을 고쳤습니다.

1. **CSF가 음수로 발산했다.** 생산(21 mL/h)에 대응하는 압력 구동 흡수항이 없었습니다.
   Davson 식과 유한한 압출 가능 예비량(18 mL)을 넣자 압력-용적 곡선이 이상(biphasic)이
   되었고, 이는 원래 의도보다 더 나은 생리입니다.
2. **IL-6이 폭주했다.** `IL6`↔`NEU` 되먹임을 선형으로 쓰면 루프 이득이 1을 넘어
   24시간에 사이토카인이 18배로 발산합니다. 양쪽을 포화 함수로 바꾸어야 염증이
   유한하고 스스로 해소되는 펄스가 됩니다.
3. **혈압 효과를 문헌보다 크게 맞춰 놓았다.** 초안 주석은 "확장 35-40% 감소"를
   목표로 적어 두었는데, INTERACT2는 평균 성장 4.5 대 5.3 mL, ATACH-2는 확장
   18.9% 대 24.4%로 실제로는 15-25%입니다. **시험이 얻지 못한 결과를 재현하도록
   맞추는 것**이므로 목표를 문헌 쪽으로 되돌렸습니다.
4. **출혈이 약이 도달하기 전에 끝났다.** `KSEAL = 0.80`이면 출혈이 1.5시간 내에
   종료되어 강압제가 효과를 낼 시간이 없었고, 강압 팔들이 사실상 구분되지 않았습니다.
   출혈 창을 6-12시간으로 늘리자(문헌과 일치) 도달 시간이 의미를 갖게 되었습니다.
5. **니카르디핀이 너무 강력했다.** `EC5NIC = 0.035 mg/L`에서는 3 mg/h가 이미 Emax를
   포화시켜 가이드라인·집중·과도 세 팔이 약리학적으로 동일했습니다.
6. **와파린 출혈이 3.5배로 나왔다** (문헌은 약 2배). `CLOT`을 단일 곱셈항으로 쓰면
   INR이 혈소판 팔까지 함께 깎기 때문입니다. 혈소판 팔(`WPLT`)과 응고 팔(`WFIB`)을
   분리하자 1.74배가 되었고, 부수적으로 PATCH(항혈소판 ICH에서 혈소판 수혈이 해로움)와도
   정합해졌으며 모델에서 혈소판 수혈·DDAVP가 VKA 출혈에 무효인 이유가 생겼습니다.
7. **U자 곡선이 창발하지 않았다.** `CBFISC = 0.55`에서는 관류 채널이 아예 작동하지
   않아 "깊을수록 좋다"가 단조롭게 나왔습니다. 혈종주변 조직은 이미 과소관류
   상태이므로(Zazulia) 손상 개시 문턱은 고전적 경색 문턱보다 **높아야** 합니다.
   0.70으로 올리자 U가 나타났습니다.
8. **사망률을 회복된 상태로 채점했다.** ICH score는 설계상 기저 점수인데 90일 시점
   상태로 계산하고 있었습니다. 24시간 점수 + 누적 두개내압 노출로 바꾸었습니다.

## 한계 (Limitations)

- **개별 환자 예측용이 아닙니다.** 환자 수준 데이터로 적합하지 않았습니다.
  "검증"은 방정식이 안정적으로 적분되고 시험 수준의 방향과 대략적 크기를 재현한다는
  뜻이며, 임상 사용 적합성을 뜻하지 않습니다.
- **재발·장기 이차예방은 ODE에 없습니다.** 90일 지평 밖이므로 지도(클러스터 17)에만
  존재합니다.
- **DNR/치료 중단에 의한 자기실현적 예언**(Becker 2001)은 모든 ICH 시험 해석을
  교란하지만 모델은 이를 지도 노드로만 포함하고 ODE로 구현하지 않았습니다.
  모델의 사망률은 생물학적 궤적만 반영합니다.
- CAA와 고혈압성 병태의 구분은 `LOC`·`SVD` 파라미터 수준이며 Aβ 동역학은 없습니다.
- 혈종주변 뉴런 생존율(`NEUR`)이 90일에 0.12-0.15까지 떨어지는 것은 비관적인
  쪽입니다. 혈종주변 테두리는 실제로 대부분 사멸하지만, NIHSS 매핑 가중치
  (`WNEUR`·`WWM`·`KDEF`)는 환자 데이터로 재적합할 가치가 있습니다.
