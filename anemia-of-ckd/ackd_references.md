# Anemia of Chronic Kidney Disease (ACKD) — References

Curated bibliography supporting the mechanistic map (`ackd_qsp_model.dot`), the
30-compartment mrgsolve model (`ackd_mrgsolve_model.R`) and the Shiny dashboard
in this directory. Organised by the section of the model each group of papers
supports. PubMed links are given directly where a specific PMID was confirmed,
and as a PubMed search query where only the citation (journal / volume / page)
was available — the convention used throughout this library.
