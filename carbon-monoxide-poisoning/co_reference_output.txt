   ANALYTIC FLOOR.  As ATA -> inf, PcO2 -> 760*ATA and PL/VA -> 760*ATA/VA, so

      = 4200/(245 x 0.1407 x 5500) = 0.02215 /min   ->   t1/2_min = 31.3 min
      Depends ONLY on alveolar ventilation, haemoglobin and blood volume.
      Observed ~20 min at 2.5-3 ATA is 36% BELOW this floor:
      CFK is FALSIFIED at hyperbaric pressure.  Reported, not fitted away.
      Corollary: inside a chamber the only remaining lever is ventilation.

   x1 session instead of x3                      Cog 1.000  MBPad 0.424
   x6 sessions instead of x3                     Cog 1.000  MBPad 0.423
  -> either action alone is SUFFICIENT; only removing both loses the benefit.
     Session number is irrelevant in the model: x1 = x3 = x6.
