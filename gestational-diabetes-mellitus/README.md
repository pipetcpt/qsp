## 한 줄 요약

**GDM은 "임신 중 혈당이 높은 상태"가 아니라, 임신 시작과 동시에 함께 돌아가는
두 개의 시계 사이의 경주다.** 태반은 거의 모든 임신에서 동일한 속도로 자라며
대항인슐린 호르몬을 쏟아내 인슐린 감수성을 50-60% 떨어뜨린다. 여기에 맞서
베타세포가 확장·좌측이동으로 보상하는데, 이 보상 능력만이 사람마다 다르다.
따라서 이 모델에서 **GDM 여부는 입력이 아니라 결과**다.

---

## 왜 이 구조인가 (The modelling thesis)

기존의 임신 중 혈당 모델은 대체로 "고혈당"을 입력으로 놓고 태아 결과를
예측합니다. 그러면 치료를 비교할 때 순환논리에 빠집니다 — 혈당을 낮추도록
지정했으니 결과가 좋아지는 것은 당연합니다.

이 모델은 인과의 방향을 뒤집습니다. 환자 수준 파라미터는 두 개뿐입니다:

| 파라미터 | 의미 | 범위 |
|---|---|---|
| `BCAP` | 베타세포 적응 능력 (β-cell adaptive capacity) | 0.25 – 1.20 |
| `BMI` | 임신 전 체질량지수 → 기저 인슐린 감수성 | 18 – 42 |

혈당·인슐린·HbA1c·출생체중·LGA 확률·산후 당뇨 위험은 **전부 출력**입니다.

### 여기서 창발하는 두 가지 결과

**(1) Powe 생리학적 아형이 지정 없이 나타난다.**
maternal 혈당/인슐린 부분계의 GW 40 해석적 고정점 (도출 과정은
`gdm_mrgsolve_model.R` 의 CALIBRATION §D):

| BCAP | BMI | 공복혈당 | 공복인슐린 | 표현형 |
|---|---|---|---|---|
| 1.00 | 22 | ~77 mg/dL | ~14 µU/mL | 정상 (NGT) — 공복혈당이 **떨어진다** |
| 0.85 | 24 | ~87 mg/dL | ~13 µU/mL | 분비결핍형 — 공복은 거의 정상, 부하 후에만 이상 |
| 1.00 | 34 | ~100 mg/dL | ~18 µU/mL | 인슐린저항형 — 고혈당 + 고인슐린 |
| 0.55 | 31 | ~110 mg/dL | ~13 µU/mL | 혼합/중증형 |

같은 진단명 아래 세 가지 다른 공복/인슐린 서명이 나오고, **약물 반응도 달라야
합니다** — 메트포민은 간 쪽(EGP)에, 인슐린은 계 전체에 작용하기 때문입니다.
분비결핍형이 공복혈당만으로는 잡히지 않는다는 것은 모델이 만들어낸 예측이
아니라 구조에서 따라 나오는 결론입니다.

**(2) 정상 임신에서 공복혈당이 떨어지는 현상이 강제되지 않고 나온다.**
인슐린 저항성이 심해지는데도 만삭 공복혈당이 85 → 77 mg/dL로 낮아지는 것은,
자궁태반 포도당 흡수(siphon)가 최대 EGP의 완만한 증가를 앞지르기 때문입니다.
간 포도당 자가조절(`KGEGP`)을 넣지 않으면 모델은 모든 비만 임신에서 명백한
공복 고혈당을 예측하는데, 그건 틀린 예측입니다.

## mrgsolve 모델 (31 ODE)

### 상태변수

| 블록 | 구획 |
|---|---|
| 태반 (7) | `PLAC` `HPL` `PROG` `E2` `TNFA` `ADIPO` `CLP` |
| 모체 대사 (8) | `BCM` `GLU` `INS` `FFA` `MBG` `GUT1` `GUT2` `FATM` |
| 태아 (6) | `GLUF` `INSF` `BCF` `IGF1F` `LEANF` `FATF` |
| 메트포민 (4) | `MGUT` `MCEN` `MPER` `MFET` |
| 인슐린 (2) | `IBAS` `IBOL` |
| 글리부라이드 (3) | `GGUT` `GCEN` `GFET` |
| 안전성 (1) | `HYPOAUC` (모체 저혈당 누적 노출) |

시간축은 **재태일수**(GW 8 → 산후 12주)이며, 분만 시점(`TDEL`)에 태반이
퇴축하면서 태아 블록 전체가 동결되고 대항인슐린 구동이 사라집니다.

### 핵심 방정식 세 개

**대항인슐린 지수 → 인슐린 감수성**
```
CID   = SHPL·hPL + SPROG·(PROG+CLP)/100 + STNF·TNFα + SCORT·PLAC
SI    = SIREF · 1/(1+CID) · exp(−KBMI·(BMI−22)) · 아디포넥틴항 · (1+운동+메트포민)
```
GW 8에서 CID ≈ 0.22, GW 40에서 ≈ 1.48 → SI가 약 49% 감소 (Catalano 관찰치와 일치).

**베타세포 보상 — 질량과 감수성 두 축**
```
dBCM/dt = KPROL·BCAP·[hPL/(hPL+KMH)]·BCM·(1−BCM/BCMMAX) − 소실항(당독성·지질독성·SU부하)
KG50E   = KG50·(1 − KSENS·BCAP·[hPL/(hPL+KMH)])      ← 분비곡선의 좌측 이동
```
사람의 베타세포 질량 증가는 1.4배 정도에 불과하므로(Butler 2010), 적응의
상당 부분을 **기능(좌측 이동)** 으로 분리했습니다.

**태아 — 지방이 탄성 구획, 제지방은 비탄성**
```
dLEANF/dt = KLN·IGF1F·LEANF·(1−LEANF/LNMAX)                        AIGF = 0.20
dFATF /dt = KFT·PLAC³·(1 + AFAT·(INSF/INSFREF−1) + BFAT·(FFA/FFAREF−1))·(LEANF/1000)
                                                                    AFAT = 0.55
```
평균 모체혈당 1 mg/dL 상승당 출생체중 약 +16 g이며, 그 증가분의 약 2/3가
**지방**입니다. 이것이 과성장이 비대칭인 이유이고, 같은 출생체중이라도
GDM 신생아의 견부난산 위험이 다른 이유입니다 (Catalano 2003).

### 보정 목표 (calibration targets)

| 대상 | 관찰값 | 모델에서 대응하는 것 |
|---|---|---|
| HAPO 연속 기울기 | 범주 1 LGA 5.3% → 범주 7 26.3% | `P(LGA) = Φ((BWZ−1.282)/1.0)`; 공복혈당 25 mg/dL 구간에 z 약 0.9 필요 |
| MFMU 치료효과 | LGA 14.5→7.1, 견부난산 4.0→1.5, 전자간증 13.6→8.6, 제왕절개 33.8→26.9 (%) | `PSD0/KSD`, `PCS0/KCS`, `PPE0/KPEG/KPEB` 를 이 쌍들에서 해석적으로 풀었음 |
| MiG | 메트포민군 46%가 보조 인슐린 필요 | 시나리오 S8이 이를 **예측**하도록 구성 (지정하지 않음) |
| Bellamy | 산후 T2DM RR 7.43 | `KDI = 3.8`; DI/DIREF = 0.45 에서 RR ≈ 8 |
| 태반 약물 통과 | 메트포민 U:M ≈ 1.0 / 글리부라이드 cord:M ≈ 0.7 / 인슐린 0 | `KPLM/(KPLM+CLMF) = 0.94` · `KPLG/(KPLG+CLGF) = 0.70` · 인슐린은 **통과항 자체가 없음** |

전체 도출 과정(단위 환산, 손으로 푼 고정점, 각 계수의 출처)은
`gdm_mrgsolve_model.R` 의 `CALIBRATION` 섹션 A–K에 있습니다.

### 10개 시나리오

| # | 시나리오 | 무엇을 보려는 것인가 |
|---|---|---|
| S1 | 정상 임신 기준 | 공복혈당이 **떨어지는** 정상 궤적 |
| S2 | 무치료 GDM · 분비결핍형 | 공복은 정상, 부하 후 이상 — 공복 단독 선별의 실패 |
| S3 | 무치료 GDM · 인슐린저항형 | 고혈당 + 고인슐린 + 높은 FFA + 전자간증 기여 |
| S4 | MNT + 운동 | 탄수화물 양·분배 + 인슐린 비의존(AMPK) 경로 |
| S5 | MNT + 메트포민 | 효과와 **태아 노출**을 같은 화면에서 |
| S6 | MNT + 인슐린 (자동 적정) | 용량이 지정이 아니라 titration 결과 |
| S7 | MNT + 글리부라이드 | 포도당 **비의존** 분비의 모체·태아 양쪽 결과 |
| S8 | 메트포민 → 인슐린 추가 | MiG의 46%를 예측으로 재현 |
| S9 | HAPO 기울기 스윕 | 역치 없는 연속성 — 이 모델의 핵심 검증 |
| S10 | 산후 추적 · 5년 T2DM | 태반이 사라진 뒤 남는 것 |

### 실행

```r
# 모델 컴파일 + 8개 치료 시나리오 + 엔드포인트 표
source("gdm_mrgsolve_model.R")
sims <- run_all()
endpoint_table(sims)

# HAPO 검증 스윕 (BCAP × BMI 격자)
sweep <- hapo_sweep()
plot_hapo(sweep)

# 인슐린 요구량은 적정으로 결정됨 (지정하지 않음)
titrate_insulin(list(BCAP = 0.55, BMI = 31, EXEFF = 0.20), fpg_target = 95)
```

## 이 모델이 하지 못하는 것 (Limitations — 읽어야 하는 부분)

1. **적합(fit)되지 않았습니다.** 개별 환자 데이터가 없고, 파라미터 불확실성
   블록(`$OMEGA`)이 의도적으로 없습니다. 모든 시나리오는 결정론적 단일 개체입니다.
2. **호르몬을 하나로 합쳤습니다.** hPL·프로게스테론·코르티솔·TNF-α는 임상
   데이터로 개별 식별이 불가능하므로 `CID` 하나로 묶었습니다. 따라서 개별
   호르몬의 기여도에 관한 주장은 이 모델로 검증할 수 없습니다.
3. **고혈당에 의한 GLUT1 하향조절을 구현하지 않았습니다** (Hahn 1998).
   극단적 고혈당에서 태아 노출을 과대추정할 수 있습니다.
4. **태아 메트포민은 추적하지만 성장 효과는 0으로 고정했습니다.**
   MiG-TOFU에서 메트포민 노출아의 지방이 더 많았는데, 이 모델이 담고 있는
   자궁 내 기전으로는 그 결과를 예측할 수 없습니다. 항을 켜면 없는 기전을
   조작하는 셈이 되므로, 코드에 보이는 상태로 두고 0을 곱해 두었습니다.
5. **엔드포인트 확률은 기계론적 드라이버 위에 얹은 인구 회귀식**입니다.
   분만 역학·태반형성·신생아 적응 자체의 기전 모델이 아닙니다.
6. **전자간증은 회귀식으로만** 다룹니다. sFlt-1/PlGF는 지도에 그려져 있으나
   미분방정식이 없습니다.
7. 사산·선천기형(이는 GDM보다 임신 전 당뇨의 문제)·신생아 호흡기 결과는
   지도에는 있으나 방정식에는 없습니다.
8. 식후 흡수는 2개 전달구획 근사이고 인크레틴은 상수 증폭이므로,
   경구 vs 정맥 포도당 부하의 차이를 재현하지 못합니다.
