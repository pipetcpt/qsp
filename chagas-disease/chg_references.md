## Note on the numbers used as anchors

The model is calibrated only to values that appear in a published abstract or table,
never to a value read off a figure. Where a trial reports intention-to-treat and
per-protocol figures the intention-to-treat figure is used, because that is the one
a decision-maker would act on. The two calibration constants that carry the most
weight — the dormant-form kill rate of the nitro class (`EMAXCD_N`) and the
per-organism re-establishment probability (`P_EST`) — were fitted to the BENDITA
duration series alone and then used unchanged to predict STOP-CHAGAS, which is a
different trial, a different drug class and a different endpoint.
