## 이 모델이 하는 단 하나의 구조적 주장

> **대동맥을 찢는 것은 혈압이 아니다. 두 항의 곱이며, 두 항은 서로 다른 장기가
> 만든다. 혈관확장제는 첫 항을 내리고 둘째 항을 올린다.**

```
        ASI  =  (σ_FL,sys / σ_ref)   ×   (dP/dt max / dPdt_ref)
                └─ 압력이 들어가는 항 ─┘   └─ 교감신경이 들어가는 항 ─┘
```

- **응력 항**은 라플라스 법칙을 *가강* 외벽에 적용한 것입니다. 박리면은 중막
  외측 1/3을 지나므로 가강 외벽은 「중막 외측 + 외막」뿐이고 두께가 전체 벽의
  40%입니다 (1.90 mm → **0.76 mm**). 같은 압력에서 가강의 원주응력은 진강의
  약 **2.5배**입니다. 이 비대칭은 약이 아니라 해부학이 정합니다.
- **충격량 항**은 좌심실이 만듭니다. dP/dt max는 수축력과 심박수로 정해지며
  평균압은 이 식에 들어가지 않습니다. 그리고 압력이 떨어지면 **압수용체 반사가
  이 항을 올립니다.**

그래서 순수 혈관확장제는 첫 항을 내리고 둘째 항을 밀어 올립니다. "β차단 먼저,
그 다음 혈관확장제"라는 규칙은 **곱에 대한 진술**이고, 따라서 계산할 수 있습니다.

두 번째 주장은 분압기에 관한 것이며, 유명하고 반직관적인 임상 관찰 하나를
산수로 환원합니다:

```
      dP_FL/dt = k·[ G_en·(MAP − P_FL) + G_re·(P_dist − P_FL) ] − (P_FL − 9)/48h
      PP_FL    = PP / √(1 + (ω·τ_FL)²),      τ_FL = 0.30 s / (G_en + G_re)
```

`G_re → 0`이면 **유출이 없으므로 압력강하도 없고**(가강 평균압 = 전신 평균압),
맥압은 저역통과 필터로 사라지므로 **가강 확장기압이 전신 평균압까지 올라갑니다**
— 진강 확장기압보다 높습니다. 원위 정체구역이 응고해 재유입구를 닫는 동안 입구
파열구는 그대로 열려 있습니다. 이것이 **부분 혈전화(partial thrombosis)** 이고,
이 모델에서 가장 나쁜 배치입니다. 이 파일 어디에도 "부분 혈전화는 위험하다"는
항은 없습니다 — **해부학 숫자 두 개**(입구 면적, 재유입 전도도)를 바꿨을 뿐입니다.

## 왜 Python 구현이 함께 있는가 (Provenance)

이 저장소가 빌드된 컨테이너에는 **R 런타임이 없습니다.** 검증되지 않은 ODE
모델을 커밋하는 것보다, 모든 방정식을 Python으로 독립 구현해 실제로 적분하고
그 결과를 함께 커밋하는 것이 정직하다고 판단했습니다.
`aad_mrgsolve_model.R`은 `aad_reference_model.py`로부터 **항 대 항으로 전사된
것**이며 그 반대가 아닙니다.

읽는 사람이 알아야 할 결과: **과학은 적분으로 검증되었고, R 문법은 눈으로만
검증되었습니다.** R 파일을 처음 실행하는 사람은 오타를 고칠 각오를 하십시오.

### 적분이 검증한 것

해석해와 수치해가 독립적으로 일치한 지점이 하나 있습니다. 성장률
`∝ (1 + A·THR)^n · (1 − s·THR)`의 최댓값은
`THR* = (n·A − s) / ((1+n)·s·A)` 이며, n = 1.9, s = 0.85, A = 1.0에서
**0.426**입니다. 201점 수치 스윕의 최댓값은 **0.425**였습니다. 즉 "최악의
가강은 절반만 응고한 가강"이라는 결론은 그림이 아니라 **미분 한 번**입니다.

### 폐쇄회로 적정을 왜 모델 안에 넣었는가

간호사가 목표 혈압에 맞춰 주입 속도를 올리고 내리는 일은 **적분 제어기**입니다.
이것을 모델 밖에 두면 각 팔이 서로 다른 압력에 도달해 버려서, "혈관확장제가
무엇을 대가로 압력을 내리는가"라는 질문 자체를 물을 수 없습니다. 제어기를
방정식으로 넣으면 모든 팔을 **같은 도달 압력에서** 비교할 수 있고, 그때 남는
차이가 이 모델이 말하려는 전부입니다. 제어기가 포화되면(니카르디핀이 표시 상한
15 mg/h에서 SBP 121 밑으로 못 내려가는 것) 그 포화 자체가 결과가 됩니다.

## 사용 (Usage)

```r
library(mrgsolve); library(dplyr)
mod <- mread("aad_mrgsolve_model", "aortic-dissection")

# 지침 순서: 에스몰롤을 심박수 60으로, 그 다음 니카르디핀을 SBP 110으로
mod %>% param(BB_AGENT = 1, BB_MAX = 900, VD_AGENT = 1, VD_MAX = 15) %>%
        mrgsim(end = 72, delta = 0.1) %>%
        plot(SBP + HR + DPDT + ASI + ASI_FLAP + MORTALITY ~ time)

# 같은 압력에 도달한 혈관확장제 단독군과 비교
mod %>% param(VD_AGENT = 1, VD_MAX = 30) %>% mrgsim(end = 72) %>%
        plot(SBP + DPDT + ASI_FLAP + AEN ~ time)

# 만성 5년: 재유입구를 닫아 맹관을 만든다 (부분 혈전화 표현형)
mod %>% param(GRE0 = 0.05, D_MET = 100, D_LOS = 50) %>%
        mrgsim(end = 43800, delta = 24) %>%
        plot(D_AORTA + THRFL + PFL_DIASTOLIC + STRESS_RATIO ~ time)
```

## 이 모델이 재현하되 적합된 적 없는 것

- **부분 가강 혈전화가 가장 나쁘다.** 개통 대비 함의 위험비 **2.36**; Tsai 등이
  IRAD에서 보고한 보정 위험비는 **2.69**. 모델에 넣은 것은 위험비가 아니라
  해부학 숫자 두 개였습니다.
- **혈관확장제 단독은 해롭다.** 표시 상한 니카르디핀은 수축기압을 33 mmHg
  내리면서 dP/dt를 +0.3% 바꾸고, 72시간 파열구 성장은 β차단 우선군의 14배,
  72시간 사망률은 무치료군보다 높습니다. 모든 지침이 "β차단 먼저"라고 말하고,
  이 모델은 그 이유를 계산합니다.
- **작은 입구 파열구는 좋은 예후 인자다.** 9 mm² 입구는 정체 → 완전 혈전화 →
  입구 봉인 → 가강 감압(9 mmHg) → 성장 정지로 이어집니다.
- **진통은 항고혈압제다.** 펜타닐 단독으로 수축기압 −11 mmHg, dP/dt −7%.

## 한계 (Limitations)

- **박동 내(intra-beat) 해상도가 없습니다.** 맥압과 dP/dt는 대수식으로
  재구성됩니다. 판막의 순간 운동, 파동 반사, 국소 전단응력은 이 모델의 언어로
  표현되지 않으며 그런 질문에는 CFD/FSI가 필요합니다.
- **공간 해상도가 없습니다.** 가강은 구획 하나입니다. 근위 개통 + 원위 혈전화가
  같은 대동맥에 공존하는 실제 형태는 "혈전분율"이라는 스칼라로 압축됩니다.
- **TEAR_TH, KGROW, G_re, τ_FL의 절대값은 모델 구성물입니다.** 각 항의 방향과
  비(ratio)는 문헌에 정박했지만, 절대 크기는 결과 보정으로 정했습니다.
- **A형 박리, 대동맥판 역류, 심낭 탐포네이드, 관상동맥 침범은 없습니다.**
  이 모델은 B형 전용입니다.
- **환자 진료에 쓰도록 검증되지 않았습니다.** 교육과 가설 생성용입니다.
