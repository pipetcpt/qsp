## 이 모델이 하려는 말 (Three structural commitments)

교과서적 LCH 모델은 "클론이 증식하고 약이 죽인다"입니다. 그 그림 하나로는 문헌이
동시에 요구하는 여섯 가지를 만족시킬 수 없습니다.

| # | 문헌이 요구하는 사실 |
|---|---|
| i | 같은 BRAF V600E가 한 아이에서는 저절로 낫는 두개골 병변, 다른 아이에서는 치명적 위험장기 질환이 된다 |
| ii | 병변의 Ki-67은 5–10%에 불과한데 임상 양상은 염증 폭풍이다 ([PMID 9588881](https://pubmed.ncbi.nlm.nih.gov/9588881/)) |
| iii | MAPK 억제제는 **며칠 안에** 임상 반응을 만드는데 혈중 BRAF V600E cfDNA는 좀처럼 사라지지 않는다 ([PMID 30718231](https://pubmed.ncbi.nlm.nih.gov/30718231/), [PMID 34383272](https://pubmed.ncbi.nlm.nih.gov/34383272/)) |
| iv | 중단하면 75% 이상이 수주–수개월 내 재활성화된다 ([PMID 31513482](https://pubmed.ncbi.nlm.nih.gov/31513482/), [PMID 28667012](https://pubmed.ncbi.nlm.nih.gov/28667012/)) |
| v | 표적세포가 거의 분열하지 않는데도 클라드리빈이 듣는다 |
| vi | 중추성 요붕증과 신경변성은 비가역이며, 질환이 **얼마나 심했는지**보다 **얼마나 오래 활성이었는지**와 상관된다 ([PMID 16047354](https://pubmed.ncbi.nlm.nih.gov/16047354/), [PMID 15049016](https://pubmed.ncbi.nlm.nih.gov/15049016/)) |

그래서 세 가지 구조적 선택을 했고, 각각에 **kill switch**를 달아 반증 가능하게 두었습니다.

### ① 표현형을 정하는 것은 성장률이 아니라 **기원세포 파티션**이다

변이 전구세포 풀은 하나입니다. 표현형을 구분하는 것은 **기원기술자(origin
descriptors)** 뿐입니다 — `FSR`(드라이버가 발생한 분화단계의 자기재생능),
`PRECM0`(그 크기), 그리고 seeding 파티션 `THB/THS/THR/THP/THC/THL`.

**병변 동역학 상수(`KPROL`·`KDL`·`KIMM`·`KDP`·`KSR`·`LMAX`·`KSEED`·`KDC`)는
표현형 사이에서 단 하나도 다르지 않습니다.**

| 표현형 | FSR | PRECM0 | θ(위험장기) | θ(뇌하수체) |
|---|---|---|---|---|
| SS-b 단일계통 골 | 0.10 | 0.020 | 0.04 | 0.06 |
| MS RO-negative | 0.72 | 0.12 | 0.06 | 0.14 |
| MS RO-positive | 1.00 | 0.45 | 0.34 | 0.08 |
| CNS-risk + 뇌하수체 | 0.85 | 0.25 | 0.10 | 0.30 |
| 성인 폐 LCH | 0.24 | 0.06 | 0.02 | 0.02 |

이 구조는 Berres 2014([PMID 25646268](https://pubmed.ncbi.nlm.nih.gov/25646268/))와
Xiao 2020([PMID 32750121](https://pubmed.ncbi.nlm.nih.gov/32750121/))의
"변이가 발생한 분화단계가 질환 범위를 결정한다"를 그대로 방정식으로 옮긴 것입니다.

**반증:** SS-b 표현형에 MS RO+ 기원기술자만 넣으면 — 어떤 속도상수도 건드리지 않고 —
위험장기 부하가 0.000 → 0.051로 켜집니다.

### ② 병변은 **모집**으로 유지되고, MAPK 억제는 **세포정지성**이다

`KPROL = 0.022/일`은 최소 면역청소율 `KDL + KIMM·(1−TREGMAX) = 0.0288/일` **아래로
일부러** 두었습니다. 따라서 **어떤 병변도 국소 분열만으로는 자립할 수 없고**, 전구세포
풀로부터 계속 공급받아야 합니다. 이것이 낮은 Ki-67의 정량적 내용입니다.

MAPK 억제제는 `CCND`(증식) · `BCL`(생존신호) · `SASP`(분비 프로그램)만 낮추고
**살상항이 전혀 없습니다**(`SL_MAPKI_KILL = 0`). 뉴클레오사이드 유사체·빈블라스틴·
글루코코르티코이드에만 살상항이 있습니다. 그래서 다음이 **가정이 아니라 결과로** 나옵니다:

```
KILL_LES = E_ARAC·PFN + E_VBL·PFN + E_CLAD + EGR_KILL + SL_MAPKI_KILL·(IBRAF+IMEK)
                    └── S기 의존       └── 비분열세포에도 작용 (2-CdA)   └── 0에 고정
```

| 검증된 결과 | 값 |
|---|---|
| 1주차 DAS 하락 vs 병변 질량 하락 | −30% vs −17% (분비체가 먼저) |
| 임상반응/질량감소 비 (MAPKi vs 2-CdA/Ara-C) | 1.65 vs 0.80 |
| MAPKi 12개월 후 cfDNA | 0.282 → 0.014 (검출한계 0.005 **초과** = 여전히 검출됨) |
| MAPKi 12개월 후 저장고 | 기저의 92% 잔존 |
| 같은 기간 2-CdA/Ara-C 후 | cfDNA 검출한계 미달, 저장고 소멸 |
| 중단 후 DAS | 0.08 → 8.75 (재발) |

플래토를 만드는 두 개의 보조 기전:

- **`FN_APO = 0.25`** — 골수 니치는 ERK와 무관한 생존신호를 공급하므로, BCL2A1 상실은
  병변 세포를 저장고 세포보다 훨씬 강하게 자멸로 몰아넣습니다. 그래서 저장고는
  사라지지 않고 **플래토**를 만듭니다.
- **`PNICHE = 0.003`** — 자기재생이 붕괴하는 최소 클론 크기(확률적 클론 소멸의 결정론적
  대용물). MAPK 억제는 여기에 도달하지 못하고, 2-CdA/Ara-C **6주기**는 도달하지만
  **3주기**는 못 합니다.

**여기서 나온 예측:** 용량 강도는 기울기가 아니라 **문턱**을 가집니다 — d500 저장고가
3주기에서 2.2531, 6주기에서 0.000000.

**반증:** `SL_MAPKI_KILL = 0.25`로 두면 중단 후 재발이 사라집니다(비 108.7 → 0.0) —
문헌 (iv)와 정면 모순.

### ③ 영구 후유증은 최대치의 함수가 아니라 **활성 질환의 시간적분**이다

`AVPN`(AVP 분비 뉴런) · `ANTPIT` · `NEUR`(소뇌/뇌교 뉴런) · `BILF` · `LUNGC`는 모두
**단조 감소/증가**하며 회복항이 없습니다. `AVPN < 0.15`에서 중추성 요붕증,
`NEUR < 0.70`에서 임상적 신경변성을 선언합니다.

```
dAVPN/dt = −KAVP·(LPIT/LREF)·√(IL1B/IL1B0)·AVPN        (양수가 될 수 없음)
dNEUR/dt = −KND·[(LCNS/LREF) + W_CDI_ND·1{CDI}·(LCNS/LREF + 0.15)]·NEUR
```

같은 환자, 치료 시작 시점만 바꾼 두 시나리오(S9 vs S9b):

| | 14일에 치료 | 180일 지연 |
|---|---|---|
| AVP 뉴런 풀 (d730) | 0.872 | **0.001** |
| 중추성 요붕증 | 없음 | **영구** |
| 뉴런 풀 | 0.962 | 0.211 |
| 활성 질환 일수 `TTET` | 14일 | 185일 |

**그리고 모델은 교차점을 계산합니다.** "느리지만 깊은" 세포독성 요법이 "빠르지만 얕은"
세포정지성 요법에 CNS 엔드포인트에서 지는가? 현재 보정값에서는 **둘 다 진단 시점에
시작하면 교차가 없습니다**(깊은 쪽 AVPN 0.929 vs 빠른 쪽 0.878). 교차는 세포독성 요법을
**15일 지연**했을 때 처음 나타납니다. 모델은 이 경계를 가정하지 않고 계산합니다.

Python(RK4, numpy 불필요)으로 재구현하고 51개 정량 검증을 수행합니다.

```
51 / 51 checks passed
```

포함 항목:

- **PK 타당성** — 소아 베무라페닙 Css 22.3 mg/L, 트라메티닙 저점 9.4 ng/mL,
  자가유도로 노출 감소, 병용 시 pERK 15.3% vs 단독 18.6%
- **자연사** — SS-b는 자연 소실하고 재골화하며 요붕증이 없음, MS RO+는 위험장기
  부하가 증가하고 요붕증·담관 섬유화가 발생
- **구조적 선택 ①②③ 전부와 각각의 kill switch**
- **약력학적 구분** — 클라드리빈 살상은 세포주기에 gate되지 않음, CNS 침투 제한으로
  CNS 병변이 전신 병변보다 덜 반응(d30에 기저의 CNS 0.62 vs 위험장기 0.10 잔존)
- **독성** — 2-CdA/Ara-C에서 4등급 호중구감소(nadir 0.05 × 10⁹/L)와 다음 주기 전 회복,
  빈블라스틴/프레드니솔론은 훨씬 경미(nadir 2.52), MEK 억제제 LVEF 최저 54.8%
- **수치 위생** — 2년 시뮬레이션에서 음수 상태 없음, 적분 스텝 절반으로 DAS 변화
  < 10⁻⁷

## 이 모델이 주장하지 않는 것 (Explicit limitations)

- 현재 보정값에서 **세포독성 요법이 MAPK 억제제보다 느리지 않습니다**(DAS 통제까지
  5.5일 vs 21.0일). 따라서 둘을 동시에 시작하면 CNS 엔드포인트 교차가 없습니다. 교차는
  세포독성 요법을 15일 이상 지연했을 때만 나타납니다. 모델은 이 경계를 **계산**하며,
  가정하지 않습니다.
- `IL17ON`으로 켜고 끌 수 있는 IL-17A/수지상세포 융합 경로는 문헌상 **논쟁 중**입니다
  ([PMID 18157139](https://pubmed.ncbi.nlm.nih.gov/18157139/) vs 반론). 기본값은 켜져
  있으나 끄면 골파괴세포 출력이 감소하는 것으로 그 기여가 국한됨을 확인할 수 있습니다.
- `PNICHE`(클론 소멸 문턱)는 확률적 소멸을 결정론적으로 대치한 것입니다. 실제로는
  잔존 클론 크기에 따른 재발 **확률**이며, 문턱이 아니라 분포입니다.
- 병변 부하 단위(burden unit)는 임의 척도입니다. cfDNA도 실제 VAF(%)가 아니라 모델
  내부 신호이며, 임상 해석은 검출한계(`CF_LOD`) 대비 상대값으로만 하십시오.
- 면역 청소(`KIMM`)와 Treg 확장은 전신 총 부하로 구동되는 단일 항입니다. 장기별 국소
  면역 미세환경 차이는 표현하지 않습니다.
- 방사선치료, 국소 스테로이드 주입, 데노수맙, PD-1 차단, HSCT는 지도에는 있으나
  ODE로는 구현하지 않았습니다.
