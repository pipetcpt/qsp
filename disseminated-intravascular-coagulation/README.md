## 이 모델이 답하려는 질문

DIC는 교과서에서 늘 두 얼굴로 서술됩니다. 패혈증에서는 미세혈전이 장기를
망가뜨리고, 급성 전골수구성 백혈병(APL)에서는 환자가 뇌출혈로 죽습니다.
같은 이름을 붙여 놓고 정반대의 일이 벌어지고, 그래서 치료도 정반대입니다 —
한쪽에는 항응고제를, 다른 쪽에는 지혈제를 씁니다.

그런데 **왜** 정반대가 되는가. 흔한 설명은 "소비성 응고병증이 진행하면
결국 인자가 고갈되어 출혈로 넘어간다"는 시간 순서 이야기입니다. 이 설명은
틀렸습니다. 패혈증성 DIC 환자는 며칠이 지나도 대개 출혈하지 않고, APL
환자는 첫날부터 출혈합니다.

이 모델은 그 답을 **가정하지 않고 산술로 유도되도록** 설계했습니다.
49개 미분방정식은 두 표현형에 대해 **완전히 동일**합니다. 달라지는 것은
파라미터 **네 개**뿐이며, 그 네 개는 서로 독립적인 **두 개의 시계**를
설정합니다.

## 구조적 결정 — 하나의 소비 과정, 두 개의 독립적인 시계

이 모델의 전체 구조는 다음 한 문장입니다.

> DIC는 조직인자가 구동하는 **하나의** 트롬빈 생성·소비 과정이며,
> 임상 표현형은 그 과정을 **두 개의 독립적으로 설정된 시계**를 통해
> 읽은 결과다.

모든 응고 단백은 **같은** 분율 소비율 `KCONS = KC0·THR/(KTHRC+THR)` 로
소비됩니다. 소비 쪽은 공통입니다. 갈리는 것은 **합성 쪽**과 **청소 쪽**입니다.

## CLOCK 1 — 급성기 항의 **부호**

간의 합성 항에 IL-6가 곱해집니다. 그런데 부호가 단백마다 다릅니다.

```
섬유소원      합성 × (1 + APOSF · APF)        ← 양성 급성기 단백
안티트롬빈    합성 ÷ (1 + ANEGAT · APF)       ← 음성 급성기 단백
protein C     합성 ÷ (1 + ANEGPC · APF)       ← 음성 급성기 단백
유리 protein S 합성 ÷ (1 + ANEGPS · APF)      ← C4BP 상승 경유
```

`APF = ΔIL-6/(KIL6 + ΔIL-6)` 하나가 두 방향으로 작용합니다.
48시간 시뮬레이션에서 **두 표현형의 소비율은 사실상 같습니다**
(패혈증 KCONS = 0.0184/h, APL 0.0204/h — APL이 오히려 약간 높습니다).
그 같은 소비율에 각자의 급성기 항을 곱해 정상상태를 풀면:

```
섬유소원_ss = kd·FIB0·(1 + APOSF·APF) / (kd + KCONS·WFIB + 섬유소원용해)

패혈증  IL-6 1400 pg/mL → APF 0.777 → 합성 ×3.33
        0.00693 × 300 × 3.33 / (0.00693 + 0.0184 + 0.0002) = 272 mg/dL
APL     IL-6  240 pg/mL → APF 0.370 → 합성 ×2.11
        0.00693 × 300 × 2.11 / (0.00693 + 0.0204 + 0.0212) =  91 mg/dL
```

**거의 같은 소비율에서 272 mg/dL 과 91 mg/dL.**

두 시계가 각각 절반씩 기여합니다. APL의 섬유소원용해 항(0.0212/h, CLOCK 2가
만든 것)을 빼면 APL의 정상상태는 161 mg/dL이 됩니다. 반대로 APL의 CLOCK 2는
그대로 두고 급성기 항만 패혈증 값으로 바꾸면 91 → 143 mg/dL이 됩니다.
곧 **272 → 161 은 CLOCK 1이, 161 → 91 은 CLOCK 2가** 만든 차이입니다.

- 패혈증 환자는 **브레이크는 풀렸는데 기질은 계속 보충되는** 상태입니다.
  → 억제되지 않은 트롬빈 + 정상 섬유소원 = **미세혈전**, 출혈이 아닙니다.
- APL 환자는 브레이크도 기질도 없습니다. → **출혈**.

**패혈증성 DIC가 출혈하지 않는 이유는 섬유소원이 양성 급성기 단백이기
때문입니다.** 이것은 모델에 넣은 규칙이 아니라 방정식에서 나온 결과입니다.

### CLOCK 1의 두 번째 결과 — ISTH 점수가 왜 놓치는가

ISTH overt-DIC 점수는 섬유소원에 **100 mg/dL 미만일 때만** 1점을 줍니다.
그런데 위 산술에 따르면 패혈증 환자의 섬유소원은 거기까지 내려가지 **않습니다**.
시뮬레이션에서 24시간 시점을 보면:

| | 값 | ISTH | SIC |
|---|---|---|---|
| 혈소판 | 135 ×10⁹/L | 0점 | 1점 |
| D-이합체 | 4.3 mg/L | 2점 | (항목 없음) |
| PT 연장 | +2.4 s (INR 1.202) | 0점 | 1점 |
| 섬유소원 | 281 mg/dL | **0점** | (항목 없음) |
| SOFA | 4.3 | (항목 없음) | 2점 |
| **합계** | | **2점 (비명백)** | **4점 (SIC 확정)** |

같은 환자, 같은 시각에 ISTH는 "명백한 DIC 아님"이라 하고 SIC는 이미
"응고병증 있음"이라 합니다. 그런데 이 시점에 이미 침착 피브린 `FDEP`은
0.88 AU (48시간 값의 68%) 이고 SOFA는 4.3 입니다.

**SIC 점수가 섬유소원을 의도적으로 뺀 이유가 방정식에서 나옵니다.**
모델에게 "ISTH는 민감도가 낮다"고 알려준 적이 없습니다. 두 점수를
상태벡터의 **출력**으로 계산했더니 그렇게 나왔습니다.

## CLOCK 2 — PAI-1 : t-PA 의 **몰비**

t-PA와 PAI-1은 1:1로, 사실상 비가역적으로 결합합니다. 그러므로 중요한 것은
각각의 농도가 아니라 **몰비**입니다. 분자량이 다르므로(t-PA 68 kDa,
PAI-1 45 kDa) ng/mL 단위로는 이 비가 보이지 않습니다.

```
t-PA   nM = ng/mL × 0.0147
PAI-1  nM = ng/mL × 0.0222 × (활성 분율 0.60)

유리 t-PA = t-PA_nM × [ FLOC + (1−FLOC)/(1 + PAI-1_nM/KPAI) ] × 아넥신A2 증폭
```

시뮬레이션 48시간 값:

| | t-PA | PAI-1 | **몰비** | **유리 t-PA** |
|---|---|---|---|---|
| 정상 | 5.0 ng/mL | 20 ng/mL | 6.0 : 1 | 0.0336 nM |
| **패혈증 DIC** | 20.2 ng/mL | **564 ng/mL** | **42.1 : 1** | **0.0222 nM** |
| **APL** | 20.9 ng/mL | 53 ng/mL | 3.9 : 1 | **0.2882 nM** |

**패혈증에서 총 t-PA는 4배로 올랐는데 유리 t-PA는 정상의 0.66배로
떨어졌습니다.** 이것이 "fibrinolytic shutdown"의 정량적 정체입니다.
t-PA를 재는 것은 아무 의미가 없고, **비를 재야** 합니다.
APL의 유리 t-PA는 패혈증의 **13배**입니다.

### CLOCK 2의 결과 — tranexamic acid의 부호가 저절로 뒤집힌다

TXA는 방정식에 **딱 한 군데**, 한 가지 부호로 들어갑니다:

```
vPLN = ( KPG · 유리tPA · PLG · FSURF  +  uPA항 ) × TXAI ,    TXAI = 1/(1 + C_TXA/IC50)
```

이 항 하나가 두 표현형에서 정반대의 임상 결과를 냅니다.

| | 패혈증 (shutdown) | APL (hyperfibrinolysis) |
|---|---|---|
| 플라스민 | 0.30 → 0.07 nM | 2.32 → 0.70 nM |
| 섬유소원 | 245 → 245 mg/dL (변화 없음) | 101 → 138 mg/dL (**개선**) |
| 침착 피브린 FDEP | 1.29 → **1.59** (악화) | 0.19 → **0.51** (악화) |
| 출혈지수 | 0.71 → 0.59 | 0.98 → 0.94 |
| 28일 사망률 | 43.3% → **51.1%** | 32.8% → **36.2%** |

패혈증에서는 이미 0에 가까운 섬유소용해를 마저 꺼버려 재고가 늘어납니다.
APL에서는 섬유소원이 회복되지만, 동시에 피브린 재고도 늘어납니다.

모델은 **APL에서도 TXA가 순이익을 내지 못한다**고 예측합니다. 이는
Avvisati의 무작위 시험(이익 없음)과 ELN 권고(항섬유소용해제를 일상적으로
쓰지 말 것, 특히 ATRA 병용 시 혈전 위험)와 일치합니다. ATRA에 TXA를
얹은 시나리오에서는 28일 사망률이 7.5% → 21.8% 로 **악화**합니다.

## 임상시험이 그렇게 읽히는 이유 — 세 개의 곱

### 곱 (1) 헤파린은 **촉매**이고, AT 항은 **포화**한다

교과서적 주장은 "DIC에서 AT가 떨어지므로 헤파린이 안 듣는다"입니다.
이것을 선형으로 쓰면(효과 ∝ AT) AT 40%에서 효과가 40%로 떨어지는데,
이는 임상적으로 관찰되는 것보다 훨씬 큽니다.

실제 화학은 촉매 반응입니다. 헤파린 한 분자가 여러 번의 AT-트롬빈 반응을
매개하고, AT에 대해 Michaelis-Menten으로 포화합니다. 그래서 모델은
이렇게 씁니다:

```
트롬빈 불활성화 = KATII × [ AT                      ← 자발반응, AT에 선형
                          + (AMP−1) × ATcat ]       ← 헤파린 촉매, AT에 포화
        ATcat = AT/(KMAT + AT) × (KMAT + 1),   KMAT = 0.25
```

| AT 활성 | 헤파린 없음 | UFH 0.5 IU/mL | 배수 이득 |
|---|---|---|---|
| 100% | 2.20 /h | 17.73 /h | 8.1× |
| 60% | 1.32 /h | 15.02 /h | 11.4× |
| **40%** | 0.88 /h | **12.83 /h** | 14.6× |
| **220%** | **4.84 /h** | 22.27 /h | 4.6× |

여기서 두 가지가 한꺼번에 나옵니다.

1. **AT 40%에서 헤파린의 천장은 정상 AT 천장의 72%** 입니다. 68%가 아니라
   72%. 용량을 올려도 회복되지 않는 **천장** 손실이지 역가 손실이 아닙니다.
   그리고 그 크기는 선형 모델이 말하는 40%보다 훨씬 작습니다 — 임상근거가
   "AT 결핍이 헤파린 저항성의 유일한 원인은 아니다"라고 말하는 것과 정합합니다.
   (모델은 PF4·히스톤에 의한 비-AT 저항성 항 `KHEPN`도 따로 갖고 있습니다.)

2. **AT를 220%까지 올려도 헤파린 팔에서는 +26%밖에 못 법니다.**
   그런데 **촉매되지 않는 자발 팔에서는 60% → 220%가 3.7배**입니다.

곧, **안티트롬빈 보충은 헤파린이 무의미하게 만들어 버리는 바로 그 팔을
통해 작동합니다.** 헤파린을 같이 주면 AT 보충의 추가 이익이 줄어들 수밖에
없습니다. 이것이 KyberSept가 전체에서는 음성이고 **헤파린 비병용 아군에서만**
양성이었던 이유의 산술적 후보입니다. 시뮬레이션에서도 AT 농축제의 증분은
헤파린 없이 −7.3%p, 헤파린 병용 시 −5.3%p 이고, 병용군의 출혈 부담이 더
큽니다.

### 곱 (2) APC 생성은 **네 항의 곱**이다

```
APC 생성 = KPCA × [트롬빈] × TM × EPCR × [protein C]
```

패혈증성 DIC 48시간 시뮬레이션 값:

```
TM 0.318  ×  EPCR 0.559  ×  protein C 0.333  =  0.059
```

**정상의 5.9%.** 그리고 단위 트롬빈당 생성되는 APC는 정상 대비 **16.6배**
감소합니다 (0.636 → 0.038 nM APC per nM 트롬빈). 세 개의 분수가 곱해지기 때문에, 어느 하나도 치명적으로
낮지 않은데 결과는 치명적입니다.

이것이 protein C를 보충하는 대신 **APC 자체를 주는** (drotrecogin alfa)
약리학적 논리입니다 — 세 항을 전부 우회하니까. 시뮬레이션에서 조기
drotrecogin alfa는 43.3% → 37.4% (−5.9%p) 로, PROWESS의 −6.1%p 와
거의 같습니다.

### 곱 (3) 지혈 실패도 곱이므로 **가장 나쁜 항이 지배**한다

```
지혈능 = (1−h_혈소판)(1−h_섬유소원)(1−h_PT)(1−h_용해)(1−h_약물)
출혈지수 = 1 − 지혈능
```

ATRA를 받고 있는 APL 환자에 무엇을 더할지 비교하면(48시간, 시나리오 O/P/R):

| | 혈소판 | 섬유소원 | h_혈소판 | h_섬유소원 | h_용해 | **출혈지수** | 28일 사망률 |
|---|---|---|---|---|---|---|---|
| O · ATRA만 | 33 | 108 | 0.664 | 0.416 | 0.784 | 0.966 | 7.5% |
| P · + 섬유소원 농축제 | 32 | **218** | 0.675 | **0.103** | 0.840 | 0.961 | 9.2% |
| R · + 혈소판 수혈 | **54** | 105 | **0.397** | 0.435 | 0.788 | **0.944** | **6.7%** |

섬유소원을 108 → 218 mg/dL 로 두 배 올리면 `h_섬유소원`은 0.416 → 0.103 으로
**4배 좋아지는데 출혈지수는 0.966 → 0.961 로 거의 움직이지 않습니다.**
곱의 다른 항(`h_혈소판` 0.67, `h_용해` 0.78)이 그대로이기 때문입니다.
반면 혈소판을 33 → 54 로 올리면 출혈지수가 0.966 → 0.944 로 더 많이
움직이고 사망률도 가장 낮습니다.

**가장 나쁜 변수를 먼저 고쳐야 한다**는 임상 격언이 곱셈에서 나옵니다.

덧붙여 P행은 모델의 예측 중 임상적으로 논쟁적인 것입니다: 섬유소원만
보충하면 출혈은 거의 개선되지 않는데 트롬빈이 구동하는 과정에 기질을
공급하는 셈이 되어 침착 피브린이 0.19 → 0.30 으로 늘고, 순사망률이
7.5% → 9.2% 로 오히려 나빠집니다. 이것은 검증된 결과가 아니라
**반증 가능한 모델 예측**으로 읽어야 합니다.

## 재고(stock)와 속도(rate)는 다른 상태변수다

모델은 피브린을 **두 개**의 상태로 나눕니다.

```
침착 속도   vDEP = KDEP · THR^1.5/(KTHD^1.5 + THR^1.5) · (FIB/FIB0)     ← 속도
침착 재고   dFDEP/dt = vDEP − KLYS·PLN_eff·FDEP − KRES·FDEP             ← 재고
장기 손상   ∝ FDEP                                                      ← 재고가 구동
```

모든 항응고제는 `vDEP`에 작용하고, 장기부전은 `FDEP`가 결정합니다.
그리고 shutdown 상태에서는 `PLN_eff ≈ 0`이므로 재고의 출구가 거의
`KRES` 하나뿐입니다 — 반감기 약 87시간. 재고는 며칠씩 남습니다.

### 그런데 이 구조는 저자의 사전 가설을 **반증했습니다**

저는 이 구조로 PROWESS → PROWESS-SHOCK 를 설명할 수 있으리라 예상했습니다:
"속도에만 듣는 약을 재고가 이미 쌓인 뒤에 주면 소용없다."
투여 시작 시각을 훑어 보면 그렇지 않습니다.

| 투여 시작 | 0 h | 6 h | 12 h | 24 h | 30 h | 48 h | 72 h | 96 h |
|---|---|---|---|---|---|---|---|---|
| 28일 사망률 | 37.8% | 37.4% | 36.9% | **36.1%** | **35.8%** | **35.9%** | 37.3% | 39.1% |

(무투여 43.3%) 이익은 단조 감소하지 않고 **24–48시간에서 최대**가 되며,
72시간을 넘어서야 무너집니다. 최대점은 피브린 침착이 가장 빠른 구간을
따라갑니다. 타이밍은 중요하지만 "너무 늦어서"라는 방향은 아니었고,
따라서 이 모델은 PROWESS-SHOCK를 설명하지 못합니다. 원인은 다른 데
(모집 인구, 병용 스테로이드, 표준치료 향상) 있을 가능성이 큽니다.

이것을 지우지 않고 남겨 둡니다. 모델의 값어치는 만든 사람의 예상을
반증할 수 있다는 데 있습니다.

## 반감기 순서가 만드는 것 — 그리고 만들지 않는 것

| 단백 | 반감기 | 소비 하에서의 시상수 τ | 48시간 시뮬레이션 값 |
|---|---|---|---|
| **protein C** | **6 h** | **7.5 h** | **33%** |
| 인자 VII | 5 h | 6.7 h | 71% |
| 인자 VIII | 10 h | 10.7 h | **123%** (급성기 상승) |
| 인자 V | 15 h | 14.1 h | 51% |
| 유리 protein S | 42 h | — | 39% |
| 인자 X | 40 h | 28.8 h | 51% |
| 프로트롬빈 | 65 h | 35.6 h | 48% |
| 안티트롬빈 | 65 h | 49.8 h | 60% |
| 섬유소원 | 100 h | 39.6 h | 245 mg/dL (**정상**) |
| 혈소판 | 200 h | ~20 h | 78 ×10⁹/L |

protein C는 τ = 7.5시간이므로 **약 22시간 만에 바닥에 도달**합니다.
안티트롬빈은 τ가 50시간, 섬유소원은 40시간이고, 섬유소원은 그마저 급성기
합성이 밀어 올려 정상 범위를 벗어나지 않습니다.

**그래서 항응고 브레이크는 응고 기질이 고갈되기 훨씬 전에 무너집니다.**
"소비가 진행되어 나중에 출혈로 넘어간다"는 서사가 패혈증에서 성립하지
않는 이유입니다. 흥미롭게도 안티트롬빈의 감소는 대부분 **소비 때문이 아닙니다.**
48시간 시점에서 AT 손실 경로를 분해하면 정상 turnover 0.00642/h, 글리코칼릭스
손상에 따른 모세혈관 누출 0.00568/h (정상 turnover와 맞먹는 크기), 엘라스타제
분해 0.00091/h 이고, 여기에 합성이 ×0.865로 억제됩니다. 트롬빈 불활성화에
따른 화학량론적 소비는 이들보다 작습니다. **헤파린이 닿을 수 있는 항은
그중 가장 작은 것 하나뿐입니다** — 그리고 헤파린은 하필 그 항을 키웁니다.

## 검증 (Verification)

mrgsolve 모델의 49개 ODE 전부를 **독립적으로 Python/scipy(LSODA)로
재구현**하여 28일간 적분했습니다. 이 과정에서 다음 결함들이 드러나
수정되었습니다.

1. **정상상태가 정상상태가 아니었음.** 초기 구현에서는 자극이 전혀 없는
   "정상" 환자의 섬유소원이 24시간 만에 300 → 25 mg/dL 로 붕괴했습니다.
   원인은 병적 구동항들이 baseline 값 자체에 반응하고 있었던 것
   (`fTNF = TNF/(K+TNF)` 가 TNF=10에서 이미 0.077). 모든 구동항을
   **baseline 위의 증분**에 대해 다시 쓴 뒤에야 정상 상태가 정지했습니다.
   현재: 28일간 어떤 상태변수도 1.2% 이상 표류하지 않습니다 (최대 표류는
   혈소판 250→247).

2. **APC가 측정되는 zymogen을 파괴하고 있었음.** APC가 FV/FVIII **자이모겐**
   구획을 직접 소비하도록 쓰여 있어, drotrecogin alfa 투여 시 PT가 32초까지
   치솟았습니다. 실제 APC는 활성화된 **FVa/FVIIIa 보조인자**를 불활성화합니다.
   prothrombinase/tenase 항에 `APCF = 1/(1 + APC/KIAPC)` 를 곱하는 구조로
   바꾸자 PT 폭주가 사라지고, 동시에 APC가 실질적 항응고 효과를 갖게 되어
   rTM 시나리오의 부호가 뒤집혔습니다.

3. **활성 TAFIa 반감기를 14배 과대설정.** `KDTAFI = 0.30/h` (t½ 2.3시간)로
   두었으나 실제 TAFIa는 t½ 약 10분입니다. 아울러 ART-123은 세포외 D1-D2-D3
   단편이라 protein C는 잘 활성화하지만 TAFI는 잘 활성화하지 못하는데
   (효율계수 `FTAFIS`), 이를 0.25로 과대 설정하고 있었습니다. 두 값을
   바로잡기 전까지 모델은 **트롬보모듈린 알파가 사망률을 높인다**고
   예측했습니다 — SCARLET과 부호가 반대. 수정 후 사실상 중립(+0.5%p)이
   되어 SCARLET의 음성 결과와 맞습니다.

4. **헤파린-AT 관계를 선형으로 쓰고 있었음.** 그 결과 AT 농축제 + 헤파린
   병용이 사망률을 43% → 1.3% 로 낮추는 비현실적 결과가 나왔습니다.
   헤파린이 **촉매**이며 AT 항이 포화한다는 화학을 반영(위 "곱 (1)")한 뒤
   현실적인 크기로 내려왔습니다.

5. **출혈 위험도 지표에 상단 동적범위가 없었음.** `BIDX = 1 − Π(1−hᵢ)` 는
   1에 포화하므로, APL에서 "출혈이 많이 줄었다"를 표현할 수 없었습니다.
   위험도를 `−ln Π(1−hᵢ)` (결손의 가산 척도)로 옮겨 해결했습니다.

## 이 모델이 틀린 곳 (정직한 기록)

| 항목 | 임상시험 | 모델 | 판정 |
|---|---|---|---|
| drotrecogin alfa 조기 | PROWESS −6.1%p | −5.9%p | 일치 |
| AT 농축제, 헤파린 비병용 | KyberSept 아군 −5.8%p | −7.3%p | 일치 |
| AT 농축제 + 헤파린 | KyberSept 0%p, 출혈 22.0 vs 12.8% | 증분 −5.3%p, 출혈 증가 | 방향만 일치 |
| 트롬보모듈린 알파 | SCARLET −2.6%p (p=0.32) | +0.5%p | 일치 (둘 다 중립) |
| APL의 ATRA | 조기 출혈사 2/3~3/4 감소 | 32.8% → 7.5% | 일치 |
| APL의 항섬유소용해제 | 이익 없음, ATRA 병용 시 혈전 | 7.5% → 21.8% (해로움) | 일치 |
| **미분획 헤파린** | **메타분석상 잘해야 수 %p** | **−15.0%p** | **불일치** |

**UFH 항이 이 모델의 가장 노출된 예측입니다.** 반증 가능한 가설로 읽어야
하며, 결과로 인용해서는 안 됩니다. 빠져 있을 가능성이 가장 큰 기전은
(i) 이미 손상된 장기로의 헤파린 유발 출혈, (ii) DIC에서 aPTT/anti-Xa
모니터링이 어려워 실제 임상에서는 목표 노출에 도달하지 못하는 점입니다.

그 밖의 구조적 한계:

- SOFA의 **심혈관 항목이 없습니다.** 혈역학·혈관수축제를 모델링하지 않았으므로
  시뮬레이션 SOFA는 실제보다 최대 4점 낮습니다.
- 응고 캐스케이드는 **집약(lumped)** 되어 있습니다. FIX, FXI, FXII, 칼리크레인은
  지도에는 있지만 ODE에서는 트롬빈 되먹임 항 하나로 압축했습니다.
- `FDEP`는 **임의단위**이며 장기별로 나뉘어 있지 않습니다. 신장/폐/간의
  차이는 손상 민감도 상수로만 표현됩니다.
- 환자간 변이(IIV)와 잔차오차가 없는 **결정론적** 모델입니다. 사망률은
  개인의 확률이 아니라 코호트 평균으로 읽어야 합니다.
- 헤파린 유발 혈소판감소증(HIT)은 지도에는 있으나 ODE에는 없습니다.

## 사용법

```r
# 1) 모델 로드 및 전체 시나리오 실행
source("dic_mrgsolve_model.R")
res <- run_all()
summarise_dic(res) |> dplyr::filter(time == 48)
summarise_dic(res) |> dplyr::filter(time == 672) |> dplyr::select(scenario, MORT)

# 2) 투여 시작 시각 스윕 (PROWESS-SHOCK 가설 검정)
apc_timing_sweep()

# 3) 인터랙티브 대시보드
shiny::runApp("dic_shiny_app.R")

# 4) 지도 다시 렌더링
# dot -Tsvg dic_qsp_model.dot -o dic_qsp_model.svg
# dot -Tpng -Gdpi=150 -Gsize="80,40" dic_qsp_model.dot -o dic_qsp_model.png

# 패혈증 표현형 -> APL 표현형으로 연속 변형
run_dic("sepsis", par = list(SIL6 = 0.10,   # CLOCK 1 끄기
                             SPAI = 0.15,   # CLOCK 2 뒤집기
                             KANX = 3.0,    # 아넥신 A2 증폭
                             MSUP = 0.20))  # 골수 억제
```

사용해서는 안 됩니다. 시뮬레이션된 사망률은 모델 구조와 파라미터의 결과이지
임상 예측이 아니며, 위의 "이 모델이 틀린 곳"에 적힌 불일치를 반드시 함께
읽어야 합니다.
