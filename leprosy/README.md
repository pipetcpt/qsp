## 한 문장 요약

한센병은 **세균지수(BI)라는 하나의 숫자**로 추적·판정되는데, 그 숫자를 지배하는
속도상수는 어떤 약도 건드리지 못하는 것이다 — 이 모델은 BI가 읽는 시계와
약이 돌리는 시계를 분리하고, 거기서 반응(reaction)·클로파지민 로딩·스테로이드
치료창(window)이 모두 산술적으로 따라 나오는 것을 보인다.

---

## 구조적 논지 (Structural thesis) — 두 개의 시계

```
    BI = log10( 살아있는 균 + 죽은 균, per gram )
    MI = 100 × 살아있는 균 / (살아있는 균 + 죽은 균)      "형태지수"
```

죽은 *M. leprae*도 여전히 **항산성(acid-fast) 간균**이다. 대식세포가 소화해야만
사라지고, 그 반감기는 약 4–5개월이다. 따라서

| | 무엇을 읽는가 | 누가 정하는가 | 시간척도 |
|---|---|---|---|
| **시계 1 · 살상** | d(생균)/dt → **MI** | 약 | 수 시간 ~ 수 주 |
| **시계 2 · 제거** | d(사균)/dt → **BI** | 숙주 | t½ ≈ 137일, **약과 무관** |

이 분리에서 네 가지가 유도된다.

### (1) BI는 요법을 비교할 수 없다

| 비교 | 21일째 생균 부담 차이 | 1년째 BI 차이 |
|------|----------------------|---------------|
| MDT-MB (S02) vs 답손 단독 (S06) | **3.83 log10** | 0.24 log10 |
| MDT-MB (S02) vs 살균속도 1/20 (S09) | **3.70 log10** | **0.11 log10** |

살균 속도상수를 20배 낮추어도 1년째 BI는 0.11 log10 움직인다 — 도말검사 판독
오차 안이다. 같은 두 요법을 **MI는 21일째에 갈라놓는다** (0.0014% vs 6.5%).
BI가 천천히 떨어지는 것은 약효 실패의 증거가 아니며, 치료 종료 기준도 아니다.

### (2) 반응(ENL)은 항원의 *수준*이 아니라 *미분값*이 몰고 간다

항원은 균이 **죽을 때**가 아니라 **소화될 때** 면역계에 노출되고, 살아 있는 균은
파고솜 성숙을 능동적으로 억제한다. 그러므로 균집단을 죽이면 **그 순간까지 쌓여
있던 전체 사균 더미의 분해가 한꺼번에 풀린다**:

* 항원 유리 속도: 치료 전 1.56 AU/일 → MDT 시작 후 **3.48 AU/일 (2.2배)**,
  이후 사균 풀과 함께 t½ 137일로 감쇠
* 누적 항원량은 **진단 시 균부담 B₀이 결정**한다 — 살균속도를 20배 바꾸어도
  2,500일 누적값 차이는 15%뿐이며, 그 잔차는 느린 쪽에서 균이 더 증식한 몫이다
* 따라서 약은 **ENL의 정점을 시간축에서 옮길 수는 있어도 면적을 없앨 수는 없다**:
  살균속도 20배 차이가 ENL 정점을 **3.7배** 바꾼다 (S02 44.8 vs S09 12.1),
  같은 BI 궤적 위에서.

모델은 요구하지 않았는데도 고전적 임상 분포를 재현한다. ENL은 `항원유리 × 항체`의
곱이므로 **나종형(LL) 극에서만** 나타나고(LL 정점 44.8 vs TT ~0),
제1형 반응은 `회복된 T세포 기능 × 잔존 신경 항원`의 곱이므로 **경계군(borderline)에서**
최대가 된다(BL이 LL의 4.3배). 두 개의 서로 반대 방향 구배의 곱이다.

### (3) 클로파지민의 항염 작용은 *로딩* 문제다

말단 반감기 70일 → 조직 저장고는 **1개월에 정상상태의 25%, 6개월에 83%**.
즉 막으려던 ENL 정점보다 **늦게 도착한다**. 첫 달에 300 mg/일을 앞세우면
30일째 저장고가 **5.3배** 높아지고, 누적 ENL 부담이 **49% 감소**한다(S10).

> ⚠️ 이 49%는 **이 모델에서 가장 노출된 예측**이다. 어떤 임상시험도
> 이 비교를 수행한 적이 없다.

### (4) 신경: 가역 풀(pool)이 비가역 싱크(sink)로 새어 나간다

```
    d(NFI_가역)/dt = 손상 − 회복(k_rec, 스테로이드 가속) − k_fix·NFI_가역
    d(NFI_영구)/dt = k_fix·NFI_가역          k_fix = 1/180 일⁻¹
```

스테로이드는 **가역 풀에만** 작용한다. 여기서 서로 다른 두 가지가 따라 나온다.

* **기간**: 20주 WHO 감량요법은 52주 코스보다 영구 결손을 **2.4배** 남긴다
  (S12 5.3점 vs S13 2.1점) — Cochrane이 20주 코스의 장기 이득을 확인하지
  못한 것과 같은 방향
* **신속성**: 충분한 기간의 코스라도 늦게 시작하면 소용이 없다.
  구제 가능한 결손의 **절반이 117일 만에 사라지고**, 1년 늦으면 아예
  치료하지 않은 것과 같아진다(S14 10.6점 ≈ 무치료 13.1점의 99%)

## 부산물: 봉쇄 역치 (containment threshold)

낮은 균부담에서 세포매개 살상은 `KHOST × SPEC`이고, 복제하는 클론의 순증식은
`MUMAX − KNAT`이다. 따라서 모델에는 날카로운 면역 설정값 역치가 존재한다:

```
    SPEC* = (MUMAX − KNAT) / KHOST = (0.05545 − 0.01043) / 2.00 = 0.0225
```

* `SPEC > 0.0225` — 잔존 클론을 숙주가 억제한다 → 치료 완료 후 재발하지 않는다
* `SPEC < 0.0225` — 억제하지 못한다 → 재발과 **내성 선택**이 여기서 일어난다

이 역치는 ODE에 대한 이분법 탐색으로 수치적으로 확인된다(대수적 값과 0.7% 일치).
답손 단독요법에서 folP1 돌연변이 클론이 10년에 걸쳐 8.2 log10/g까지 확장되는 것도
(S07), 같은 환자에서 MDT가 그 클론을 덮는 것도 이 역치의 양쪽이다.

## 모델 구조

**38개 ODE 구획**

| 그룹 | 구획 |
|------|------|
| 리팜피신 | `RIFG` `RIFC` `ENZ`(자가유도) |
| 답손 | `DAPG` `DAPC` `NOH`(하이드록실아민) `METHB` `HB` |
| 클로파지민 | `CLOG` `CLO1` `CLO2`(조직 저장고, t½ 70일) |
| 프레드니솔론 · 탈리도마이드 · 2차약 | `PDNG` `PDNC` `THAG` `THAC` `ROMG` `ROMC` |
| 세균 집단 | `BG`(증식) `BP`(지속균) `BR`(내성) `BD`(**사균 — BI를 지배**) |
| 항원 | `AG` `AGN`(신경내) `AGC`(누적) |
| 체액성 · ENL | `AB` `IC` `TNF` `NEU` |
| 세포성 면역 | `CMI` `TREG` |
| 반응 · 신경 | `T1R` `NFIR`(가역) `NFIP`(영구) |
| 서술적 | `LES` `PIG` `HPA` `ALT` `ENLC` |

**핵심 방정식**

```
k_clr  = KCLR0 · (1 + CLRBOOST·(1 − B_live/(B_live+KSUB)))   ← 살아있는 균이 소화를 막는다
방출   = YB·(사망 플럭스) + YD·k_clr·B_dead                    ← YB=0.10, YD=0.90
k_host = KHOST · CMI · KSAT/(KSAT + B_live)                    ← 육아종 봉쇄는 포화한다
CMI 목표 = CMIMAX·SPEC/(1 + B_live/BSUP)·(1 − TREGSUP·TREG)    ← 무반응성은 *생균*이 만든다
ENL    = Hill₄(TNF, 호중구),  면역복합체 = 항원 × 항체
```

`CMI`의 무반응성이 **자유 항원이 아니라 생균 부담**에 걸려 있다는 점이 중요하다.
생균은 유효 살균제 투여 후 며칠 만에 무너지지만 항원 풀은 수년간 남는다 —
그래서 제1형 반응이 **치료 개시 현상**이 되고, 모델에서 67일째에 정점을 찍는다.

## 검증 (Verification)

두 가지 독립적 확인을 거쳤다.

1. **`lep_verify_python.py`** — 38개 ODE 전체를 Python/scipy로 처음부터 다시
   구현하고, 발표된 앵커 54개에 대해 검사한다. **54/54 통과**
   (`lep_verification_output.txt`).
2. **R ↔ Python 교차검증** — mrgsolve 구현과 Python 구현이 361일에 걸쳐
   유효숫자 4자리까지 일치한다 (예: 359일째 `BLIVE` 2.859e-04 vs 2.859e-04).

앵커 예: 리팜피신 Cmax 7.9 mg/L·t½ 4.1 h, 답손 Css 1.63 mg/L·메트헤모글로빈
5.9%, 클로파지민 혈장 Css 0.58 mg/L·조직 저장고 30일에 25%, 미치료 LL의 BI 5.9·
MI 19%, MDT 1년차 BI 감소 0.80 log10, 답손 단독에서 MI 0 도달 181일,
600 mg 1회 리팜피신의 4.0 log10 살상, MDT-MB 12개월 후 재발지수 1.8%.

### 튜닝 과정에서 드러나 고친 결함

* **무반응성을 자유 항원에 걸었던 초기 버전** — 항원 풀은 사균과 함께 수년 감쇠하므로
  세포성 면역이 332일에 걸쳐 완만히 상승했고, 제1형 반응이 급성 삽화가 아니라
  평탄한 고원이 되어 스테로이드 시점 실험이 무의미해졌다. 생균 부담으로 바꾸자
  정점이 67일로 이동했다.
* **신경 손상에 역치가 없던 버전** — 반응 활성 4/100의 잔잔한 꼬리도 신경을 계속
  깎았고, 그 결과 20주 스테로이드가 900일 적분에서 아무 차이를 못 만들었다.
  Hill 역치(T1R50 = 12, h = 5)를 넣자 급성 삽화가 손상을 지배하게 되었다.
* **육아종 봉쇄를 균부담과 무관한 선형항으로 두었던 버전** — 치료 후 LL 환자의
  재발을 막을 만큼 세게 하면 미치료 경계군 환자가 저절로 낫고, 약하게 하면
  모든 LL이 3년 안에 재발했다. 포화항 `KSAT/(KSAT+B_live)`로 두 요구가 동시에
  만족되었고, 부산물로 봉쇄 역치 SPEC*가 나왔다.
* **지속균이 숙주 면역에 너무 잘 죽던 버전** — 6개월 요법과 12개월 요법의 재발
  위험비가 19배로 나왔다(관찰값 ~2배). 휴면 지속균의 면역 회피(PIMM = 0.02)를
  넣어 2.4배로 맞췄다.

### 검증되지 않은 채 남아 있는 것

1. 사균 분해의 탈억제 계수 `CLRBOOST = 2.0` — BI 감소 속도에서 역산한 값이며
   직접 측정된 적이 없다.
2. 클로파지민 로딩의 ENL 49% 감소 — **시험된 적 없는 예측**.
3. 봉쇄 역치 `SPEC* = 0.0225` — 모델 내부 유도값이며 임상적 대응물이 측정된 바 없다.
4. 재발은 결정론적 궤적에서 읽은 확률이 아니라, 치료 종료 시점의 **잔존 생균수**에서
   계산한 포아송 탈출 지수다. 연속 ODE는 수천 마리 집단의 확률적 소멸을 표현할 수
   없기 때문이다.
5. 신경 손상 지수(0–100)는 WHO 장애등급의 형태에 맞춘 것이지 개별 신경전도검사에
   적합시킨 것이 아니다.
