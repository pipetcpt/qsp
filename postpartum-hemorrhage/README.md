# 산후출혈 (Primary Postpartum Haemorrhage) — QSP 모델

**PPH는 응고 질환이 아니다. 임신이 크게 보이도록 만들어 놓은 저장고에 대한
유량(flux) 문제이며, 그 밸브는 기계적이다.**

만삭 자궁혈류는 750 mL/min — 심박출량 7 L/min의 10-15%가, 영양막 재형성으로
자체 평활근을 잃어 **수축할 수 없게 된** 나선동맥 약 120개의 절단면으로 쏟아진다.
임신이 벌어놓은 순환혈액량 증가분은 2100 mL(70 → 100 mL/kg)이므로

> **2100 mL ÷ 750 mL/min = 2.8분**

이것이 임신 전체가 벌어준 시간의 총액이다. 모델의 완전 무긴장 자궁(ATN = 1)은
최대 516 mL/min에 도달하고, **6.0분**에 ATLS class III 문턱(2100 mL)을 넘고
**10분**에 실혈사한다. 이 문서의 모든 치료 관련 주장은 "그 시계를 얼마나 벌어
주는가"에 대한 주장이다.

## 이 모델이 주장하는 것 (아홉 가지, 전부 수치로 유도됨)

### 1. 밸브는 선형이 아니라 Poiseuille이다

태반 부착부의 지혈은 봉합도 응고도 아니고, 근층 다발("**living ligature**")이
혈관을 조여 닫는 기계적 과정이다. 압축된 혈관의 유량은 반지름의 4승에 비례하므로
모델은 `patency = (1 − TONE)^4`로 쓴다.

| 자궁 긴장도 | patency | 누출 |
|---|---|---|
| 0.91 (단단한 자궁) | 6×10⁻⁵ | 0.05 mL/min |
| 0.50 | 0.063 | 47 mL/min |
| 0.20 (물렁한 자궁) | 0.410 | 307 mL/min |

즉 임상에서 말하는 "firm vs boggy"는 수축능의 수 %에 불과한 좁은 띠이며, 모델은
그만큼 **양안정(bistable)** 이다.

| ATN (무긴장 중증도) | 무치료 결과 |
|---|---|
| 0.60 | 2218 mL, 생존, MAP 최저 78 mmHg |
| **0.63** | **70분에 사망 (3544 mL)** |

수축능 3%가 생사를 가른다.

### 2. 응고는 기계가 작동하기 전까지 잠겨 있다

혈전 형성은 전단력으로 게이팅된다: `fSH = 1/(1 + (Q/80)²)`. 그리고 근층이 조여
주지 않는 혈관 위의 혈전은 patency의 35%(`CSEAL0`) 이상을 결코 막을 수 없다.
10분 시점의 모델 값:

| | 누출 | 전단 게이트 | 태반부 혈전 |
|---|---|---|---|
| 정상 | 0 mL/min | 1.00 | → 0.98, 성숙 → 1.00 |
| 중등도 무긴장 | 39 | 0.81 | 0.83 |
| **중증, 무치료** | **168** | **0.19** | **0.22에서 정체** |
| 중증, 치료 | 22 | 0.93 | 0.87 |

그래서 "자궁수축제·탐포네이드가 혈액제제보다 먼저"는 관습이 아니라 **산술**이다.
게다가 지속적 지혈에는 혈전이 저전단 상태에서 **조직화(organise)** 될 시간까지
필요하다(상태변수 `MAT`) — 모든 기계적 처치가 실제로 사들이는 것은 그 시간이다.

### 3. 옥시토신은 자기 표적을 스스로 지운다

OTR은 작용제 노출로 내재화되고(`KDES` 0.08/min, 점유율 구동) t½ 2.6시간으로
회복한다. 유도되는 두 결과:

- 12 mU/min으로 8시간 증강분만 → 정상상태 OTR **0.39** (증강 분만 후 자궁근
  결합부위 30-60% 감소 보고와 일치)
- **치료 자체가 탈감작시킨다**: OTR 1.00에서 시작한 표준 주입이 120분에 **0.09**

증강 분만 후 중증 무긴장 환자(옥시토신+마사지에서 2605 mL)에게 남은 두 수단은
동등하지 않다.

| 수단 | 실혈 | 감소량 |
|---|---|---|
| 옥시토신 2배 | 2462 mL | −143 |
| 옥시토신 4배 | 2328 mL | −277 |
| **카보프로스트 추가 (FP)** | **1680 mL** | **−925** |
| 에르고메트린 추가 (α₁/5-HT₂A) | 1781 mL | −824 |
| 미소프로스톨 추가 (EP2/EP3) | 1953 mL | −652 |

**수용체를 바꾸는 것이 이미 사라진 수용체의 용량을 올리는 것보다 3-6배 가치가 있다.**

### 4. 하나의 파라미터가 치료 사다리 전체를 만든다

`ATN` 하나가 내인성 수축 구동(`DRVI`)과 약물이 밀어붙일 수 있는 **천장**(`CAP`)을
동시에 정한다. 실혈(mL), D@n = n분에 사망:

| ATN | 무치료 | 마사지 | 옥시토신 | 옥시토신+마사지 | 4제 사다리 |
|---|---|---|---|---|---|
| 0.60 | 2218 | 940 | 1078 | 743 | 641 |
| 0.63 | D@70 | 1170 | 1434 | 882 | 741 |
| 0.66 | D@44 | 1504 | 2081 | 1072 | 870 |
| 0.70 | D@30 | 2236 | **D@77** | 1446 | 1102 |
| 0.74 | D@22 | **D@58** | **D@51** | **2054** | 1427 |
| 0.78 | D@18 | D@32 | D@38 | **D@93** | **1877** |
| 0.84 | D@13 | D@19 | D@24 | D@37 | **D@57** |
| 0.90 | D@11 | D@13 | D@16 | D@20 | D@21 |

ATN 0.74 행이 **초가법성(superadditivity)**을 보여준다: 마사지 단독은 58분에,
옥시토신 단독은 51분에 사망하지만 **둘을 함께 쓰면 2054 mL로 생존한다.** 문턱
아래의 두 구동이 합쳐져 문턱을 넘기 때문이다. ATN 0.84 이상에서는 약물 사다리
전체가 문턱에 닿지 못한다 — 이것이 "uterotonic-refractory atony"의 모델 내 정의다.

### 5. 피브리노겐이 가장 먼저 임계선을 넘는다 — 비율 산술로

희석·출혈하는 환자에서 무엇이 먼저 결핍되는지를 정하는 것은 **임계값/초기값의
비율**뿐이다.

| | 임계값 | 만삭 초기값 | 비율 |
|---|---|---|---|
| **피브리노겐** | 2.0 g/L | 4.5 g/L | **0.44 ← 최대** |
| 응고인자(통합) | 0.30 | 1.00 | 0.30 |
| 혈소판 | 50 ×10⁹/L | 250 ×10⁹/L | 0.20 |

crystalloid-first 팔에서 모델이 순서를 확인한다: 피브리노겐은 누적 실혈
**3476 mL**에서 2.0 g/L를 넘고, Hb는 3555 mL에서 7 g/dL를 넘고, 혈소판(최저 71)과
응고인자(최저 0.33)는 **끝까지 임계값에 도달하지 않는다.**

따름정리 — 역시 산술: **FFP는 낮은 피브리노겐을 올릴 수 없다.** FFP의 피브리노겐
농도는 2 g/L이고, 혈장 7 L를 1 g/L 올리려면 7 g = **14 단위 = 3.5 L**의 FFP가
필요하다. FFP의 농도 자체가 수혈 목표치이므로, FFP는 피브리노겐을 어느 쪽에서든
2 g/L **쪽으로** 끌고 간다.

### 6. 순환을 살리는 소생술이 리가처를 망가뜨린다

칼슘은 응고 보조인자이면서 동시에 **평활근의 수축 이온**이다. 그래서 구연산에
의한 이온화 저칼슘혈증은 산과 출혈에 고유한 이중 타격이다. 차가운 제제는 효소와
근육을 함께 식힌다. 그리고 자궁순환이 압력 수동적이므로 결정질 수액으로 MAP를
올리면 **누출도 함께 올라간다.**

| 소생 전략 (ATN 0.88, 4제 + TXA) | 실혈 | 부산물 |
|---|---|---|
| 목표지향 1:1 + 피브리노겐 + 칼슘 + 가온 | **3489 mL** | iCa 1.00, 37.0 °C |
| crystalloid-first, RBC만 | 3953 mL | 피브리노겐 1.37 g/L, 34.6 °C, pH 7.31, 6.2 단위 |
| 대량수혈 중 칼슘 미보충 | +922 mL | iCa 0.45 |
| 대량수혈 중 가온기 미사용 | +2873 mL | 31.8 °C, 16 vs 11 단위 |

**수액 가온기는 지혈 약물이다.**

### 7. TXA의 창(window)은 3시간이 아니다. 출혈의 지속시간이다

TXA는 혈전을 만들지 않는다. 기계가 만들 수 있게 해준 혈전을 **보호**한다. 출혈이
약 40분 지속되는 불응성 환자에서:

| TXA 투여시점 | 실혈 | 이득 |
|---|---|---|
| 미투여 | 4099 mL | — |
| 5분 | 3400 mL | −699 |
| 15분 | 3645 mL | −454 |
| 30분 | 4030 mL | −69 |
| 45 / 90 / 180분 | 4099 mL | **0** |

WOMAN 시험의 3시간 경계는 **분자의 성질이 아니라 그 집단의 출혈 지속시간**이다.
모델은 "15분마다 이득 10% 감소"를 가정하지 않고 플라스민 동역학에서 재유도한다.
(모델 내 플라스민 최대치: 정상 1.0 · 중등도 1.4 · 중증 치료 1.7 · **중증 무치료 4.1**
— 과다섬유소분해는 별개의 질환이 아니라 **유량의 결과**다.)

### 8. 타이밍이 기구를 압도한다

파국적 무긴장(ATN 0.94) + 완전 약물 번들 + 목표지향 소생술:

| 추가 처치 | 실혈 | 결과 | 산소부채 |
|---|---|---|---|
| 없음 | 10044 mL | **80분에 사망** | 1791 mL |
| 풍선 탐포네이드 20분 | **4528 mL** | 생존 | 152 |
| 풍선 45분 | 7617 mL | 생존 | 1195 |
| 풍선 75분 | 10156 mL | **150분에 사망** | 8260 |
| **대동맥 압박 8-35분 → 풍선 35분** | **2782 mL** | 생존, **수혈 0** | **0** |
| 자궁동맥 결찰 50분 | 9624 mL | 생존 | 1527 |
| 자궁절제 60분 | 8451 mL | 생존 | 710 |
| 자궁절제 120분 | 10044 mL | 사망 | — |

**교량 처치(bridge)를 일찍 하는 것이 확정적 수술을 늦게 하는 것보다 낫다.**
장비 없이 몇 초면 되는 대동맥 압박이, 이 모델에서 가장 좋은 단일 수(手)다.

### 9. 헤모글로빈은 가장 마지막에 움직인다

전혈은 농도를 유지한 채로 나가므로, 무치료 실혈사 팔은 **Hb 11.2-11.4 g/dL로
사망한다.** 헤모글로빈을 방아쇠로 삼는 수혈 정책은 구조적으로 늦다. 그래서 모델의
대량수혈 프로토콜은 **진행 중인 실혈**(>1500 mL이면서 누출 >25 mL/min)로
발동한다 — 실제 프로토콜이 하는 방식이다.

### 부록: 나머지 세 개의 T는 대수적으로 독립인 항이다

4T는 감별진단 목록이 아니라 서로에게 보이지 않는 네 개의 항이다.

| 상황 | 자궁수축제만 | 원인 처치 |
|---|---|---|
| 경부 열상 260 mL/min | **79분 사망**; 사다리 전부 추가해도 **80분 사망** | 25분 봉합 → 3794 mL 생존 / 60분 봉합 → 8179 mL |
| 잔류 조직 35% | 4제 사다리에도 **106분 사망** | 30분 수기 제거 → 4407 mL 생존 |
| 내원 시 피브리노겐 1.6 g/L | 2193 mL (최저 0.89) | 2.5 g/L로 보충 → 1677 mL |

**자궁수축제에 반응하지 않는다는 사실은 용량 문제가 아니라 진단 정보다.**

## 모델 구조

41개 ODE 구획, 시간 단위 = 분, 70 kg 만삭 산모, 태반 분만 직후 시점에서 시작.

| 블록 | 상태변수 |
|---|---|
| 약물 PK (10) | `OXY` `CBT` `MSD`/`MSC` `ERD`/`ERC` `PGD`/`PGC` `TX1`/`TX2` |
| 용적·유량 (5) | `V` `CIV` `LOSS` `UO` `ODEBT` |
| 혈액 성분 (4) | `HBM` `FBM` `PLTM` `FCT` — 전부 **질량**이므로 희석이 자동 |
| 자궁 (4) | `TONE` `OTR` `RET` `MECH` |
| 지혈 (5) | `CLT` `CLTR` `MAT` `TPA` `PLS` |
| 내부 환경 (5) | `CIT` `CAI` `TMP` `LAC` `HCO` |
| 제제 카운터 (5) | `RBCU` `FFPU` `PLTU` `FGCU` `CAU` |
| 노출 적분 (3) | `TSEV`(MAP<50) `TAKI`(MAP<65) `XSEV`(Fib<2) |

사망 판정은 임의의 실혈량 규칙이 아니라 **누적 산소부채 120 mL O₂/kg
(= 8400 mL)** 또는 순환혈액량 45% 소실 중 먼저 도달하는 것으로 한다.

### 보정된 것 (6개)

1. `UBF0`와 긴장도→patency 지수 `NP` — 정상 3기 실혈 약 270 mL, 약 5분에 지혈
2. `ATN → (DRVI, CAP)` 사상 — 위 4번의 치료 사다리를 재현하도록
3. `KFORM` `QS50` `CSEAL0` `KMAT` — 저유량 태반부는 15-30분에 지속적으로
   혈전화하고 고유량 태반부는 전혀 혈전화하지 않도록
4. `KDES`/`KREC` — 8시간 증강분만 후 OTR ≈ 0.39
5. `KFDEG`/`KLYS`/`KTPA*` — 중증 PPH에서 피브리노겐 <2 g/L, 플라스민 3-4배
6. 구연산·칼슘·열용량 상수 — 산과 대량수혈에서 이온화칼슘 0.5-0.9 mmol/L,
   가온하지 않은 4 °C 제제 100 mL/min당 약 2.8 °C/h 냉각

### 유도된 것 (반증 가능한 출력)

2.8분의 예비량 · 6분의 class III 도달 · ATN 0.60/0.63 칼날 · 치료 사다리 전체 ·
용량 증량의 무용함과 수용체 교차의 이득 · 피브리노겐 최초 교차와 OBS2 음성 결과 ·
TXA 창 = 출혈 지속시간 · 타이밍 > 기구 · 헤모글로빈이 마지막에 움직인다는 사실.

### 재현된 임상시험 결과

- **WOMAN / Gayet-Ageron IPD** — 이득이 조기 투여에 국한되고 지연과 함께 소멸
- **OBS2 · FIB-PPH** — 피브리노겐이 이미 절벽 위(2.5-4 g/L)일 때 경험적 4 g 투여는
  실혈을 3489 → 3473 mL로 **16 mL** 바꿀 뿐이다. 모델은 이 음성 결과를 재현하고
  이유까지 말한다: 그 지점에서 `fFIB`는 이미 0.94이고 혈전 형성은 피브리노겐
  제한적이지 않다.
- **CHAMPION** — 카베토신과 옥시토신의 예방 효과가 서로 근접(946 vs 1212 mL)
- **Hiippala** — 희석 시 결핍 순서(피브리노겐 최초)
- **Suarez 등** — 풍선 탐포네이드의 성공률과 그 타이밍 의존성

### 숫자의 출처에 대한 고지

이 문서와 `.R` 주석에 인용된 모든 수치는 **동일한 방정식·파라미터의 독립
구현**(순수 python RK4, dt = 0.01분)으로 산출했다. 이 파일들을 작성한 환경에는
R과 mrgsolve가 없었으므로 `pph_mrgsolve_model.R` 자체는 여기서 실행되지
않았다. 재실행 결과가 다르면 **R 출력을 신뢰하고** 차이를 알려주기 바란다.

## 가장 공격받아야 할 세 가지 가정

1. **`NP = 4`** (Poiseuille 밸브). `NP = 2`로 두면 칼날이 사라지고 긴장도는
   너그러운 연속 변수가 되며, 모델은 "firm vs boggy"가 왜 쓸 만한 침상 구분인지
   설명하지 못한다. `NP = 1`이면 정상 3기가 3 L/h를 흘린다. 실제 태반 부착부
   유량-긴장도 관계에 대한 인체 측정은 문헌에 보이지 않는다.
2. **`CSEAL0 = 0.35`** (조여지지 않은 혈관 위 혈전의 한계). 1.0으로 올리면 중증
   무긴장이 자연 지혈되고 불응성 PPH라는 것이 존재하지 않게 된다. 0으로 내리면
   응고 보충이 결코 도움되지 않는다. PPH가 기계적 질환이라는 이 모델의 주장이
   전부 이 한 파라미터에 걸려 있으므로, 측정되어야 할 첫 번째 수치다.
3. **`KREC` (t½ 2.6 h)** — 회복이 훨씬 빠르다면 용량 증량이 통해야 하고 "수용체를
   교차하라"는 조언은 틀린다. 증강/비증강 분만의 자궁근 절편으로 검증 가능하다.
