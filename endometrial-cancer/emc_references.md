# Endometrial Carcinoma (EC) — References

Curated bibliography supporting the mechanistic map, mrgsolve QSP model, and
Shiny dashboard in this directory. Organised by section. PubMed links are given
directly where a specific PMID was confirmed, and as a PubMed search query where
only the citation (not a verified PMID) was available.
