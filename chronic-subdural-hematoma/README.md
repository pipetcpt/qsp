## 이 모델이 말하려는 것 (the structural claim)

만성 경막하 혈종은 보통 **흡수에 실패한 응고물**로 배웁니다. 이 모델은 그렇게 보지 않고
**분비하는 기관**으로 씁니다. 경막측에 신생막이 자라고, 그 미성숙 신생모세혈관이
경막 림프관이 치울 수 있는 속도보다 빠르게 혈장을 경막하 공간으로 여과합니다.
그러면 부피는 감쇠하는 재고가 아니라 **세 항의 균형이 만드는 고정점**이 됩니다.

```
dV/dt  =  J_exudation  +  J_rebleed  −  J_absorption

J_ex  = Lp(N_CAP, N_MAT) · A_mem · [(P_cap − ICP) − σ·(π_plasma − π_cavity)]
J_rb  = k_rb · N_CAP · A_mem · φ_fragility · (1 − H) · MMA_supply
J_abs = (k_lymph·A_mem + k_arach·V) · (ICP − P_sink)
```

나머지 47개의 방정식은 저 세 줄에 정직한 인수를 공급하기 위해 존재합니다.
그리고 **모든 치료는 세 항 중 어디를 건드리는지에 대한 주장**이 됩니다 —
2024–25년 무작위배정 시험들이 서로 어긋나는 이유가 바로 여기 있습니다.

| 치료 | 건드리는 것 | 무엇을 하는가 |
|------|------------|--------------|
| 천공배액 · 배액관 | **STOCK** | 부피를 비운다. Lp·A_mem·N_CAP·안 펴진 뇌는 그대로 남는다 |
| 세척 (irrigation) | **SWITCH** | 공동 내 헴 *농도*를 낮춘다 |
| 개두술 + 막 제거 | **SOURCE** | 막 면적과 격막 자체를 제거한다 |
| **MMA 색전술** | **SOURCE** | 재고는 손대지 않고 공급을 끊는다 → 효과가 *적분*으로 나타난다 |
| 덱사메타손 | J_ex | VEGF·Lp를 낮추고, 전신적으로는 환자를 해친다 |
| 아토르바스타틴 | J_ex | 혈관을 성숙시켜 Lp를 낮추고 σ를 동시에 올린다 |
| 트라넥삼산 | J_rb | 섬유소용해 루프를 끊는다 (단, 유출액에 실려서만 도달한다) |

### 두 개의 닫힌 루프

```
L1   헴 → 대식세포 → VEGF → 미성숙 혈관 → 재출혈 → 헴
L2   미성숙 내피 → t-PA → 플라스민 → FDP → 응고 실패 → 재출혈 → 더 많은 피브린
```

L1의 헴 항에는 Hill 지수 2가 붙어 있습니다. 원래 의도는 그 지수 하나로 질환을
**쌍안정**으로 만들어, "맑아질 때까지 세척한다"를 미용적 조작이 아니라 치유적
조작으로 유도하는 것이었습니다. **보정 후에는 그 의도가 성립하지 않습니다** —
아래 「모델의 성적표」를 반드시 읽으십시오.

### 위축: 같은 파라미터가 반대 부호로 두 번 들어간다

`V_RES`(뇌 위축이 만든 두개내 예비공간)는 모델에 정확히 두 번 등장합니다.

1. **압력과 정중선 전위를 완충한다** → 위축된 환자는 더 큰 혈종을 견디고, 더 늦게,
   더 큰 부피로 발현한다 *(이롭다)*
2. **뇌 재팽창을 늦춘다**, `k_reexp = k₀·exp(−V_RES/λ)` → 배액 후 공간이 남는다
   *(해롭다)*

같은 숫자가 수술 전에는 환자를 지켜주고 수술 후에는 환자를 배신합니다. 모델에서
이 둘을 잇는 다른 항은 없고, 둘 다 하나의 파라미터의 결과입니다. 검증 결과
(§5, `csdh_report.py`):

| V_RES (mL) | 발현까지 (일) | 발현 시 부피 (mL) | k_reexp (/일) | 재수술 확률 |
|-----------:|-------------:|-----------------:|-------------:|-----------:|
| 5  | 21.5 | 44.6  | 0.0776 | 0.000 |
| 20 | 24.2 | 59.1  | 0.0436 | 0.094 |
| 30 | 26.7 | 70.4  | 0.0297 | 0.144 |
| 40 | 31.0 | 82.8  | 0.0202 | 0.159 |
| 60 | 44.3 | 107.4 | 0.0094 | 0.170 |

정중선 전위 8 mm를 발현 기준으로 고정했을 때, 위축이 커지면 **견디는 부피는 2.4배로
늘고**(44.6 → 107.4 mL) **재발 확률은 0에서 17%로 올라갑니다.** V_RES ≈ 20 mL 근처에
문턱이 있고, 그 아래에서는 모델이 모든 환자를 치유합니다.

## 모델의 성적표 (what it reproduces, and what it does not)

> 이 절은 숨기지 않고 씁니다. 모든 수치는 `csdh_reference_output.txt`에서 나오며,
> 그 파일은 `csdh_verify.py`(scipy로 독립 재구현한 같은 50-ODE 계)가 생성합니다.

### 재현하는 것

**자연사가 보정 없이 떨어져 나옵니다.** 얇은 막(12 mL)에서 출발해 신생막이 자라고
팽창하는 과정을 적분하면:

| 항목 | 모델 | 보고된 범위 |
|------|------|------------|
| 외상 → 발현(78 mL) 잠재기 | **33.5일** | 3–8주 |
| 고평부 부피 | 112 mL | 증상성 cSDH 60–130 mL |
| 최대 두께 / 정중선 전위 | 16.5 mm / 10.5 mm | — |
| 공동 단백 | **6.58 g/dL** | 4–8 g/dL |
| 공동 t-PA | 24 ng/mL | 혈장보다 크게 높음 |
| 공동 FDP | 258 µg/mL | 혈장보다 크게 높음 |
| CT 밀도 | 50 HU | 등밀도 만성기 |

공동 단백은 질량수지의 **결과**입니다 — 넣은 값이 아닙니다. 정상 부피에서
`J_ex + J_rb = J_abs`가 성립하므로 공동 단백은 혈장 단백(7 g/dL) 아래로 **묶입니다**.

**MMA 색전술 엔드포인트는 거의 정확합니다**: 180일 치료 실패 **0.044** vs
EMBOLISE의 **0.041**.

**가장 좋은 결과는 보정하지 않은 시간 경과입니다.** 색전술은 STOCK이 아니라 SOURCE를
없애고 기존 신생혈관은 τ ≈ 5–9일로 감쇠하므로, 효과는 사건이 아니라 **적분**입니다:

| 시점 | 수술만 P(재수술) | +MMAE | 절대 위험 감소 |
|-----:|----------------:|------:|--------------:|
| 14일 | 0.000 | 0.000 | **0.000** |
| 30일 | 0.003 | 0.000 | **0.003** |
| 90일 | 0.059 | 0.001 | **0.058** |
| 180일 | 0.153 | 0.044 | **0.108** |

즉 **EMBOLISE(180일, 양성)와 MAGIC-MT(90일, 음성)의 불일치가 구조에서 유도됩니다.**
가정으로 넣은 것이 아닙니다. 색전 시점 스윕도 단조롭습니다:
0일 0.044 → 30일 0.089 → 90일 0.124 → 안 함 0.153.

**TXA는 혈장 반감기 3시간, 작용부위 반감기 약 6일입니다.** 약은 확산이 아니라
유출액에 실려 공동으로 들어오고 흡수로 씻겨 나가므로, 율속 단계는 공동의 회전시간
`V/J_abs`(10–38일)입니다. 공동/혈장 농도비: 0.5일 0.04 → 7일 0.35 → 21일 0.76.

**항응고제 재개의 상충이 명시적입니다**: 3일 재개 시 P(혈전) 0.027 / P(재수술) 0.156,
아예 재개 안 하면 0.078 / 0.153 — 합이 0.183 vs 0.230으로 조기 재개가 유리합니다.

### 실패하는 것 (그리고 왜)

1. **헴 스위치가 보정된 파라미터에서 작동하지 않습니다.** `HB50`이 0.90 g/dL로
   돌아왔는데 공동 헤모글로빈은 ~4 g/dL이므로 `haem_drive`가 모든 arm에서 0.97에
   고정됩니다. 세척 스윕이 **평평합니다**(wash 0.05 → 1.00에서 P(재수술) 0.151 →
   0.156). 쌍안정성은 방정식에는 있지만 적합된 영역에는 없습니다. **따라서 이 모델은
   "맑아질 때까지 세척"을 지지하지 않습니다.**
2. **배액관 대조가 없습니다**: 0.059 / 0.075 vs Santarius 0.093 / **0.240**.
   모델에서 48시간 배액관은 재충전을 약 10일 늦추는 데 그치고, 90일 위험 적분은 그
   차이를 거의 못 봅니다. → **배액관의 실제 2.6배 효과는 체액 제거만으로 설명되지
   않으며, 영구적 상태 변화(양막 융착)를 요구합니다.** 이것은 모델이 만든 검증 가능한
   주장입니다. 융착 속도를 결정적으로 올리는 시도는 A_EXT–두께–개방성 고리를 stiff하게
   만들어 실용적으로 적분이 불가능해졌습니다 (미해결).
3. **수술의 이득이 과소평가됩니다**: 보존적 0.179 vs 천공+배액관 0.152.
4. **아토르바스타틴이 사실상 무효입니다**: 0.050 vs 0.052. ATOCH는 수술 전환을
   23.5% → 11.2%로 절반으로 줄였습니다.
5. **덱사메타손의 기능적 결과가 부호가 반대입니다**: P(양호) 0.264(dex) vs 0.228(위약)
   — Dex-CSDH는 83.9% vs 90.3%로 **악화**를 보였습니다. 절대 척도도 크게 어긋납니다
   (0.23 vs 0.90). 스테로이드 독성 가중치는 보정되지 않았습니다. 국소 효과의 방향만은
   맞습니다(재수술 0.135 vs 0.152, 최고 혈당 8.33 vs 5.40 mmol/L).
6. **적합된 영역에서 재출혈이 유출을 능가합니다**(고평부 J_rb 6.56 vs J_ex 3.46 mL/일).
   이는 위의 "분비하는 기관" 서술을 **뒤집습니다.** 적합은 재출혈 우세 병변을
   선호했습니다. 유출 우세로 강제한 파라미터 조합은 적분이 불가능해졌습니다.
7. **`MMA_FLOOR`의 국소 민감도가 정확히 0입니다** — PMMA = 1인 동안 공급 항이
   포화되어 있기 때문입니다(포화 인공물).

### 민감도가 말하는 것

민감도 순위는 이것이 **체액-역학 모델**임을 보여줍니다: `D50_PAT`(공동 개방성,
−13.8%) → `P_CAP`(+12.2%) → `K_RB`(+11.1%) → `K_SPROUT`(+8.4%) → `KD_CAP`(−6.7%).
사이토카인 파라미터들은 하위권입니다.

## 검증에서 드러난 결함 (defects found by independent re-implementation)

이 환경에는 R 툴체인이 없어, 같은 50-ODE 계를 `csdh_verify.py`에 numpy/scipy로
**독립적으로 다시 타이핑**해 적분했습니다. 그 과정에서 아래 **아홉 개**의 결함이
드러났고 모두 고쳤습니다. 하나하나가 모델을 조용히 무의미하게 만들던 것들입니다.

1. **t-PA 생성 상수가 13배 작았습니다.** 공동 t-PA가 27 → 2 ng/mL로 무너져
   **섬유소용해 루프 L2 전체가 사실상 꺼져 있었습니다.**
2. **단백–교질삼투압 루프의 이득이 1을 넘었습니다.** 부피를 고정한 채 다른 상태를
   이완시키려 하자 공동 단백이 **739 g/dL**까지 폭주했습니다. 원인은 부피 고정이
   `J_ex + J_rb = J_abs`라는, 유계성을 보장하는 바로 그 불변량을 깨뜨린 것이었습니다.
   → 초기조건 가정을 버리고 **생리적 run-in**(얇은 막에서 키워서 발현 시점을 t=0으로)
   으로 바꾸고, 확산성 단백 평형항을 추가했습니다.
3. **흡수항에 구동력이 없었습니다.** 순수 운동학적이어서 3 mL 수집액이 하루에
   사라졌고, 모델은 신생막이 생기기 전에 모든 초발 혈종을 없애 버렸습니다.
   → 압력 구동(ICP − P_sink)으로 바꿨습니다.
4. **모델에 고정점이 하나뿐이었습니다.** 모든 수술이 미치료 부피로 재충전되어
   **재발률이 구조적으로 100%**였습니다. → 헴 항에 Hill 지수 2를 넣어 루프에 문턱을
   부여했습니다(단, §실패 1 참조 — 보정 후 이 스위치는 작동하지 않습니다).
5. **세척이 무효 연산이었습니다.** 부피와 용질량을 같은 계수로 줄이면 모든 *농도*가
   보존되므로 헴 자극이 그대로 남았습니다. → 농도를 줄이는 `wash` 인수를 분리했습니다.
6. **막 면적이 현재 체액량에 묶여 있었습니다.** 배액하면 방금 만들어진 막이 함께
   사라져, 얇은 술후 막은 교환 면적이 거의 없어 어떤 공동도 재충전될 수 없었습니다.
   → 막 확장 범위 `A_EXT`를 **상태변수로 승격**했습니다.
7. **ICP가 기저치 아래로 내려갈 수 없었습니다.** 배압이 없으니 48시간 배액관이
   78 mL 혈종을 **0.06 mL**로 비웠습니다. → ICP를 양방향으로 만들었습니다.
8. **대식세포 구동에 헴과 무관한 IL-8 자가분비 항이 있었습니다.** 외부 입력이 없는
   두 번째 양성 피드백이어서 염증 상태가 결코 꺼지지 않았고(헴 구동 0.12에서도
   대식세포 0.63), 막이 항상 재점화되어 **수술은 누구도 낫게 하지 못하고 MMA 색전술만
   유효**해졌습니다(P(재수술) 0.0007 vs 보고된 0.041). → IL-8 증폭을 헴에 종속시켰습니다.
9. **수치적 강성 세 건.** (a) 압력항의 `max()` 꺾임이 LSODA를 무한정 정지시켰습니다
   → softplus로 평활화. (b) 세척 항의 분모에 부피가 있어 성공적으로 치료된 공동이
   비워질 때 발산했습니다 → `V_FLOOR`. (c) `A_EXT`(확장 vs 융착)와 `V_COMP`(적재 vs
   해제)의 **상태변수에 대한 if/else 분기**가 전환면에서 chattering을 일으켜 지연
   색전술 시나리오가 적분기를 완전히 멈춰 세웠습니다 → 시그모이드 혼합으로 대체.

또한 **음수 상태 없음**, 공동 단백 최대 6.82 g/dL(혈장 7.0 아래로 유지),
ICP 범위 4.23–17.83 mmHg(양방향 확인), 개방성 0.025–0.916을 확인했습니다.
