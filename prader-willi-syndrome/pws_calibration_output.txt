[1] THE ESCAPE-RATIO FORMALISM, SWEPT OVER PC1/3 ACTIVITY
------------------------------------------------------------------------------
  A prohormone P is made at rate S, processed by PC1/3 with pseudo-first-
  order rate kc*PC13, and lost unprocessed at rate d (secreted as
  precursor, or degraded).  In the sub-saturating regime:

      dP/dt = S - (kc*PC13 + d) P          =>  P_ss = S / (PC13 + eps)
      product flux = kc*PC13*P             =>  flux = S / (1 + eps/PC13)
      eps = d/kc = d*Km/kcat               (the ESCAPE RATIO)

      L(eps, PC13) = 1 - (1+eps)/(1+eps/PC13)     product loss
      R(eps, PC13) = (1+eps)/(PC13+eps)           precursor accumulation

  Note the limits, which are the whole point:
      eps -> 0    L -> 0        (fully compensated, precursor piles up)
      eps -> inf  L -> 1-PC13   (fully proportional, no pile-up)

  product loss L (%) as PC1/3 activity falls
  branch (eps)                        1.00    0.80    0.60    0.40    0.30    0.20
  pro-oxytocin -> OXT (6.00)           0.0    17.6    36.4    56.2    66.7    77.4
  POMC -> alpha-MSH (1.50)             0.0    13.0    28.6    47.4    58.3    70.6
  pro-GHRH -> GHRH (1.00)              0.0    11.1    25.0    42.9    53.8    66.7
  proinsulin -> insulin (0.15)         0.0     3.2     8.0    16.4    23.3    34.3
  proghrelin -> acyl-ghrelin (0.10)     0.0     2.2     5.7    12.0    17.5    26.7

  precursor accumulation R (x normal) over the same sweep
  branch (eps)                        1.00    0.80    0.60    0.40    0.30    0.20
  pro-oxytocin -> OXT (6.00)         1.000   1.029   1.061   1.094   1.111   1.129
  POMC -> alpha-MSH (1.50)           1.000   1.087   1.190   1.316   1.389   1.471
  pro-GHRH -> GHRH (1.00)            1.000   1.111   1.250   1.429   1.538   1.667
  proinsulin -> insulin (0.15)       1.000   1.211   1.533   2.091   2.556   3.286
  proghrelin -> acyl-ghrelin (0.10)   1.000   1.222   1.571   2.200   2.750   3.667

  The two tables run in OPPOSITE directions down the rows.  At every
  PC1/3 activity the branch ordering by product loss is the exact
  reverse of the ordering by precursor accumulation — this is forced by
  the algebra, not chosen.  Consequence: the precursor:product ratio is
  a good severity marker only for the branches that are NOT failing.

  AN EXACT IDENTITY, AND THE MEASUREMENT THEORY THAT FOLLOWS
..............................................................................
  Divide Eq. B by (1 - Eq. A):

      precursor / product  =  (1+eps)/(PC13+eps) * (1+eps/PC13)/(1+eps)
                           =  (1+eps/PC13)/(PC13+eps)
                           =  1 / PC13          <-- eps CANCELS

  The precursor:product ratio is 1/PC13 for EVERY branch, exactly,
  independent of the escape ratio.  Numerically, at PC13 = 0.400:

  branch                                prec/prod         1/PC13
  pro-oxytocin -> OXT                2.5000000000   2.5000000000
  POMC -> alpha-MSH                  2.5000000000   2.5000000000
  pro-GHRH -> GHRH                   2.5000000000   2.5000000000
  proinsulin -> insulin              2.5000000000   2.5000000000
  proghrelin -> acyl-ghrelin         2.5000000000   2.5000000000

  So the model implies a complete and slightly bleak measurement theory:

    precursor + product  =  S            measures SYNTHESIS;
                                         exactly blind to PC1/3
    precursor / product  =  1/PC13       measures the CONVERTASE;
                                         exactly blind to eps, i.e.
                                         identical for all five branches
    product alone        =  S/(1+eps/PC13)   the ONLY quantity that
                                         carries branch information

  The two easy assays are each blind to precisely the thing the other
  measures, and neither can tell you which branch is failing.  The one
  informative quantity — absolute bioactive product — is the hardest to
  measure in a living patient, especially for a neuropeptide released
  centrally.  This is a testable claim about assay design, not a
  rhetorical flourish: it says a hyperproinsulinaemia measurement and a
  pro-oxytocin:oxytocin measurement should give the SAME number in the
  same patient, and that number grades the convertase, not the
  phenotype.

[2] WHY A CROSS-REACTING ASSAY IS EXACTLY BLIND TO THE LESION
------------------------------------------------------------------------------
  At steady state, mass in = mass out:
      S = kc*PC13*P  +  d*P  =  (product flux) + (escape flux)
  So the SUM of the two fluxes equals S for every PC13.  An assay that
  cannot separate precursor from product measures that sum.

  branch                         PC13    product     escape        SUM
  pro-oxytocin                   1.00   0.142857   0.857143   1.000000
                                 0.40   0.062500   0.937500   1.000000
                                 0.15   0.024390   0.975610   1.000000
  POMC                           1.00   0.400000   0.600000   1.000000
                                 0.40   0.210526   0.789474   1.000000
                                 0.15   0.090909   0.909091   1.000000
  proinsulin                     1.00   0.869565   0.130435   1.000000
                                 0.40   0.727273   0.272727   1.000000
                                 0.15   0.500000   0.500000   1.000000

  The SUM column is 1.000000 everywhere.  This is not a numerical
  coincidence and it is not parameter-dependent: it is conservation.
  It predicts that studies measuring total immunoreactive oxytocin in
  plasma or CSF in PWS should give inconsistent, near-null results —
  which is what the literature reports — while bioactive, meal-entrained
  central release is markedly reduced.  Any trial that uses a
  cross-reacting oxytocin assay as a target-engagement biomarker is
  measuring a quantity the model says CANNOT respond.

[3] HARMONIC-MEAN SENSITIVITY — WHICH ARM IS WORTH REPAIRING
------------------------------------------------------------------------------
      SAT = 1 / sum_i (w_i / x_i)
      dSAT/dx_i = SAT^2 * w_i / x_i^2

  The sensitivity to an arm scales as w_i / x_i^2, so it grows
  QUADRATICALLY as an arm gets worse.  A harmonic mean does not just
  refuse to be rescued by its healthy terms — it actively concentrates

[4] THE MELANOCORTIN RELAY CEILING
------------------------------------------------------------------------------
      x1 = OXT * relay(MC) * (1 + E_OXTR)
      relay(MC) = (MC/(K+MC)) * (K+1),   K = KREL = 0.20

  relay(1) = 1 by construction, and relay(inf) = K+1 = 1.20.
  So MC4R agonism, no matter how potent, cannot multiply the oxytocin
  arm by more than 1.20 — and it starts from PWS's alpha-MSH tone of
  0.609, where relay = 0.9033.

  MC = 1                             1.0000     0.3281     0.4920

  MC = 5                             1.1538     0.3786     0.5395
  MC = 10                            1.1765     0.3860     0.5461
  MC -> infinity (the CEILING)       1.2000     0.3937     0.5528

  Setmelanotide 3 mg/d reaches MC = 3.14 in the model, i.e. 94% of the
  ceiling already.  There is essentially nothing left to gain from a
  more potent MC4R agonist, and that is a STRUCTURAL statement:
  the drug enters ABOVE the block.  It is also why setmelanotide works
  in POMC and LEPR deficiency (lesion above MC4R) and not in PWS
  (lesion below it) — the same molecule, two different topologies.

      E(C) = E1*C/(K1+C) - E2*C/(K2+C)
      E1 = 1.35  K1 = 0.55 ng/mL   (OXTR agonism)

      =>  sqrt(E1K1)/(K1+C) = sqrt(E2K2)/(K2+C)

[9] THE TWO AIRWAY CLOCKS — PEAK TIME IN CLOSED FORM
------------------------------------------------------------------------------
  Strip the airway block to its skeleton: a step change in IGF-1 drives
  an obstructive term up with rate k_f and a protective term up with
  rate k_s, and AHI is their difference.

      AHI(t) - AHI(0) = A*(1 - exp(-k_f t)) - B*(1 - exp(-k_s t))
      d/dt = 0  =>  t_peak = ln( (A k_f)/(B k_s) ) / (k_f - k_s)

  from the parameter block:
      k_f (lymphoid, up-phase)  ~ 0.1270 /d   (tau 8 d)
      k_s (muscle strength)     = 1/TAURMS = 0.0133 /d   (tau 75 d)
      adaptation (involution)   = 1/TAUAD  = 0.0100 /d   (tau 100 d)

         A        B t_peak (d) t_peak (wk)
       3.0      2.0       23.4        3.3
       3.0      3.0       19.8        2.8
       3.0      5.0       15.3        2.2
       2.0      6.0       10.2        1.5

  Over the whole plausible range of amplitudes the peak sits between
  weeks 3 and 8, because it is set by the RATIO of two rate constants
  under a logarithm — the least amplitude-sensitive quantity the model
  produces.  This is why 'polysomnography at 6-8 weeks' is a robust
  recommendation and not a convention: the timing barely depends on how
  big the effect is, only on how fast lymphoid tissue and muscle move.

  The full model (section [7] of pws_reference_output.txt) puts the peak
  at week 4 with AHI 11.2 -> 13.2 for a typical airway, and 11.2 ->
  22.1 for a vulnerable one, both returning below baseline by 1 year.
  Airway vulnerability multiplies the OBSTRUCTIVE terms only, so it
  scales the window and not the plateau — which is exactly the shape of
  the reported early-GH mortality signal.
